# 摆动结构与假突破（Market / Swing Structure）

| 项目 | 内容 |
|---|---|
| 中文名称 | 摆动结构 |
| 英文名称 | Market Structure / Swing Structure |
| 常用别称 | 结构、摆动序列、HH/HL |
| 类型 | 价格结构观察（摆动点序列，不是算法指标） |

会读 K 线、会连趋势线与水平区域之后，下一步是问：**这段是推进还是回撤，结构还在不在。**

与 [trendlines.md](./trendlines.md) 的分工：趋势线篇管**斜线与水平区域怎么画**；本文件管**摆动点怎么排成序列**，以及收盘离开与影线扫过（假突破）怎么记。两篇共用同一套摆动点标法，不要各画一套高低点。

本文件不使用订单块、Smart Money、庄家诱多等说法。扫过前高前低，只记「到过 / 收回」，不鉴定谁在扫。

---

## 1. 它是什么

**摆动结构（Market Structure / Swing Structure）**是把相邻的**摆动高点（Swing High）**与**摆动低点（Swing Low）**排成序列，用来描述一段价格是在抬高、压低，还是已经打断。

- **摆动高点**：左右若干根已收盘 K 线里的局部最高。
- **摆动低点**：左右若干根已收盘 K 线里的局部最低。

序列常用四组简称：

| 简称 | 英文 | 含义 |
|---|---|---|
| HH | Higher High | 更高的高点 |
| HL | Higher Low | 更高的低点 |
| LH | Lower High | 更低的高点 |
| LL | Lower Low | 更低的低点 |

教学上：

- **上升结构**：可见的 HH + HL（更高高点、更高低点）
- **下降结构**：可见的 LH + LL（更低高点、更低低点）

结构是读图约定，不是开仓指令，也不是「结构在，价格就会继续」。

---

## 2. 它测量什么

测量的是**摆动点的先后关系**：这段在推进、在回撤，还是已经留下破结构的收盘。

它回答：

- 最近几个高低点是在抬还是在压？
- 这一段更像沿原方向的推进，还是逆向的回撤？
- 价格是收盘离开了前高 / 前低所在区域，还是影线扫过又收回？
- 破结构之后，原区域是开始被当成反角色来观察，还是立刻被扫回？

它不测量：

- 斜线斜率与水平区宽度（那是趋势线与支撑阻力）
- 平滑后的平均价（MA / EMA）
- 动量读数（RSI / MACD）
- 成交、仓位、资金费

默认读图顺序：**先结构，再均线，再副图**。副图不能单独推翻已收盘的结构；均线穿过也不等于结构已被破坏。

---

## 3. 如何计算（教学级）

没有回看参数公式。有的是与趋势线篇同一套读图步骤：

1. 选定图表周期，只标**已收盘** K 线。
2. 用左右 3–5 根窗口标出摆动高点、摆动低点（与 [trendlines.md](./trendlines.md) 一致）。
3. 按时间顺序写下 HH / HL / LH / LL，不要先假设「这是上升」再挑点。
4. 把同方向、实体较长的一段称作**推进（Impulse / Advance）**；把逆向、通常较短的一段称作**回撤（Pullback / Retracement）**。回撤不是自动反转。
5. 判断「破了没有」时，优先看收盘是否离开前高 / 前低所在**区域**；影线扫到只说明到过。
6. 破结构之后，把原区域标成「角色可能互换」的观察位，同时允许它立刻被扫回。

不同人选出的摆动点会不一样。这是结构观察的主观性，不是计算误差。课文必须写明：同一张图可以标出不同序列，序列要服务于你要回答的问题（这段还在不在），不要为了好看而改点。

跨周期：5 分钟上的破结构，不能用来否决 4 小时上仍成立的已收盘结构。多周期怎么写规则，留给后续系统课；本文件只立这条边界。

---

## 4. 如何观察

建议顺序：

1. **图表周期**：先声明在看哪一根周期的结构。
2. **摆动点**：先标点，再写 HH/HL 或 LH/LL；不要先写结论再找点。
3. **推进还是回撤**：沿最近结构方向走、波动相对大的是推进；逆向、通常更浅的是回撤。回撤可以很深，仍不必改写成反转。
4. **收盘离开 vs 影线扫过**：
   - 收盘离开前高 / 前低区域：记「收盘离开」，结构可能已被打断。
   - 影线越过、收盘回到区内：记**假突破（False Breakout）**或扫过外侧停单（扫流动性的观察说法）。到过不等于收在。
5. **破结构之后**：原阻力可能开始被当成支撑来观察，或相反（**角色互换**）。也可能刚破就被扫回。两种后果都要允许，不要写成剧本。
6. **再叠加均线与副图**：结构看完，才问均线斜率、动量是否同步。副图冲突时回到结构，不是再加一把振荡器。

## 5. 常见参数

| 选择 | 常见取值 | 说明 |
|---|---|---|
| 图表周期 | 15m / 1H / 4H / 1D | 必须写明；跨周期的结构不要叠成同一条 |
| 摆动窗口 | 左右 3–5 根 | 与趋势线篇同一约定 |
| 确认约定 | 已收盘离开区域 | 本库教学默认；盘中刺破不算站稳 |
| 区域宽度 | 近期波动的一小段 | 前高前低是区，不是发丝价 |

没有「标准结构参数」。窗口越小，摆动点越多、噪声越大；窗口越大，结构越慢、越滞后。

---

## 6. 典型形态

下列名称用于教学识别，**不是**涨跌指令。

| 形态 | 怎么认 | 教学上可说的观察 | 不能说的话 |
|---|---|---|---|
| 上升结构 | 可见 HH + HL | 高低点在抬 | 「上涨会继续」 |
| 下降结构 | 可见 LH + LL | 高低点在压 | 「下跌已确立」 |
| 推进 | 沿结构方向的一段延伸 | 这是推进段 | 「主升 / 主跌已确认」 |
| 回撤 | 逆向、通常较浅的一段 | 这是回撤，尚未改序列 | 「回调结束，该接」 |
| 假突破 / 扫过 | 影线穿出前高或前低，收盘回到区内 | 到过，未收盘离开 | 「庄家诱多 / 诱空已确认」 |
| 收盘破结构 | 收盘离开前高或前低区域 | 原序列可能已被打断 | 「趋势反转完成」 |
| 破后角色观察 | 回到原区域附近 | 原阻力开始被当成支撑来观察，或相反 | 「突破后必回踩确认」 |
| 破后立刻扫回 | 刚收盘离开又被收回 | 打断可能失败 | 「假突破之后必反向」 |

---

## 7. 何时有用

- 作为默认读图的第一层：先回答结构还在不在，再决定要不要看均线。
- 区分推进与回撤，避免把每一段逆向都写成反转。
- 给假突破一个可检查的记法：影线到过、收盘在哪。
- 为入场、止损规则提供位置描述（阶段 3 再用），本篇本身不下规则。
- 给多周期课留钩子：低周期结构与高周期结构可以同时成立，讨论的不是同一段路。

---

## 8. 何时失效

- **几乎没有摆动点**：单边插针或根数太少，序列变成事后拟合。
- **周期过短**：点差和薄盘成交会制造假高低点。
- **未收盘当已破**：盘中刺破，收盘可能收回。
- **用更小周期否决更大周期**：5 分钟的 LL 不能单独改写 4 小时的 HL。
- **把结构当预测**：HH/HL 描述的是已经发生的点，不保证下一个点仍更高。
- **和趋势线、均线混成同一工具**：线是位置，均线是算法平滑，结构是点的顺序。
- **清算瀑布、薄盘跳价**：高低点可能是强平扫货，不是广泛共识。见 [liquidation-cascade.md](./liquidation-cascade.md)。

---

## 9. 常见误区

1. 刺破瞬间写成突破开仓，不等收盘。
2. 把回撤自动写成反转。
3. 用 5 分钟结构否决 4 小时结构，却不声明周期。
4. 把影线扫过写成庄家确定诱多、诱空。
5. 破结构后把角色互换当成价格会回来确认的剧本。
6. 先画一条「好看的」趋势线，再改摆动点去贴线。
7. 副图金叉、背离单独推翻已收盘结构。
8. 用虚构 K 线证明某种结构能赚钱。

## 10. 可与哪些指标组合

| 组合 | 观察目的 | 注意 |
|---|---|---|
| 结构 + 趋势线 / 水平区 | 序列对照手画位置 | 线管区，本篇管点的顺序 |
| 结构 + MA / EMA | 先结构，再看均线是否同向 | 穿过均线不等于破结构 |
| 结构 + ATR | 这一摆的宽度是否超出普通噪声 | ATR 不给方向 |
| 结构 + RSI / MACD | 到区或破结构时动能是否同步 | 冲突时回到结构，不加第三把振荡器 |
| 结构 + Volume | 推进 / 破结构时转手是否异常 | 放量也可能是强平连锁 |
| 结构 + OI | 破结构时仓位增减 | 见 OI 四象限 |

优先组合：先把摆动序列写清楚，再叠加一条均线。不要用六条副图重复解释同一个更高低点。

## 教学备注（给 Content Agent）

- 插在趋势线之后、MA 之前。先修：`kline`、`trendlines`。下一篇：`ma`。
- 必须出现正反例：影线刺破前高后收回，记「到过，未收盘离开」；刺破瞬间写成突破开仓是反例。
- 默认读图顺序写成可检查的三步：结构 → 均线 → 副图。
- 禁止订单块、Smart Money 术语堆砌、把扫荡写成庄家确定诱多。
- 多周期打架只留一句钩子，正文不展开。
- 示意图建议：上升结构（HH/HL）一格，假突破收回一格。真实行情须写 symbol、timeframe、source、period。
