# 资金费率（Funding Rate）

| 项目 | 内容 |
|---|---|
| 中文名称 | 资金费率 |
| 英文名称 | Funding Rate |
| 相关词 | 资金费（Funding Payment） |
| 类型 | 永续合约机制数据 / 拥挤与溢价观察 |

机制背景见 [perpetual-futures.md](../perpetual-futures.md)。本文回答：费率怎么来、图上怎么读、何时失效。它不是振荡指标，没有 70/30。

---

## 1. 它是什么

资金费率是永续合约按固定或动态间隔，在**多头与空头之间**转移资金所用的比率。目的是抑制永续价格长期偏离指数价格。

- **费率为正**：多头支付空头。常见于合约相对现货升水（永续更贵）。
- **费率为负**：空头支付多头。常见于合约相对现货贴水（永续更便宜）。

**资金费**是实际划走的金额，约等于：

> 资金费 ≈ 仓位名义价值 × 资金费率

（精确公式含标记价选取、仓位方向、费率封顶，以交易所为准。）

只有持有仓位越过结算时点的一方才收付。费率本身不是价格预测。

---

## 2. 它测量什么

直接测量：**让永续贴住现货指数的周期性费用方向与大小**。

间接观察：

- 合约相对现货的溢价 / 贴水是否偏大
- 某一方向持仓是否愿意持续付费（拥挤的侧面）
- 持有成本：逆势或顺势拿仓要付多少

它不测量价格下一步涨跌，也不等于 OI 或成交量。极端正费率可以和上涨同时存在很久：付钱的多头仍可能在价格上盈利。

---

## 3. 如何计算（教学级）

各交易所公式不同。教学抓结构，不背某一所的全部系数。

常见结构（以主流 U 本位永续的思路为例）：

1. **溢价指数（Premium Index）**  
   比较合约买一 / 卖一或中间价与指数价，衡量永续贵了还是便宜了。为避免被薄盘操纵，常用冲击买卖价（Impact bid/ask）并做时间平均。
2. **利率（Interest Rate）**  
   部分交易所加入稳定币与标的借贷利率差的一项，数值通常较小，并有夹逼（clamp），避免利率项主导。
3. **资金费率**  
   由溢价与利率合成，再设上限、下限。结算间隔常见 8 小时；波动大时有的交易所会缩短间隔。

学习者在图上看到的，多是「已结算费率」或「预测中的下一次费率」。预测值在结算前会变。分析历史用已结算序列；盯盘用预测值时要标明「未结算」。

不要尝试在课文里给出跨交易所通用的精确代数，以免与真实规则冲突。

---

## 4. 如何观察

1. **符号**：正 / 负，谁在付钱。
2. **幅度**：靠近 0 是常态；远离 0 表示溢价或贴水偏大，或间隔缩短后的折算不同。比较幅度时先统一「每 8 小时」还是「年化」。
3. **持续时间**：短暂尖峰 vs 连续多个周期同向偏高。后者更像拥挤或持续升水，仍不是反转时钟。
4. **与价格**：价格急涨且费率转正加大，常见于多头愿意付费拿仓。价格跌而费率仍大幅为正，可能是溢价尚未消退或计算滞后。
5. **与 OI**：费率极端 + OI 仍升，拥挤可能在加；费率极端 + OI 降，可能在去杠杆。见第 10 问。
6. **结算时刻**：K 线在结算附近出现的量能或插针，要先排除机械性调仓，再谈形态。

年化换算（仅便于直觉，各所间隔不同）：

> 粗略年化 ≈ 单次费率 × (24 / 间隔小时) × 365

粗略年化很大时，只说明「若费率维持不变，持有一年的费用很可观」——费率通常不会维持不变。

---

## 5. 常见参数

| 项目 | 常见情况 | 须写明 |
|---|---|---|
| 结算间隔 | 8h；也有 1h 或动态 | 交易所规则 |
| 显示单位 | 单次比率 / 年化 | 二者差几十倍，不能混图 |
| 序列 | 已结算 / 预测 | 预测会改 |
| 封顶 | 各所不同 | 极端行情触顶后不再线性放大 |
| 标的 | 各合约独立 | BTC 与山寨币费率性格不同 |

没有 RSI 式的默认回看。若对费率做均线（如 3 日均值），属于二次平滑，须声明。

---

## 6. 典型形态

| 形态 | 观察 | 限制 |
|---|---|---|
| 持续小幅为正 | 轻度升水，多头付少量费 | 常态，几乎不构成观点 |
| 持续大幅为正 | 多头拥挤或合约持续升水 | 价格仍可继续涨 |
| 持续大幅为负 | 空头拥挤或持续贴水 | 价格仍可继续跌 |
| 费率尖峰后回落 | 溢价被修复或间隔规则变化 | 不保证价格回头 |
| 价格新高、费率未新高 | 溢价与价格不同步 | 不是顶背离的等价物 |
| 结算时刻毛刺 | 量能或影线异常 | 先当机制噪声 |

---

## 7. 何时有用

- 解释永续为何能没有到期日仍贴近现货。
- 计算持仓成本：回测与复盘要把资金费算进净盈亏。
- 观察拥挤的一个侧面，与 OI、多空比互相核对。
- 提醒高杠杆账户：费用与强平是两套风险，可能叠加。

---

## 8. 何时失效

- **当反转指标用**：极端费率可以维持，且趋势继续。
- **跨所、跨间隔直接比数字**。
- **把预测费率当已发生**。
- **忽略名义价值**：费率 0.01% 在高杠杆、大名义上仍是真金白银。
- **只看 BTC 的经验套到低流动性合约**：山寨溢价与操纵更常见。
- **保险基金、自动减仓等极端机制启动时**，价格、溢价、费率关系会变形。

---

## 9. 常见误区

1. 正费率就是该空，负费率就是该多（逆费率交易被写成稳定策略）。
2. 收到资金费证明方向正确。
3. 把资金费率当成 APR 理财。对方付给你的钱来自对面持仓者，伴随价格风险。
4. 年化与单次费率混在一张图上比较「谁更极端」。
5. 认为资金费由交易所当庄家收取。常规情况下是多空互付（交易所规则说明为准）。
6. 忽略：强平与资金费结算可能落在同一时段，因果难分。

---

## 10. 可与哪些指标组合

| 组合 | 观察目的 |
|---|---|
| Funding + OI | 课程核心：付费方向是否伴随加仓 |
| Funding + 价格 / K 线 | 溢价与趋势是否同向 |
| Funding + Volume | 极端费率时段是否放量 |
| Funding + 多空比 | 费用方向与某口径倾斜是否一致（注意口径） |
| Funding + CVD | 主动成交与愿意付费的方向是否一致 |
| Funding + 杠杆教学 | 费用对薄保证金账户的侵蚀 |

禁止把「Funding + OI」写成「双指标共振即可反向开仓」。共振只表示多个上下文同向，结果仍不确定。
