# 成交量（Volume）

| 项目 | 内容 |
|---|---|
| 中文名称 | 成交量 |
| 英文名称 | Volume |
| 常用缩写 | Vol |
| 类型 | 市场活跃度 / 转手 |

成交量回答「这段时间转手了多少」，不回答「现在还挂着多少仓」（那是持仓量），也不回答「主动买减主动卖累加多少」（那是 CVD）。

---

## 1. 它是什么

成交量是某一时间桶内成交的数量汇总。在 U 本位永续上，同一根成交量柱可能按不同单位显示：

| 单位 | 含义 | 注意 |
|---|---|---|
| 标的数量 | 如 BTC 张数 / 币数 | 价格涨时，同样币数对应更多 USDT |
| 报价货币额 | 如 USDT 成交额 | 便于跨价格比较金额 |
| 合约张数 | 交易所合约乘数后的张 | 跨所不能直接加 |

课文必须写明当前图是哪一种。只写「放量」而不写单位，读者无法复现。

成交量是双方成交的结果：有买就有卖。高成交量不表示「只有多方」或「只有空方」。

---

## 2. 它测量什么

测量**转手活跃程度**。

间接触及：

- 某段价格移动是否伴随更多成交
- 活跃度是在上升还是萎缩
- 相对近期均值，当前量是否异常

不测量：

- 未平仓总量（OI）
- 主动方向净额（CVD / Delta）
- 多空人数（多空比）
- 持仓成本（资金费）

「放量上涨」只说明上涨这段转手多，不能直接说「主力在吸筹」或「后面只会继续涨」。

---

## 3. 如何计算（教学级）

对时间桶内每笔成交：

> 成交量_桶 = 各笔成交数量之和（按选定单位）

若用 USDT 成交额：

> 成交额_桶 ≈ Σ (成交价格 × 标的数量)

永续上常见额外拆分（不是普通 Volume 的必需项）：

- 主动买成交量（Taker buy volume）
- 主动卖成交量（Taker sell volume）

普通成交量柱 = 主动买 + 主动卖（同一批成交）。把两者相减再累加，就进入 [cvd.md](./cvd.md) 的范围。

不同交易所、聚合源对「一张」的定义不同。跨所比较应先换算到同一单位（通常换 USDT 名义）。

---

## 4. 如何观察

1. **绝对柱高**：单独一根很高，先问单位、是否含爆点、是否新闻时段。
2. **相对均量**：与最近 20 根成交量均值比较，比看绝对数字稳定。均量本身也滞后。
3. **量价同向或不同向**：
   - 价格创新高、量能也放大：常见于趋势延伸或高潮，两者事后都能找到例子。
   - 价格创新高、量能缩小：参与减少的画面，可能是乏力，也可能是顺畅的低阻力滑动。
4. **缩量回撤 / 放量回撤**：回撤时量能变化，常被用来讨论「回撤是否被更多人抢」，仍不是规则。
5. **连续缩量**：活跃度下降，突破后的滑点风险可能上升，方向仍未知。
6. **与 OI 对照**：量高而 OI 升，偏向新开仓对开；量高而 OI 降，偏向平仓对砸。见 [open-interest.md](./open-interest.md)。

---

## 5. 常见参数

成交量本身无经典「14」参数，但观察时常加：

| 选择 | 常见做法 |
|---|---|
| 单位 | 标的数量或 USDT 额，必须固定 |
| 均量线 | 20 或 50 根成交量 SMA |
| 图表周期 | 与价格图相同，不要用 1m 量解释日线结构 |
| 是否含当前未收盘 | 分析用已收盘；未收盘量会一直增加 |

没有「正常量」的绝对标准。各自品种、各自时段（亚洲 / 欧美盘）的量级不同。

---

## 6. 典型形态

| 形态 | 观察 | 限制 |
|---|---|---|
| 放量推进 | 价格沿方向移动，量高于近期均值 | 也可能是高潮或强平连锁 |
| 缩量推进 | 价格移动但量低 | 可能顺滑，也可能参与不足 |
| 放量反转烛 | 长实体反向 + 大量 | 也可能是中继的反向扫单 |
| 量价背离 | 价格新高/新低，量不确认 | 不是反转指令 |
| 间歇巨量 | 单根远高于两侧 | 检查插针、资金费结算、数据毛刺 |
| 均量抬升 | 一段时间整体更活跃 | 不指示方向 |

---

## 7. 何时有用

- 给价格变动加「参与度」上下文。
- 识别异常活跃的时间桶，再决定要不要细看该段的 OI、CVD、资金费。
- 趋势课：看推进与回撤的量能差异（描述，不是信号）。
- 与 OI 一起，区分「转手」和「仓位增减」。

---

## 8. 何时失效

- **单位混乱**：把张数当 BTC、把 USDT 当张。
- **刷量 / 自成交**：公开成交量可能被扭曲，尤其小币种。
- **聚合图**：多交易所简单相加，重复或口径不一。
- **只看颜色**：有的软件把上涨根画成绿量、下跌根画成红量，颜色来自价格，不是来自买卖方向。
- **低流动性品种**：几笔单就能造成「放量」。
- **用现货量解释合约，或反过来**，不经换算。

---

## 9. 常见误区

1. 放量 = 主力买入。成交是双边的。
2. 成交量等于持仓量。
3. 绿柱是买、红柱是卖（多数软件只是随涨跌上色）。
4. 放量突破「更可靠」——放量突破失败同样常见，本库不把放量写成确认。
5. 忽略资金费结算、整点附近的机械成交。
6. 跨周期比较绝对柱高（1 分钟量加总才接近 1 小时量，还要考虑漏桶与缺失）。

---

## 10. 可与哪些指标组合

| 组合 | 观察目的 |
|---|---|
| Volume + K 线 | 长实体、长影是否伴随异常转手 |
| Volume + MA / EMA | 课程「趋势 + 成交量」：方向与活跃度 |
| Volume + OI | 转手 vs 增减仓 |
| Volume + CVD | 总量 vs 主动净额 |
| Volume + RSI / MACD | 动量变化是否有量 |
| Volume + Funding | 费率极端时是否同时放量 |

「趋势 + 成交量」「OI + Volume」是第二部分组合，知识边界止于如何读，不停在如何下单。

## 教学备注（给 Content Agent）

- 开篇用一张表分清 Volume / OI / CVD。
- 用同一段行情分别看「上色成交量」和「买卖方向拆分」，打破绿买红卖。
- 不编造「放量后连涨三天」的统计结论。
