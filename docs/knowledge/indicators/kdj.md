# 随机指标 / KDJ（Stochastic Oscillator / KDJ）

| 项目 | 内容 |
|---|---|
| 中文名称 | 随机指标；KDJ |
| 英文名称 | Stochastic Oscillator（KDJ 为其常见中文扩展画法） |
| 常用缩写 | KDJ、Stoch |
| 类型 | 动量振荡器（位置型） |

KDJ 在中文交易教学里比「随机指标」更常见。它与 RSI 都是动量工具，但提问不同：RSI 问「涨幅相对跌幅」；KDJ 问「收盘价落在最近高低区间的哪里」。

---

## 1. 它是什么

随机指标看的是：**当前收盘价在最近 N 根最高价与最低价之间的相对位置**。收盘靠近区间上沿，读数偏高；靠近下沿，读数偏低。

经典 Stochastic 有快慢两条线（%K、%D）。中文常用的 **KDJ** 再增加第三条 **J 线**：

> J = 3K − 2D

J 线更敏感，可以跑到 0 以下或 100 以上。KDJ 因此比 RSI 更容易画出「极端」和「交叉」，也更容易在震荡之外给出噪声。

---

## 2. 它测量什么

测量**收盘价在回看窗口极值区间中的百分位**，再平滑。

它回答：

- 现在的收盘，是靠近最近的强势端，还是靠近弱势端？
- 这个相对位置的快线与慢线是否交叉？
- 价格创新高 / 新低时，相对位置指标有没有同步？

它不测量涨跌速度的比值（RSI），也不测量量与仓。窗口内如果出现一根极长的高影或低影，整个 RSV 的分母会被拉大，后续读数会被「撑开」或「压扁」。

---

## 3. 如何计算（教学级）

设回看 n 根（常用 9），窗口最高价 H_n、最低价 L_n，收盘 C。

**未成熟随机值 RSV（即原始 %K）**：

> RSV = (C − L_n) / (H_n − L_n) × 100
>
> 若 H_n = L_n（窗口无波动），RSV 在软件里常取 50 或沿用上值，课文需说明。

**K 与 D 的平滑**（国内 KDJ 常见写法）：

> K_t = (2/3) × K_{t-1} + (1/3) × RSV_t
>
> D_t = (2/3) × D_{t-1} + (1/3) × K_t
>
> J_t = 3 × K_t − 2 × D_t

种子：K、D 常从 50 起，或用前几根 RSV 的平均。不同软件种子不同，早期数值会对不上。

对照西方 Stochastic：

- Fast %K ≈ RSV
- Fast %D / Slow %K ≈ 对 RSV 再平均
- Slow %D ≈ 再平滑一次

参数常写作 (n, m1, m2)，如 (9, 3, 3)，对应窗口 9、K 平滑 3、D 平滑 3。2/3 与 1/3 就是「3 期指数式平滑」的一种写法。

本库讲 KDJ 时默认 **(9, 3, 3) + J = 3K − 2D**。若图表是纯 Stochastic 且无 J 线，不要硬叫 KDJ。

---

## 4. 如何观察

1. **K、D 位置**：传统上也借用超买超卖语言，常见 80 / 20 或 70 / 30。区域仍不是反转指令。
2. **K 与 D 交叉**：K 上穿 D 称金叉，下穿称死叉。KDJ 交叉非常频繁，尤其在低周期。交叉不是买卖指令。
3. **J 线**：J 先到极端、先回头，常被当作「更早的提醒」，也因此假动作更多。J > 100 或 J < 0 只说明 K 相对 D 偏离大。
4. **钝化**：价格续创新高或新低，K/D 在高位或低位走平。趋势里很常见。
5. **背离**：价格与 K 或 D 的高低点不同步。背离不是反转确认。
6. **与 RSI 对照**：同一段趋势，KDJ 可能已多次从 80 回落，RSI 仍停在 60–80。这是性格差异，不是谁对谁错。

---

## 5. 常见参数

| 参数 | 常见值 | 效果 |
|---|---|---|
| n（高低窗口） | 9 | 中文 KDJ 默认；更短更敏感 |
| n | 14 | 更接近随机指标教科书 |
| m1, m2 | 3, 3 | K、D 平滑 |
| 极端区 | 80 / 20 | 比 70 / 30 更严 |

没有一组参数能让交叉「只出现在转折点」。缩短 n 会增加交叉次数。

---

## 6. 典型形态

| 形态 | 观察 | 限制 |
|---|---|---|
| 低位金叉 | K 从低区上穿 D | 下跌趋势中可连续多次低位金叉后继续跌 |
| 高位死叉 | K 从高区下穿 D | 上涨趋势中可连续多次后继续涨 |
| J 上穿 100 / 下穿 0 | 偏离极大 | 可停留或反复穿越 |
| 高位 / 低位钝化 | 指标不再跟随价格创新高或新低 | 常被过早当成转折 |
| 顶 / 底背离 | 价格与 K/D 不同步 | 可长时间无效 |
| K、D、J 纠缠在 50 附近 | 窗口内收盘居中、方向不清 | 此时交叉参考价值弱 |

---

## 7. 何时有用

- 震荡、高低边界相对清楚时，观察收盘是贴着区间上沿还是下沿。
- 需要比 RSI 更敏感的交叉与极端提醒，并愿意接受更多空信号。
- 教学上用来对比「位置型动量」与「涨跌比型动量」。
- 与趋势过滤同时使用，减少逆趋势解读每一次交叉。

---

## 8. 何时失效

- **单边趋势**：指标在极端区钝化或反复交叉，价格不回头。
- **窗口内异常高低点**：一根长影线改写 H_n 或 L_n，RSV 失真数根。
- **低周期永续**：插针多，KDJ 几乎一直在交叉。
- **把三条线都当成独立信号**：J、K、D 高度同源，不是三重独立证据。
- **软件叫 KDJ 但算法是 Slow Stochastic 且无 J**，学习者对不上图。

---

## 9. 常见误区

1. 金叉就能买、死叉就能卖。
2. J 值大于 100 就是顶部。
3. 认为 KDJ 比 RSI「更准」只因为更敏感。
4. 忽略高低价来自 High/Low，插针会污染分母。
5. 用未收盘的当前高低计算 RSV，盘中数值剧烈跳动。
6. 把 KDJ 当资金流向或主力持仓——它只用 OHLC。

---

## 10. 可与哪些指标组合

| 组合 | 观察目的 |
|---|---|
| KDJ + MA / EMA | 趋势过滤，降低震荡交叉的误用 |
| KDJ + RSI | 位置动量 vs 涨跌比动量；同向时只说明动量描述一致 |
| KDJ + MACD | 快交叉 vs 慢均线差 |
| KDJ + 布林带 | 价格在轨道附近时，收盘分位是否也在极端 |
| KDJ + Volume | 交叉或离开极端区时有没有量 |
| KDJ + K 线 | 先看收盘在最近波段的位置，再看指标是否重复同一信息 |

课程上 KDJ 不宜作为第一篇动量课文；应在 RSI 之后，专门对比敏感度与假交叉。

## 术语对照

| 中文 | 英文 |
|---|---|
| 随机指标 | Stochastic Oscillator |
| 未成熟随机值 | RSV / raw %K |
| K 线 / D 线 / J 线 | %K / %D / J |
| 快随机 / 慢随机 | Fast / Slow Stochastic |
| 钝化 | Flattening at extremes |

此处「K 线」指 KDJ 的 K，不是蜡烛图。课文必须写「KDJ 的 K 线」以免和蜡烛图冲突。本库蜡烛图始终称「K 线（蜡烛）」，KDJ 称「K 值 / D 值 / J 值」。

---

## 教学备注（给 Content Agent）

- 术语：用「K 值」不要用「K 线」指指标。
- 手算：先算 RSV，再做一次 1/3 平滑，最后算 J。
- 必配趋势市高位钝化反例。
