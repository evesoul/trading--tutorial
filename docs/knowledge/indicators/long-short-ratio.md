# 多空比（Long/Short Ratio，LSR）

| 项目 | 内容 |
|---|---|
| 中文名称 | 多空比 |
| 英文名称 | Long/Short Ratio |
| 常用缩写 | LSR |
| 类型 | 持仓结构（口径依赖披露） |

多空比是「某一统计口径下，多头相对空头有多少」的比值。没有口径的多空比无法解释，也不能跨接口比较。

---

## 1. 它是什么

多空比用除法表达倾斜：

> 多空比 = 多头侧统计量 / 空头侧统计量

「侧」可能是：

| 口径 | 统计对象 | 常见误解 |
|---|---|---|
| 账户数比（Accounts） | 有多少账户持多、持空 | 一个大户和一个散户各算 1 |
| 持仓量比（Positions / Size） | 多头仓位总量 / 空头仓位总量 | 与账户数比可以反向 |
| 大户账户比（Top trader accounts） | 排名靠前账户的多空人数 | 「大户」定义由交易所定 |
| 大户持仓比（Top trader positions） | 排名靠前账户的仓位量 | 仍不是全市场 |

同一时刻，账户数比可以大于 1（更多账户做多），持仓量比可以小于 1（空头单户更大）。两张图讲的不是同一件事。

多空比通常只覆盖**该交易所、该接口样本**，不是链上全部持仓，也不是全球交易者投票。

---

## 2. 它测量什么

测量**样本内多空结构的倾斜**，不是价格动量，也不是未平仓总量。

它至多提供：

- 样本更偏多还是更偏空
- 倾斜是在加大还是收敛
- 大户口径与全员口径是否分裂

它不提供：

- 这些仓位的杠杆与强平价
- 开仓成本
- 下一步价格

把散户账户数比当作「聪明钱反向指标」，属于策略假设，不是本库的知识结论。该假设有时成立、有时不成立，且随样本变化。

---

## 3. 如何计算（教学级）

交易所先按自己的规则抽样（全体、或前 N 账户、或某门槛以上），再分别加总多头与空头的账户数或仓位，相除。

教学写法：

> 账户多空比 = 多头账户数 / 空头账户数
>
> 持仓多空比 = 多头仓位规模 / 空头仓位规模

细节因所而异，课文必须抄接口说明，而不是背「全球统一公式」：

- 对冲账户怎么算（净仓还是分腿）
- 更新频率（5 分钟、15 分钟、1 小时）
- 是否含跟单、子账户
- 单位（张、币、USDT）

本库不指定某一交易所的数字为「标准多空比」。写入教程的每一张图都要有：交易所、接口名、口径、时间。

---

## 4. 如何观察

1. **先读标题口径**，再读数字。
2. **1 附近**：样本相对均衡（仍可能两边杠杆不同）。
3. **远离 1**：倾斜。账户比远离 1 只说明人数不均。
4. **变化**：从 0.8 到 1.5 的过程，比孤立读 1.2 更有上下文。
5. **分裂**：全员账户比偏多、大户持仓比偏空，说明结构分层。分层是观察，不是「大户正确」。
6. **与价格、OI、资金费对照**：单独的多空比最容易被讲成故事。

数值没有传统超买超卖线。人为画 2.0 / 0.5 当极端，只是个人分区，须声明，且不构成指令。

---

## 5. 常见参数

| 项目 | 必须声明 |
|---|---|
| 交易所与接口 | 例如某所「全员账户」「顶级交易者持仓」 |
| 口径 | 账户 vs 持仓；全员 vs 大户 |
| 更新间隔 | 与 K 线是否对齐 |
| 品种 | 各合约独立 |
| 平滑 | 若对比值做均线，写窗口 |

没有默认 (14) 参数。不要把 LSR 画成 RSI 风格的 0–100 再套 70/30，除非你先做了自己的变换并声明——本库不采用这种变换。

---

## 6. 典型形态

| 形态 | 观察 | 限制 |
|---|---|---|
| 账户比持续 > 1 | 更多账户持多 | 仓位可能仍被少数空头主导 |
| 持仓比持续 < 1 | 空头仓位总量更大 | 人数可能仍偏多 |
| 价格上涨、账户比升 | 更多账户跟多 | 可能是趋势跟随，也可能是拥挤 |
| 价格下跌、账户比仍高 | 人数尚未转向 | 不能推出「即将反弹」或「还将跌」 |
| 大户与全员反向 | 结构分裂 | 不知哪边代表未来价格 |
| 比值急跳 | 检查数据更新、接口变更 | 先当数据事件 |

---

## 7. 何时有用

- 演示「公开持仓结构是样本，不是真相」。
- 与 OI、资金费一起，讨论拥挤是否只存在于某一口径。
- 帮助学习者读懂交易所信息页，避免把四个接口当成同一个指标。
- 作为策略研究的输入之一时，必须固定口径并做样本外检验（归 Strategy / 回测，不在本文给规则）。

---

## 8. 何时失效

- **口径未声明或中途更换**。
- **把单所散户比当成全球情绪**。
- **样本偏差**：零售占比高的接口，人数比会系统性偏多或偏空。
- **对冲与套利账户**：真实方向暴露被净额或分腿规则隐藏。
- **低更新频率配高波动价格**。
- **当逆势定时器**：一边倒可以持续整个趋势。

---

## 9. 常见误区

1. 多空比就是多头开仓量减空头开仓量。OI 才是双边存量；多空比是倾斜。
2. 账户比和持仓比可以互相替代。
3. 散户偏多就该空。这是未经验证的口号。
4. 「顶级交易者」等于知情者。排名规则不透明，且大户也会错。
5. 把比值 2 理解成「多头是空头的两倍力量」而不看是人数还是仓位。
6. 跨交易所平均出一个「世界多空比」而不统一口径。

---

## 10. 可与哪些指标组合

| 组合 | 观察目的 |
|---|---|
| LSR + OI | 倾斜变化时存量是增是减 |
| LSR + Funding | 人数 / 仓位倾斜与付费方向是否一致 |
| LSR + 价格 | 倾斜加大时价格是否同向 |
| LSR + Volume | 结构变化是否发生在放量段 |
| LSR + CVD | 披露结构 vs 主动成交（常不一致） |
| 两种 LSR 口径互相对照 | 人数 vs 仓位，全员 vs 大户 |

多空比在课程中应靠后，先建立 OI 与资金费，再引入「还有一种更容易误读的结构数据」。
