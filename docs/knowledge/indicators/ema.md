# 指数均线（Exponential Moving Average，EMA）

| 项目 | 内容 |
|---|---|
| 中文名称 | 指数均线；指数移动平均 |
| 英文名称 | Exponential Moving Average |
| 常用缩写 | EMA |
| 类型 | 趋势 / 滞后平滑（近端加权） |

EMA 与 [ma.md](./ma.md) 的 SMA 同属均线家族，算法不同。本库不把 EMA 简称成「MA」以免读者以为权重相同。

---

## 1. 它是什么

EMA 也是一条由历史价格平滑出来的线，但对**越近的价格给越高权重**，对较老的价格权重按指数衰减。因此同样 N 的 EMA，通常比 SMA 更贴近最近的收盘价，转向也往往更早出现——仍然滞后于价格本身。

EMA 被广泛用作 MACD 的原材料，也常单独当作趋势参照。

---

## 2. 它测量什么

测量**近端加权后的价格中枢**。它比 SMA 更强调「最近发生的事」，但仍是过去信息的压缩。

它回答的问题接近 SMA：

- 近期中枢往哪移？
- 现价在中枢哪一侧？
- 快慢 EMA 是否交叉？

它不回答谁在主动成交、仓位如何、费率是否拥挤。

---

## 3. 如何计算（教学级）

常用平滑系数：

> k = 2 / (N + 1)

递推：

> EMA_t = C_t × k + EMA_{t-1} × (1 − k)

其中 C_t 为当日（或当根）收盘价。

启动方式常见两种，课文必须声明软件用哪一种：

1. **用前 N 根 SMA 作第一个 EMA**，再开始递推（较多图表软件）。
2. 从第一根价格直接当 EMA 种子（早期数值不稳定）。

因为递推依赖整段历史，**同一 N 的 EMA 在不同起始日期上会略有差别**，样本越长差别通常越小。这是复现指标时的常见坑。

与 SMA 对比（直觉）：

- SMA：窗口内每根权重 1/N，出窗口立刻变成 0。
- EMA：最近一根权重 k，再往前每根乘 (1−k)，理论上旧值影响逐渐变小但不突然归零。

N = 20 时，k = 2/21 ≈ 0.0952，最新收盘约占 9.5% 权重。

---

## 4. 如何观察

观察维度与 SMA 相同，解释时多强调「反应更快」：

1. 斜率与走平。
2. 价格在 EMA 上方 / 下方运行的持续性。
3. **快慢 EMA 交叉**（如 12 与 26，正是 MACD 的两条线）。金叉死叉同样滞后，同样不是指令。
4. 价格击穿 EMA 后是收盘站回，还是继续离开。教学看**收盘**，不看影线扫到。
5. 与同参数 SMA 画在一起：EMA 更贴价格，SMA 更钝。两者分开过大时，说明最近一段涨跌很急。

短 EMA（如 8、12）在永续的低周期图上会非常敏感，几乎跟着价格蛇形，趋势过滤作用变弱。

---

## 5. 常见参数

| N | 常见场景 |
|---|---|
| 8 / 9 / 12 | 短趋势、MACD 快线相关 |
| 21 / 26 | 短中；26 为 MACD 慢线常用 |
| 50 / 55 | 中期趋势参照 |
| 100 / 200 | 更长趋势；与 SMA200 常被拿来对比 |

MACD 默认 12 / 26 / 9 都是 EMA。改 EMA 参数等于改 MACD 性格。

必须同时写图表周期与价格源（默认 Close）。

---

## 6. 典型形态

| 形态 | 观察 | 限制 |
|---|---|---|
| 价格沿 EMA 阶梯上移或下移 | 回撤浅、收盘多次回到线附近再离开 | 一次深刺破就能打断「阶梯」叙事 |
| EMA 金叉 / 死叉 | 快线穿越慢线 | 震荡中频繁出现 |
| EMA 束发散 | 短中长 EMA 拉开距离 | 已是趋势中后段的常见画面 |
| EMA 束粘合 | 波动收缩、方向不清 | 其后扩张方向事先不知道 |
| EMA 领先于同 N 的 SMA 转向 | 近端加权生效 | 领先幅度有限，且假转更多 |

---

## 7. 何时有用

- 希望均线比 SMA 更快承认最近的加速或减速。
- 趋势跟踪里用 EMA 做动态参照，规则写清「收盘在哪一侧」。
- 作为 MACD、部分通道与交叉系统的组件。
- 对比 SMA，讲解「权重分配如何改变滞后」。

---

## 8. 何时失效

- 震荡与锯齿行情：更快意味着更多来回穿越。
- 一次性插针：近端权重大，EMA 会被单根异常收盘拽走，随后再拽回来。
- 历史起点不同导致数值对不上，学习者误以为公式错了。
- 周期过短：EMA 几乎贴着收盘价，失去「中枢」意义。
- 把「更灵敏」理解成「更准确」：灵敏与稳定是权衡，不是升级。

---

## 9. 常见误区

1. 以为 EMA 能消除滞后。它只是减少部分滞后，代价是更多噪声。
2. 把 12/26 交叉直接叫 MACD 金叉而不看柱状图与信号线——相关但不相同。
3. 混用交易所 App 里未标明算法的「MA」。
4. 用未收盘价宣称 EMA 已转向。
5. 认为价格每次都会在 EMA 上获得支撑。
6. 为了让交叉更好看而不断改 N，造成拟合历史。

---

## 10. 可与哪些指标组合

| 组合 | 观察目的 |
|---|---|
| EMA + SMA | 算法对比，防止混名 |
| EMA + MACD | MACD 就是 EMA 差；对照价格与柱状图 |
| EMA + Volume | 转向或交叉时量能是否同步 |
| EMA + RSI | 趋势侧 + 动量极端区 / 背离 |
| EMA + 布林带 | 有人用 EMA 作中轨变体；须声明，本库布林带默认 SMA |
| EMA + OI / Funding | 均线方向与仓位、拥挤是否同向 |

课程上建议：先教 SMA，再教 EMA，再教 MACD，三者共用「均线差与滞后」这条主线。
