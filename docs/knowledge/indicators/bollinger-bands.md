# 布林带（Bollinger Bands，BB）

| 项目 | 内容 |
|---|---|
| 中文名称 | 布林带；布林通道 |
| 英文名称 | Bollinger Bands |
| 常用缩写 | BB、BOLL |
| 类型 | 波动率通道（中轨为均线） |

布林带由 John Bollinger 提出。它把「均线中枢」和「价格离散程度」画在同一张主图上。

---

## 1. 它是什么

布林带由三条线组成：

- **中轨**：通常是 N 期简单移动平均（SMA）
- **上轨**：中轨 + k 倍标准差
- **下轨**：中轨 − k 倍标准差

价格进入上轨附近或下轨附近，只说明相对最近 N 根，它处在统计上较远的位置。这不是「到上轨就该卖、到下轨就该买」。

本库中轨默认 **SMA**，与 [ma.md](./ma.md) 一致。若软件用 EMA 作中轨，必须当作变体声明。

---

## 2. 它测量什么

同时测量两件事：

1. **中枢位置**（均线）
2. **波动率**（标准差，即价格相对中枢的离散）

派生读数（可选）：

- **带宽（Bandwidth）**：(上轨 − 下轨) / 中轨
- **%B**：价格在上下轨之间的相对位置，(Price − 下轨) / (上轨 − 下轨)

它不测量方向的对错，也不测量成交与持仓。带宽变窄只说明最近波动小，不说明即将往哪边扩大。

与 [atr.md](./atr.md) 对照：**ATR 是尺子**（一根宽度数字），**布林带是通道**（均线加减若干倍标准差）。需要判断「这根算不算普通噪声、止损要留多宽」时用 ATR；需要看收口、走轨、价格相对中枢的位置时用布林带。不要把两套画成同一个开仓系统。先修建议先读 ATR，再读本篇。

---

## 3. 如何计算（教学级）

默认常用 N = 20，k = 2，价格源 Close。

> 中轨_t = SMA(Close, N)
>
> σ_t = 过去 N 根收盘价的标准差
>
> 上轨_t = 中轨_t + k × σ_t
>
> 下轨_t = 中轨_t − k × σ_t

标准差教学说明：

- 先算各收盘与中轨的差，平方，再平均，再开方。
- 软件可能用总体标准差（除以 N）或样本标准差（除以 N−1）。两条轨道宽度会略有差别。写复现时要注明。本库教学用「窗口内离散程度」，不要求读者手算到第几位。

约 2 倍标准差的直观（若收益近似钟形，仅作数量级直觉，行情不满足正态）：多数收盘会落在上下轨之间，少数会触及或刺破轨道。刺破并不罕见，尤其在趋势加速时。

---

## 4. 如何观察

1. **带宽**：变窄是波动收缩（有时称收口、挤压 Squeeze）；变宽是波动扩张。收口之后常有较大波动，但**方向事先未知**，也不是每次收口都会大波动。
2. **价格与轨道**：触及或刺破上轨 / 下轨，表示相对中枢的延伸。趋势里价格可以沿上轨或下轨「走轨道（walking the band）」。
3. **中轨**：当作 20 期均线来看斜率与穿越。价格回到中轨，可能是回归，也可能是中继，也可能是反向的开始。
4. **%B**：大于 1 表示收盘在上轨之上；小于 0 表示在下轨之下。同样不是买卖指令。
5. **与 K 线配合**：看收盘相对轨道，而不是影线扫到上轨就算「冲带」。

---

## 5. 常见参数

| 参数 | 常见值 | 说明 |
|---|---|---|
| N | 20 | Bollinger 常用默认 |
| k | 2 | 默认带宽 |
| k | 1.5 / 2.5 / 3 | 更窄或更宽，触及频率改变 |
| 中轨算法 | SMA | 本库默认 |
| 价格源 | Close | 也有人用典型价，须声明 |

改 N 同时改变中枢速度和波动样本。没有「更准」的带宽，只有「触及更频繁或更稀少」。

---

## 6. 典型形态

| 形态 | 观察 | 限制 |
|---|---|---|
| 收口 / 挤压 | 带宽明显变窄 | 随后扩张方向不明，也可能假扩张 |
| 开口 / 扩张 | 带宽迅速变宽 | 常已伴随一段急涨或急跌 |
| 走轨道 | 连续多根收盘贴近上轨或下轨 | 回归交易在此环境容易逆向 |
| 刺破后收回带内 | 一次延伸后回到轨道之间 | 也可能再次刺破并延续 |
| 中轨走平、价格上下碰轨 | 震荡画面 | 轨道会被新波动改写，边界会移动 |
| 上轨下移 / 下轨上移 | 波动下降或价格回归 | 单独看一轨容易误读 |

---

## 7. 何时有用

- 需要同时看到「均线」和「最近波动有多大」。
- 比较当前波幅是否异常（相对自己的 20 根历史）。
- 趋势教学：展示价格如何贴着轨道运行，打破「碰轨就反」的直觉。
- 震荡教学：展示价格在移动通道里来回，但通道本身会变形。

---

## 8. 何时失效

- **把轨道当固定支撑阻力**：轨道每根都在重算，会跟着价格走。
- **强趋势走轨道**：下轨买入或上轨卖出会反复做错方向。
- **突然插针**：标准差被单根放大，轨道瞬间撑开，随后再收，形态难看且滞后。
- **低波动长时间收口**：学习者以为「马上突破」而过早加杠杆。收口可以维持很久。
- **跨品种比较带宽绝对值**：价格量级不同，应看相对带宽。

---

## 9. 常见误区

1. 上轨超买、下轨超卖，到轨就反向。
2. 收口之后向上突破「更常见」——方向没有这种知识库级结论。
3. 以为 2 倍标准差意味着只有 5% 时间触轨，因而触轨很稀有。行情不服从简单正态，触轨并不稀有。
4. 把布林带当成独立于均线的「另一套系统」——中轨就是均线。
5. 用未收盘价让轨道跟着影线跳舞。
6. 叠加很多组 (N, k) 直到某段历史看起来「刚好碰到点」。

---

## 10. 可与哪些指标组合

| 组合 | 观察目的 |
|---|---|
| 布林带 + MA / EMA | 中轨之外再加更长趋势均线，区分大方向 |
| 布林带 + RSI / KDJ | 触轨时动量是否也在极端区 |
| 布林带 + MACD | 开口时动量差是否同步放大 |
| 布林带 + Volume | 开口或刺破是否放量 |
| 布林带 + ATR | 通道 vs 尺子：收口走轨看通道，噪声宽度看 ATR |
| 布林带 + OI | 波动扩张时仓位增减 |

课程「趋势 + 动量」里，布林带负责提供波动环境，不负责给方向。

## 教学备注（给 Content Agent）

- 先复习 SMA，再叠加 ±2σ，不要一上来讲策略。
- 必须有「走轨道」反例，否则读者会把碰轨当反向信号。
- 示意图标明「示意图」；真实行情图写满数据出处。
