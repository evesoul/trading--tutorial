# 清算瀑布怎么读图（Liquidation Cascade）

| 项目 | 内容 |
|---|---|
| 中文名称 | 清算瀑布；强平连锁 |
| 英文名称 | Liquidation Cascade |
| 常用别称 | 连环强平、清算瀑布 |
| 类型 | 永续机制事件（不是振荡指标） |

本文回答：强平连锁时，图上哪些数暂时不可信。它不是方向指标，也没有 70/30。

先修概念：成交量、持仓量、CVD。机制背景见 [perpetual-futures.md](../perpetual-futures.md)。本文件不教如何「抄瀑布底」，不教如何预测瀑布结束。

---

## 1. 它是什么

**清算瀑布（Liquidation Cascade）**是一连串强平单在短时间内互相催发的过程。

教学链条：

1. 一批仓位触及维持保证金，交易所按规则强制减仓或平仓。
2. **强平单通常是被动市价（taker）**，打进当时的订单簿。
3. 簿薄时，市价会连续吃掉多档，K 线上留下**插针**（长影或跳价）。
4. 这一跳让下一批仓位的保证金也不够，再触发强平，形成连锁。

瀑布是**保证金事件在薄盘上的成交痕迹**，不是形态交易系统，也不是「主力选择了方向」。

---

## 2. 它测量什么

它不测量涨跌方向。它描述的是：**强平冲击有没有在改写盘口和公开数据。**

它回答：

- 这一段急跌或急涨，是否更像强平扫货，而不是普通转手？
- 此时成交量、OI、CVD、多空比还能不能拿来解释方向？

教学默认：

> 瀑布进行中，成交量、持仓量、CVD、多空比都可能同时失真，**暂时不可解释方向**。

它不回答：

- 瀑布会在哪一价结束
- 长下影是不是底部
- 该不该反向开仓

---

## 3. 如何计算（教学级）

没有 RSI 那种回看公式。学习者通常读交易所或数据商的**强平记录 / 强平热力图**，再对照价格与盘口，而不是自己算一条「瀑布指标」。

概念上只需记住成交路径：

1. 强平以市价进入订单簿（见 [order-types.md](../order-types.md) 的市价与薄盘止损）。
2. 对手挂单被吃掉，最新价跳变；标记价会跟，但不必同步。
3. 下一档维持保证金被打穿，重复步骤 1。

可对照的公开痕迹（都可能滞后或口径不一）：

- 价格：数根内走出远大于近期 ATR 的影线或缺口
- 成交量：单根远高于两侧
- OI：短时间明显下降（仓位被关掉）
- 强平数量：连续出现、同一方向堆积

跨所强平数字不能直接加总。本库只要求：写案例时注明来源，不要把单一热力图当成全市场真相。

---

## 4. 如何观察

1. **先看价格冲击**：盘口一跳数个点（或短时间走出远超近期普通波幅），同时出现长影或缺口。
2. **再看是否连续强平**：不是单笔强平，而是短时间一波接一波。
3. **同时核对四条曲线**：Volume 巨量、OI 急变、CVD 单边直插、多空比跳变——任一已经可疑；几条一起剧烈抖动，按教学默认记「数据不可用」。
4. **不要在此时写方向句**：不写「主力出货」「抄底」「空头胜利」。先记「瀑布进行中」或「刚结束、数据仍脏」。
5. **等盘口重新连续、强平不再成串**，再恢复用 Volume / OI / CVD 做普通观察。恢复可读，不等于可以预测下一波。

教学禁止条件（给系统课用的边界，不是盘中喊单）：

- 连续强平
- 盘口一跳数个点（相对该品种近期普通价差）

上述条件下，教学默认：**空仓或只平不开**；这些数暂时不可解释方向。

---

## 5. 常见参数

瀑布本身没有 14、20。观察时必须声明：

| 项目 | 须写明 |
|---|---|
| 数据来源 | 哪一家所的强平 / 成交 / OI |
| 图表周期 | 1m 插针在 4H 上可能只是一根影线 |
| 对照尺子 | 近期 ATR 或近期均量，用来判断「偏大」 |
| 时间窗 | 连续强平看的是几分钟还是几根 K |

没有「瀑布阈值」。不要自造「强平超过某张数即瀑布」的全站标准。

---

## 6. 典型形态

| 形态 | 观察 | 限制 |
|---|---|---|
| 插针长影 | 市价扫过薄盘后部分收回 | 收回不等于底部或顶部完成 |
| 跳价缺口 | 盘口一跳数个点 | 中间价位可能从未被稳定报价 |
| 巨量柱 | 转手暴增 | 可能主要是连锁平仓，不是新开仓共识 |
| OI 急降 | 未平仓被关掉 | 也可能夹杂普通平仓，口径会滞后 |
| CVD 直插 | 主动卖或主动买单边堆积 | 强平 taker 会扭曲 Delta，见 [cvd.md](./cvd.md) |
| 多空比跳变 | 某口径账户或仓位被削掉 | 口径不同，不能当成全市场真相 |
| 数条同时抖动 | 量 / OI / CVD / 多空比一起失真 | 教学上记数据不可用，不写方向 |

---

## 7. 何时有用

- 教读者识别：哪些时段公开数据不宜拿来讲方向。
- 给 Volume / OI / CVD / 多空比立失效边界，避免把连锁平仓读成「主力」。
- 为风险管理提供禁止条件：连续强平、盘口跳价时不解释、不开新方向。
- 解释永续与现货的差别：现货没有这套强平连锁，合约图上的长影经常含保证金事件。

---

## 8. 何时失效

- **当底部 / 顶部形态用**：长下影或长上影在瀑布里首先是扫货痕迹。
- **用来预测结束**：没有知识库级的「瀑布结束公式」。
- **抄瀑布底 / 摸瀑布顶**：薄盘市价的滑点可以远大于你在图上看到的收盘。
- **把单笔强平当成瀑布**：个别强平是日常机制，不等于连锁。
- **跨所热力图直接加总**。
- **瀑布刚过就立刻恢复用 CVD 讲主力**：失真可以持续一段时间。

---

## 9. 常见误区

1. 把瀑布长下影写成锤子线底部。
2. 把 CVD 急跌写成主力出货，把急升写成主力吸筹。
3. 把巨量当成「有人在这个价大量建仓」。
4. 试图抄瀑布底，或预测「再扫一次就结束」。
5. 用 4 小时收盘形态解释 1 分钟里已经发生的连锁强平。
6. 认为标记价插针和最新价插针是同一件事——强平看标记价，K 线看最新价。
7. 把禁止条件写成「出现瀑布后反向开仓更划算」。

---

## 10. 可与哪些指标组合

这里的「组合」是**一起失效**，不是共振开仓。

| 组合 | 观察目的 | 注意 |
|---|---|---|
| 瀑布 + Volume | 巨量是否发生在连续强平时段 | 见 [volume.md](./volume.md) |
| 瀑布 + OI | 未平仓是否在被关掉 | 滞后与口径 |
| 瀑布 + CVD | Delta 是否被强平 taker 扭曲 | 见 [cvd.md](./cvd.md) |
| 瀑布 + 多空比 | 某口径是否被削掉一边 | 必须写口径 |
| 瀑布 + ATR | 这一跳是否远超近期尺子 | ATR 随后也会被抬高 |
| 瀑布 + 资金费 | 结算时刻与强平重叠时因果难分 | 不要单归因 |

禁止把「量 + OI + CVD 同时剧烈变动」写成方向确认。教学上这是数据不可用的标志。
