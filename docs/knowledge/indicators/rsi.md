# 相对强弱指标（Relative Strength Index，RSI）

| 项目 | 内容 |
|---|---|
| 中文名称 | 相对强弱指标 |
| 英文名称 | Relative Strength Index |
| 常用缩写 | RSI |
| 类型 | 动量振荡器 |

本文合并并补全原草稿内容。规范文件名为 `rsi.md`（macOS 等大小写不敏感文件系统上，与历史文件名 `RSI.md` 为同一路径，故不再另留指针文件）。

---

## 1. 它是什么

RSI 由 J. Welles Wilder 提出，用来观察**一段时间内价格上涨力度相对下跌力度**的强弱，并把结果映射到大约 0 到 100 的区间。

它是动量指标，不是趋势线，也不是成交量指标。数值高表示窗口内上涨幅度相对占优，数值低表示下跌幅度相对占优。数值高或低都不等于价格马上反向。

核心用途（继承原草稿并收紧表述）：RSI 用于观察一段时间内价格上涨和下跌动能的相对强弱。

---

## 2. 它测量什么

测量窗口内**平均上涨幅度与平均下跌幅度的比值**，再做成有界振荡。

它回答：

- 最近 N 根里，涨的那部分和跌的那部分谁更大？
- 这种相对强弱是在增强还是在减弱？
- 价格创新高 / 新低时，相对强弱有没有同步？

它不测量：趋势的绝对方向（价格可在 RSI 高位继续涨）、仓位、主动成交、资金费。

「相对」是相对自己窗口内的涨跌，不是相对另一个币种的强弱。跨品种比较要用其他方法，且口径要单独定义。

---

## 3. 如何计算（教学级）

默认价格源为收盘价，默认 N = 14。

对每根已收盘 K 线计算变化：

> 变化 = Close_t − Close_{t-1}
>
> 涨幅 = max(变化, 0)
>
> 跌幅 = max(−变化, 0)

**第一步（前 N 根）**：

> 平均涨幅 = 窗口内涨幅之和 / N
>
> 平均跌幅 = 窗口内跌幅之和 / N

**之后用 Wilder 平滑**（不是再做普通 SMA）：

> 平均涨幅_t = (平均涨幅_{t-1} × (N − 1) + 当前涨幅) / N
>
> 平均跌幅_t = (平均跌幅_{t-1} × (N − 1) + 当前跌幅) / N

**相对强度与 RSI**：

> RS = 平均涨幅 / 平均跌幅
>
> RSI = 100 − 100 / (1 + RS)

特例：平均跌幅为 0 时，RSI 视为 100；平均涨幅为 0 且平均跌幅 > 0 时，RSI 为 0。

部分软件用 SMA 或 EMA 平滑，数值会与 Wilder 原法不同。教学与复盘必须写明算法。本库默认 **Wilder RSI**。

## 4. 如何观察

1. **读数位置**：传统技术分析常见把 70 附近看作超买区、30 附近看作超卖区。这是分区习惯，不是开关。
2. **中轴 50**：RSI 在 50 上方，窗口内平均涨幅占优；下方则跌幅占优。可当作粗略的动量方向，仍滞后。
3. **停留时间**：强趋势里，RSI 可以长时间留在高位或低位。这是原草稿已强调、必须保留的要点。
4. **背离**：价格创新高而 RSI 未创新高，称潜在顶背离；价格创新低而 RSI 未创新低，称潜在底背离。背离不是确定性的反转信号。
5. **形态**：RSI 自己的突破、失败摆动（failure swing）等，都属于指标内部结构，需要与价格结构对照，不能单独下指令。
6. **看已收盘**：未收盘 RSI 会随最新价晃动。

超买不代表价格即将下跌，超卖不代表价格即将上涨。

---

## 5. 常见参数

| 项目 | 常见选择 | 说明 |
|---|---|---|
| N | 14 | Wilder 默认；本库教学默认 |
| N | 7 / 9 | 更敏感，进出极端区更频繁 |
| N | 21 | 更平滑 |
| 极端区 | 70 / 30 | 传统分区 |
| 极端区 | 80 / 20 | 强趋势里减少「过早喊反转」的误读，仍不是安全区 |

参数不是固定规则。改 N 会改变 RSI 进入 70/30 的频率，不存在一组「更准确」的参数。

---

## 6. 典型形态

| 形态 | 观察 | 限制 |
|---|---|---|
| 进入 70 以上后回到 70 下 | 高位动量开始回落的画面 | 也可能再次冲上 70 并续涨 |
| 进入 30 以下后回到 30 上 | 低位动量开始回升的画面 | 也可能再次跌回并续跌 |
| 高位钝化 | 价格续创新高，RSI 在高位走平或略降 | 常被误认为顶部已现 |
| 低位钝化 | 对称 | 常被误认为底部已现 |
| 顶背离 / 底背离 | 价格与 RSI 高低点不同步 | 趋势中可反复出现 |
| 50 轴来回穿越 | 动量方向不稳定 | 震荡或转换期常见 |

原草稿中的优势（简单、直观、适合观察动量、可辅助识别震荡区间）在震荡市更明显：RSI 来回摆动的可读性通常好于单边趋势。

---

## 7. 何时有用

- 需要一条有界、好读的动量尺，对照价格是否「涨得吃力」或「跌得吃力」。
- 震荡区间里，观察 RSI 是否在高低区来回摆动（辅助识别区间，不是区间交易信号）。
- 与趋势工具合用：先判断大方向，再解释 RSI 读数，减少把趋势中的超当反转。
- 讲解背离概念时，RSI 比无界指标更容易画高低点。

---

## 8. 何时失效

- **强趋势**：超买或超卖可以持续，不能仅靠 RSI 判断买卖。这是原草稿已写的核心局限，必须保留。
- **突然单根巨幅**：Wilder 平滑会把冲击带很久，也会在随后若干根里显得「钝」。
- **周期过短**：14 周期 RSI 在 1 分钟图上噪声大。
- **算法不一致**：Wilder 与 SMA-RSI 混用导致「同一时刻不同读数」。
- **只看 70/30 水平线**：忽略价格结构与趋势。

---

## 9. 常见误区

1. 超买 = 卖出，超卖 = 买入。
2. 背离 = 反转已确认。
3. 认为 RSI 能预测下一根涨跌。
4. 把 RSI 的「相对强弱」理解成两个币的强弱排名。
5. 用未收盘 RSI 做规则判定。
6. 同时改 N 和极端区去拟合某段行情。
7. 忽略：RSI 只使用价格，不含量和仓。

---

## 10. 可与哪些指标组合

原草稿推荐与 EMA、MACD、Volume、OI 结合。本库展开如下：

| 组合 | 观察目的 |
|---|---|
| RSI + EMA / MA | 趋势过滤：例如仅在均线方向上解释 RSI 回踩 |
| RSI + MACD | 有界动量 vs 均线差动量，看是否同向或是否同时背离 |
| RSI + Volume | 动量回升或回落时量能是否配合 |
| RSI + OI | 动量转折画面里仓位是在增加还是在回补 |
| RSI + 布林带 | 价格触及轨道时 RSI 是否也在极端区 |
| RSI + KDJ | 两个振荡器；KDJ 通常更敏感，共振仍不是指令 |

「RSI + MACD」是课程第二部分的明确组合：只核对动量是否同向，不写成双重确认即可下单。
