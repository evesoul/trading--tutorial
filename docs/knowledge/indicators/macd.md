# 平滑异同移动平均线（MACD）

| 项目 | 内容 |
|---|---|
| 中文名称 | 平滑异同移动平均线 |
| 英文名称 | Moving Average Convergence Divergence |
| 常用缩写 | MACD |
| 类型 | 趋势跟随 + 动量（由均线差派生） |

MACD 建立在 [ema.md](./ema.md) 上。没讲清 EMA，不宜直接教 MACD。

---

## 1. 它是什么

MACD 用两条不同速度的指数均线之差，描述价格动量如何随快慢均线的聚拢（Convergence）和分开（Divergence）而变化。图上通常有三部分：

1. **MACD 线（DIF / MACD line）**：快 EMA 减慢 EMA
2. **信号线（DEA / Signal line）**：MACD 线再做一条更短的 EMA
3. **柱状图（Histogram）**：MACD 线减信号线

它把「两条均线离多远、这个距离本身在不在扩大」画成振荡器，零轴上下都可以看。

---

## 2. 它测量什么

测量**快慢趋势之间的差距及其变化速度**。

- MACD 线离零轴远：快慢 EMA 分开较多，近期涨跌力度相对较大（相对所选参数而言）。
- MACD 线向零轴靠：快慢均线聚拢，近期力度在减弱或方向在切换。
- 柱状图缩短：MACD 线与信号线靠近，动量增量变小。

它不测量超买超卖的固定价格区间（不像 RSI 有 0–100 边界），也不测量成交与持仓。

---

## 3. 如何计算（教学级）

默认常用参数 12、26、9，价格源为收盘价：

> MACD 线 = EMA(Close, 12) − EMA(Close, 26)
>
> 信号线 = EMA(MACD 线, 9)
>
> 柱状图 = MACD 线 − 信号线

步骤：

1. 先算 12 期与 26 期 EMA（注意 EMA 种子与历史长度）。
2. 两者相减得到 MACD 线。快线在慢线上方时，MACD 为正。
3. 对 MACD 线再算 9 期 EMA，得到信号线。
4. 两者再减，得到柱状图。柱状图由负转正，对应 MACD 线上穿信号线。

部分国内软件把 MACD 线叫 DIF、信号线叫 DEA，柱状图叫 MACD。本库正文用「MACD 线 / 信号线 / 柱状图」，首次出现时括号注明 DIF / DEA。

缩放：有的软件把差值再乘 2 画柱。比的是形态和交叉，不是跨平台的绝对柱高。

---

## 4. 如何观察

1. **零轴**：MACD 线在零轴上方，表示 12 EMA 高于 26 EMA；下方则相反。零轴是均线排列的另一种画法。
2. **交叉**：MACD 线上穿信号线（金叉）、下穿（死叉）。发生在零轴上方或下方，上下文不同；交叉本身仍滞后，仍不是指令。
3. **柱状图伸缩**：柱子变长表示差价扩大，变短表示差价收窄。柱状图换色只是软件习惯。
4. **背离**：价格创新高而 MACD 线或柱状图未创新高（顶背离）；价格创新低而指标未创新低（底背离）。背离是不同步现象，不是反转已被确认。趋势中可多次背离而价格继续走。
5. **与价格同图对照**：只看副图交叉、不看价格结构，容易在震荡里反复操作。

---

## 5. 常见参数

| 参数组 | 含义 |
|---|---|
| 12, 26, 9 | 最常见默认值，来自传统日线习惯 |
| 更短，如 6, 13, 5 | 更敏感，交叉更多 |
| 更长，如 19, 39, 9 | 更钝，交叉更少 |

改参数就是改「快、慢、再平滑」三重滞后。没有一组参数适用于所有图表周期。把日线默认值直接搬到 5 分钟永续上，性格会变得非常吵。

EMA 的历史起点会影响早期 MACD，样本要足够长再读交叉。

---

## 6. 典型形态

| 形态 | 观察 | 限制 |
|---|---|---|
| 零轴上方金叉 | 快慢均线已多头，且 MACD 线重新上穿信号线 | 二次推动常见，失败也常见 |
| 零轴下方死叉 | 对称的空头语境 | 同上 |
| 柱状图缩短后再次拉长 | 回调后力度再增强的画面 | 缩短后也可以直接穿零轴 |
| 顶 / 底背离 | 价格与 MACD 高低点不一致 | 可长时间无效 |
| 零轴粘着 | 快慢 EMA 缠绕 | 趋势工具失效区 |
| 柱状图与价格同步新高 | 动量与价格同向延伸 | 不保证还能延伸多久 |

---

## 7. 何时有用

- 趋势已经展开，需要看力度是在加大还是在减弱。
- 用零轴过滤：只在零轴一侧解读交叉，减少逆大方向的短线交叉（过滤，不是正确性保证）。
- 与价格结构一起看背离，作为「动量可能不再创新高」的提醒。
- 讲解均线差时，比同时看两条 EMA 更省视线。

---

## 8. 何时失效

- **震荡市**：零轴附近频繁交叉，柱状图正负快速切换。
- **单边加速**：背离出现后价格仍可走很远，过早解读为顶部或底部。
- **低周期 + 默认参数**：噪声被当成动量转折。
- **不同软件柱状图缩放不同**：不能跨平台比绝对数值。
- **用未收盘 EMA 计算**：交叉会闪烁。

MACD 从均线派生，均线失效的环境，MACD 通常一起失效。

---

## 9. 常见误区

1. 把金叉死叉写成买卖点。
2. 认为背离出现后价格将转向。
3. 把 MACD 当成有 70/30 的超买超卖尺。它没有固定上下界。
4. 只看柱状图颜色，不看零轴位置。
5. 以为 MACD「比均线更先进所以更准」——信息源仍是价格。
6. 用极短参数拟合某段历史的完美交叉。
7. 忽略手续费：低周期交叉频繁时，成本会吃掉规则里纸面优势。

---

## 10. 可与哪些指标组合

| 组合 | 观察目的 |
|---|---|
| MACD + EMA | 回到原材料，核对零轴就是 12 与 26 的位置关系 |
| MACD + RSI | 两类动量：一个无界差价，一个 0–100 相对强弱 |
| MACD + MA（更长） | 大趋势过滤 + 中期动量 |
| MACD + Volume | 柱状图放大时是否有量 |
| MACD + 布林带 | 动量变化是否发生在波动扩张段 |
| MACD + OI | 动量方向与开平仓是否同向 |

本课程「趋势 + 动量」「RSI + MACD」都依赖：交叉与背离必须写成观察，并配失效环境。

## 术语对照

| 中文 | 英文 / 国内软件 |
|---|---|
| MACD 线 | MACD line / DIF |
| 信号线 | Signal line / DEA |
| 柱状图 | Histogram |
| 零轴 | Zero line |
| 聚合 / 发散 | Convergence / Divergence |
| 背离 | Divergence（价格与指标） |

注意：指标名字里的 Divergence 指快慢均线分开；「顶背离」里的背离指价格与指标不同步。课文首次要拆开，避免一词两义。

## 教学备注（给 Content Agent）

- 先画 12/26 EMA，再画它们的差，最后才出柱状图。
- 必须有震荡市频繁交叉的反例，以及趋势里背离后价格续走的反例。
- 统一用「MACD 线 / 信号线」，括号给 DIF/DEA。
