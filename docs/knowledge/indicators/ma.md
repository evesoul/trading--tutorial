# 均线（Moving Average，MA / SMA）

| 项目 | 内容 |
|---|---|
| 中文名称 | 均线；简单移动平均 |
| 英文名称 | Moving Average；Simple Moving Average |
| 常用缩写 | MA、SMA |
| 类型 | 趋势 / 滞后平滑 |

本库单独写「均线」或「MA」时，**默认指简单移动平均（SMA）**。指数均线见 [ema.md](./ema.md)，不要把两种算法写成同一个东西。

---

## 1. 它是什么

均线把最近 N 根价格（教学默认用收盘价）加以平均，再把每个时点的平均值连成线。它是一条**滞后的参照线**：用来看价格相对近期中枢偏高还是偏低，以及这条中枢本身是否在抬升或下移。

均线不是未来价格的预测线，也不是自动支撑阻力。

---

## 2. 它测量什么

测量**过去 N 根价格的算术中枢及其随时间的移动**。

间接触及：

- 方向：均线斜率向上 / 向下 / 走平
- 位置：现价在均线上方还是下方
- 距离：现价偏离中枢多远（偏离大可能是延伸，也可能是即将回归，两者都要保留）

不测量：成交是否主动、仓位增减、资金费、波动率的上下边界（那是布林带等工具）。

---

## 3. 如何计算（教学级）

对已收盘的收盘价序列 \(C_t\)，回看参数为 N：

> SMA_t = (C_t + C_{t-1} + … + C_{t-N+1}) / N

每形成一个新收盘：

1. 加入最新收盘价
2. 丢掉最老的那一根
3. 再除以 N

因此 SMA 对 N 根里的每一根权重相同。一根很老的尖峰从窗口里滑出时，均线会突然「掉一截」，即使最新价格没怎么动。这是 SMA 的特征，不是错误。

教学计算只用已收盘价。把当前未收盘价当收盘，会让均线跟着盘中抖动，回测不可复现。

---

## 4. 如何观察

1. **斜率**：上倾、下倾、走平。走平常与震荡或方向不明确同时出现。
2. **价格在均线哪一侧**：持续在上或在下，是趋势环境的常见画面，不是「站上就只会涨」。
3. **交叉**：短周期均线上穿长周期均线称**金叉（Golden Cross）**，下穿称**死叉（Death Cross）**。交叉是滞后现象：快线已经带着过去一段涨跌走完，才在图上交叉。金叉不代表此后只涨，死叉不代表此后只跌。
4. **距离**：价格远离均线后，后市可能继续远离，也可能回到均线附近。把回归当成交易计划，需要另写规则，且接受失败。
5. **均线束**：多条不同 N 的均线发散或缠绕，用来辅助判断趋势是否展开或收束。

先看大周期均线的方向，再看小周期均线的交叉，比单看交叉更不容易自相矛盾。

---

## 5. 常见参数

没有官方「正确 N」。常见教学取值：

| 参数 N | 常见称呼 | 粗略用途（教学） |
|---|---|---|
| 5 / 10 | 短均线 | 观察最近数根的中枢 |
| 20 / 21 | 中短 | 与布林带中轨常用 20 对齐 |
| 50 | 中期 | 日线或 4 小时上较常见 |
| 100 / 200 | 长均线 | 观察更长趋势；200 日均线在传统股市讨论多 |

同一 N 在 5 分钟图和日线图上覆盖的真实时间完全不同。写参数必须同时写图表周期。

价格源除收盘外，也可以用典型价 (H+L+C)/3 等，课文需标明。本库默认 Close。

---

## 6. 典型形态

| 形态 | 观察 | 限制 |
|---|---|---|
| 多头排列 | 短、中、长均线从上到下依次排开且上倾 | 排列出现时，一段涨幅往往已经发生 |
| 空头排列 | 短、中、长均线从上到下反向排开且下倾 | 同上，滞后 |
| 金叉 / 死叉 | 快线上穿 / 下穿慢线 | 震荡市会反复交叉，形成来回损耗 |
| 均线走平缠绕 | 多条均线纠结 | 趋势工具不擅长的环境 |
| 价格回踩均线后离开 | 回踩后继续沿原斜率运动 | 也常见跌破后变反向 |
| 远离后回归 | 价格回到均线附近 | 趋势延伸时「该回归却不回」 |

这些是画面分类，不是信号列表。

---

## 7. 何时有用

- 需要一条简单、可复述的趋势参照时。
- 趋势段较长、回撤相对规则时，均线斜率与多空排列比较好读。
- 用来过滤：例如只在长均线上方讨论做多观察，减少逆大方向解读短线抖动（这是过滤，不是保证正确）。
- 作为其他指标的零件：布林带中轨、部分通道规则。

---

## 8. 何时失效

- **震荡市**：价格围绕均线来回穿越，交叉频繁。
- **突发跳空或插针**：窗口内的旧极值突然进出，SMA 台阶式移动。
- **周期与参数错配**：用 200 周期均线做超短线，或用 5 周期均线判断月线结构。
- **高波动新闻时段**：均线来不及改方向，价格已大幅离开。
- **把均线当绝对支撑**：价格可以穿过任何均线。

均线是滞后指标。它擅长总结「已经走出来的方向」，不擅长预报转折点。

---

## 9. 常见误区

1. 把金叉死叉当成买卖指令。
2. 认为价格「必须」回到均线。
3. 同时画十几根均线，却没有一条承担明确问题。
4. 把 SMA 与 EMA 的交叉混在同一句话里而不加算法名。
5. 在未收盘时宣布「均线已金叉」。
6. 用均线距离当「超买超卖」却不承认趋势可延伸。
7. 忽略：均线本身由过去价格构成，它不能独立于价格提供新信息，只是压缩信息。

---

## 10. 可与哪些指标组合

| 组合 | 观察目的 |
|---|---|
| MA + EMA | 同一 N 下对比平滑程度与反应速度 |
| MA + Volume | 均线方向改变时是否有量能配合 |
| MA + RSI / MACD | 趋势过滤 + 动量是否同步 |
| MA + 布林带 | 中轨就是 SMA 时，带宽补上波动率 |
| MA + OI | 均线方向与仓位增减是否同向 |
| K 线 + MA | 收盘相对均线，而不是影线扫到均线就算「站上」 |

与 EMA 的分工：要讲解「每根权重相同、旧值滑出影响大」用 MA；要讲解「更新价权重大」用 EMA。
