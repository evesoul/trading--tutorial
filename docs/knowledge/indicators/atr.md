# 平均真实波幅（Average True Range，ATR）

| 项目 | 内容 |
|---|---|
| 中文名称 | 平均真实波幅 |
| 英文名称 | Average True Range |
| 常用缩写 | ATR |
| 类型 | 波动率尺子（不给方向） |

ATR 由 J. Welles Wilder 提出。它回答：**最近普通波动有多宽，这根算不算噪声。** 它不回答涨还是跌。

与 [bollinger-bands.md](./bollinger-bands.md) 的分工：**ATR 是尺子**（一根宽度），**布林带是通道**（均线加减若干倍标准差）。两套都可以观察波动，不要写成同一个指标。

本文件不写 ATR 突破开仓系统，不颁布止损或仓位的「标准倍数」。

---

## 1. 它是什么

**平均真实波幅（Average True Range，ATR）**是对最近 N 根**真实波幅（True Range，TR）**做平滑后的值。它测量近期高低波动的典型宽度，单位与价格相同（如 USDT），不是 0–100 的振荡器。

ATR 上升：最近的真实波幅在变宽。  
ATR 下降：最近的真实波幅在变窄。

宽窄说的是波动大小，不是方向。ATR 变大，多头和空头都可能同样难拿。

---

## 2. 它测量什么

测量**近期高低波幅的典型宽度**。

它回答：

- 最近 N 根里，普通的一天（或一根）大概能走出多远？
- 当前这根的高低差，相对这把尺子是偏小、普通，还是偏大？
- 波动变宽之后，同一笔风险金额还能撑多大的名义仓位？

它不测量：

- 涨跌方向
- 超买超卖
- 成交、持仓、资金费
- 「该不该追」——ATR 变大只说明更吵，不说明该加仓

同一 ATR 数值在不同品种、不同图表周期上不能直接比。BTC 1 小时的 ATR 和某山寨 1 分钟的 ATR 不是同一把尺。

---

## 3. 如何计算（教学级）

对每根已收盘 K 线，先算 **真实波幅（True Range，TR）**：

> TR = max( 高 − 低， |高 − 前收|， |低 − 前收| )

三项的含义：

- **高 − 低**：本根自己的振幅
- **|高 − 前收| / |低 − 前收|**：相对前收的跳空也被算进波幅，避免只看本根高低而漏掉缺口

教学级 ATR：对 TR 做平滑即可。常见两种，须声明：

1. **Wilder 平滑**（原法，与 RSI 同族）：前 N 根用 TR 的简单平均作种子，之后  
   `ATR_t = (ATR_{t-1} × (N − 1) + TR_t) / N`
2. **简单移动平均**：`ATR ≈ SMA(TR, N)`

两条曲线形状接近，数值会对不上。本库叙述默认 **Wilder ATR**，课文须写明软件用的是哪一种。

默认回看 **N = 14**，价格源为该周期的 OHLC。未收盘 K 线的 TR 会变，分析用已收盘。

不要在课文里给出跨软件通用到小数点的对账公式。

---

## 4. 如何观察

1. **绝对宽度**：ATR 本身是价格单位。先看「普通一根大概多宽」，再看具体影线。
2. **相对变化**：ATR 相对自己近期是在抬升还是回落，比跨品种比绝对数更有意义。
3. **这根是否超出普通噪声**：当前高低差（或相对前收的偏离）远大于 ATR，记「超出近期普通宽度」；接近或小于 ATR，更像普通噪声。超出不等于反转，也不等于突破成立。
4. **止损距离的尺子**：计划止损可以写成「结构位外侧，再留若干 ATR 的空间」，避免把止损钉在普通噪声里。若干是多少，由系统自己定义并回测，本库不给推荐倍数。
5. **仓位**：波动变宽时，若单笔允许亏损的金额不变，名义仓位按公式应变小。ATR 变大却仍按旧仓位开，等于在加风险。
6. **与布林带对照**：ATR 给一个宽度；布林带把宽度画成上下轨。收口 / 开口看通道，噪声尺子看 ATR。

---

## 5. 常见参数

| 参数 | 常见值 | 说明 |
|---|---|---|
| N | 14 | Wilder 常用默认 |
| N | 7 / 20 / 21 | 更敏感或更慢，须声明 |
| 平滑 | Wilder / SMA | 本库默认 Wilder |
| 图表周期 | 与决策周期相同 | 1 小时 ATR 不要直接拿去量 1 分钟噪声 |
| 是否含未收盘 | 分析用已收盘 | 盘中 ATR 会跟着影线变 |

没有「更准」的 N。N 越小，尺子跟得越紧、越吵；N 越大，越慢。

---

## 6. 典型形态

| 形态 | 观察 | 限制 |
|---|---|---|
| ATR 抬升 | 近期真实波幅变宽 | 不指示方向，也不等于该追 |
| ATR 回落 | 近期真实波幅变窄 | 不表示即将突破 |
| 单根远大于 ATR | 这根超出近期普通宽度 | 可能是新闻、强平、薄盘，也可能是趋势加速 |
| 单根远小于 ATR | 这根偏安静 | 可能是缩量，也可能只是窗口里的普通小根 |
| 波动变宽、结构止损变远 | 同一结构位，按 ATR 留的空间变大 | 仓位应随风险公式重算，不是加仓理由 |
| 与布林带同时开口 | 尺子与通道都在说波动变大 | 仍没有方向 |

---

## 7. 何时有用

- 判断这根影线或这根实体，是普通噪声还是偏大波动。
- 给止损距离一把可检查的尺子（与结构位并列，不取代结构）。
- 高波动时，在同等单笔风险下把名义仓位算小。
- 检查杠杆：预估强平价若比计划止损近，说明杠杆偏高或止损太远，须重算。本库不颁布「应远于几倍 ATR」。
- 与布林带对照：需要通道看收口走轨时用布林带；只需要一个宽度数字时用 ATR。

---

## 8. 何时失效

- **当方向指标用**：ATR 上升不是做多或做空的理由。
- **跨品种、跨周期直接比数字**。
- **写成 ATR 突破开仓系统**：价格越过 ATR 通道或「ATR 扩张就追」，不是本库内容。
- **颁布标准倍数**：2 倍、3 倍都不写成全站默认。
- **突然插针**：单根 TR 会把 ATR 抬起来，随后若干根尺子仍偏宽，属于滞后。
- **低流动性品种**：几笔单就能撑大 TR，尺子不再代表「普通波动」。
- **只用收盘、忽略缺口**：那不是 True Range，跳空日会低估波幅。

---

## 9. 常见误区

1. ATR 变大读成「该追」或趋势更可靠。
2. ATR 变大却仍按旧名义仓位开。
3. 把 ATR 当成布林带：一个是尺子，一个是通道。
4. 跨周期把 1 日 ATR 直接套到 5 分钟止损。
5. 未收盘就用盘中 ATR 下结论。
6. 把某篇课文里的教学倍数写成「正确倍数」。
7. 用 ATR 替代结构：尺子量宽度，不告诉你高低点还在不在。

---

## 10. 可与哪些指标组合

| 组合 | 观察目的 | 注意 |
|---|---|---|
| ATR + K 线 | 这根波幅是否异常 | 异常不等于反转 |
| ATR + 摆动结构 | 止损放在结构外，再用 ATR 量噪声 | 先结构，再尺子 |
| ATR + 布林带 | 尺子 vs 通道 | 不要叠成两套开仓系统 |
| ATR + Volume | 波幅变宽时转手是否也大 | 巨量可能是强平连锁 |
| ATR + 仓位 / 杠杆教学 | 同等风险下名义随 ATR 变 | 不颁布倍数 |
| ATR + 均线 | 趋势环境里波动是宽是窄 | 均线给位置，ATR 给宽度 |

优先组合：先会读 K 线与结构，再把 ATR 当成尺子。不要把 ATR 画成第四条买卖线。
