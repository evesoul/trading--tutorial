# 累计成交量差（Cumulative Volume Delta，CVD）

| 项目 | 内容 |
|---|---|
| 中文名称 | 累计成交量差 |
| 英文名称 | Cumulative Volume Delta |
| 常用缩写 | CVD |
| 类型 | 主动成交压力（依赖逐笔方向） |

CVD 与普通成交量、持仓量都不同。成交量是转手总量；OI 是未平仓存量；CVD 是**主动买减去主动卖之后再累加**。

---

## 1. 它是什么

单笔成交总有主动方（Taker）和被动方（Maker）。**成交量差（Volume Delta）**定义为：

> Delta = 主动买成交量 − 主动卖成交量

**累计成交量差（CVD）**把每个时间桶的 Delta 依次相加：

> CVD_t = CVD_{t-1} + Delta_t

CVD 上升：这段累积里，主动买多于主动卖。  
CVD 下降：主动卖多于主动买。

「主动」指吃单的一方，不是「看多的人更多」。被动挂单的大卖方，完全可以在主动买很多的时候把价格按住——于是出现价格不涨、CVD 上升的吸收画面。这是观察，不是庄家鉴定。

---

## 2. 它测量什么

测量**主动成交方向的累积**。

它回答：

- 最近是抬价吃卖单更多，还是砸价吃买单更多？
- 这种净主动量与价格是否同步？
- 价格停住时，主动方向是否仍在加码（吸收 / 消耗的讨论）

它不测量：

- 未平仓增减（OI 可以与 CVD 完全脱节）
- 账户人数倾斜（多空比）
- 未来方向

CVD 的质量完全取决于「如何判断主动方」。判断错了，整条曲线的含义就偏了。

---

## 3. 如何计算（教学级）

对时间桶内每笔成交赋予方向后，按选定单位（币或 USDT）求和：

1. **交易所提供 taker side**（优先）：字段标明买方是 taker 还是卖方是 taker。
2. **报价规则（Quote rule）**：成交价贴近卖一偏主动买，贴近买一偏主动卖。需要可靠的盘口快照。
3. **点规则（Tick rule）**：相对上一笔成交价上涨偏主动买，下跌偏主动卖，平价沿用上一方向。这是近似，错误率更高。

然后：

> Delta_桶 = Σ 主动买 − Σ 主动卖
>
> CVD 累加 Delta_桶

重置（Reset）选择必须声明，否则不同平台的 CVD 绝对值对不上：

| 重置 | 含义 |
|---|---|
| 不重置（会话或全历史） | 曲线绝对水平依赖起点 |
| 按日 / 按周重置 | 便于看当日净主动 |
| 从可见图表左端为 0 | 只保留形状 |

教学看**形状、斜率、与价格的同步**，不看「CVD 等于多少才算多」。

聚合多交易所时，方向字段、时间戳、重复成交都会引入误差。本库要求单来源或明确的聚合说明。

---

## 4. 如何观察

1. **斜率**：CVD 向上 / 向下 / 走平，表示净主动方向。
2. **与价格同步**：价格与 CVD 同创新高或同创新低，主动方向与结果一致。
3. **背离**：价格新高而 CVD 未新高（或相反）。可能是主动买无法再推高，也可能是数据噪声或吸收之后仍突破。背离不是反转指令。
4. **吸收 / 消耗画面**：CVD 升而价格横或跌；CVD 降而价格横或涨。说明被动方在该价区承接或供应较多。事后既可能反转也可能被打穿。
5. **与 Volume 对照**：总量很大但 Delta 接近 0，说明主动买卖接近打平。
6. **重置点**：在重置处曲线跳回 0，不要当成方向突变。

---

## 5. 常见参数

| 项目 | 常见选择 | 必须声明 |
|---|---|---|
| 方向分类 | 交易所 side / tick / quote | 方法名 |
| 单位 | 标的数量或 USDT | 与 Volume 一致便于对照 |
| 桶周期 | 与 K 线相同 | 1m CVD 不要直接解释日线 |
| 重置 | 日、周、或图表窗口 | 起点 |
| 来源 | 单一交易所 | 名称 |

没有 14、20 这类经典默认。对 CVD 再套 RSI 或均线属于二次加工，另算指标，本文件不展开。

---

## 6. 典型形态

| 形态 | 观察 | 限制 |
|---|---|---|
| 价量同向推进 | 价格与 CVD 同向新高或新低 | 可在高潮处出现 |
| 顶 / 底背离 | 价格与 CVD 高低点不同步 | 可失败、可过早 |
| 上升吸收 | CVD 升、价格不升 | 可能稍后补涨或继续不涨 |
| 下降吸收 | CVD 降、价格不降 | 对称 |
| 大量零 Delta | 放量但主动买卖接近 | 激烈换手，方向未分 |
| 重置造成的跳变 | 日线 0 点 | 不是市场事件 |

---

## 7. 何时有用

- 在已有 Volume 的基础上，追问「转手里主动哪边更多」。
- 讲解吸收、背离等盘口结果的简化版本（CVD 是成交汇总，不是完整订单簿）。
- 与 OI 对照：主动卖很多但 OI 升，可能是主动开空；主动卖很多且 OI 降，可能是主动平多。仍是框架，不是鉴定。
- 帮助学习者理解：价格是结果，主动成交是过程之一，过程与结果可以不一致。

---

## 8. 何时失效

- **方向分类差**：tick rule 在来回撮合里误判。
- **刷量、自成交、返佣结构**扭曲 taker 标记。
- **多所聚合不当**。
- **低流动性**：几笔单决定全日 CVD 形状。
- **只看绝对水平**：起点任意。
- **把 CVD 当订单簿深度**。它不含未成交挂单。
- **强平与保险基金吃单**：方向字段的经济含义变复杂。

---

## 9. 常见误区

1. CVD 上升 = 庄家在买。主动买也可能是散户抬价。
2. CVD 就是成交量。
3. CVD 就是持仓量。
4. 价格与 CVD 背离后将转向。
5. 不同网站的 CVD 应该重合——重置、单位、分类不同就不会重合。
6. 用 CVD 替代资金费与 OI 来讲永续拥挤。

---

## 10. 可与哪些指标组合

| 组合 | 观察目的 |
|---|---|
| CVD + Volume | 净额 vs 总量 |
| CVD + K 线 | 收盘方向与主动方向是否一致 |
| CVD + OI | 主动成交 vs 增减仓 |
| CVD + MA / EMA | 趋势方向与主动方向 |
| CVD + RSI / MACD | 价格动量 vs 主动成交动量 |
| CVD + Funding | 付费方向 vs 主动方向（常短期不一致） |

CVD 适合作为第一部分靠后的课：先会读 Volume 与 OI，再引入主动方向，否则读者会把三条曲线看成同一个东西。
