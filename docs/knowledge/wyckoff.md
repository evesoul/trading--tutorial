# 威科夫与量价（Wyckoff / Volume-Price）

本文件给阶段 4 课文提供定义。形态是**观察工具**，不是买卖指令。永续合约有爆仓风险；历史图不能代表未来结果。

Content 转写前先读本文件，再读 [glossary.md](./glossary.md) 新增词条。策略边界见 `docs/strategy/wyckoff.md`。

## 是什么

**威科夫方法（Wyckoff Method）**用供需转移描述价格如何在区间里被吸收，再离开区间。教学上压成四阶段：

| 阶段 | 英文 | 观察问题 |
|---|---|---|
| 吸筹 | Accumulation | 下跌之后，卖压有没有被接住、区间有没有被反复测试 |
| 拉升 | Markup | 价格有没有收盘离开吸筹上沿，回踩时量有没有缩小 |
| 派发 | Distribution | 上涨之后，买盘有没有在高位被接走 |
| 下跌 | Markdown | 价格有没有收盘离开派发下沿 |

**量价（Volume-Price Analysis）**只做一件事：用成交量当**努力**，用价格位移当**结果**。放量但走不动，记对面可能在吸收；缩量但轻松走，记阻力或支撑可能被抽空。这是对照，不是方向结论。

本站不鉴定「主力」或「庄家」。只记：区间在哪、收盘在结构哪一侧、量相对近期均量如何、永续过滤器有没有否决。

## 解决什么

阶段 1 的 [摆动结构](./indicators/market-structure.md) 回答 HH/HL 序列。威科夫回答另一句：**这段摆动更像区间内的测试，还是已经离开区间。**

它不替代均线、RSI 或资金费率。四阶段是命名约定，用来把已经发生的图排进一种读法。

## 关键事件（只记位置 + 收盘 + 量）

| 缩写 | 全称 | 记法 |
|---|---|---|
| PS / SC | Preliminary Support / Selling Climax | 下跌减速或高潮量，是候选，不是底部完成 |
| AR | Automatic Rally / Reaction | 自动反弹或回落，用来画区间另一沿 |
| ST | Secondary Test | 回到高潮区，量通常应更小 |
| Spring | Spring | 刺破区间下沿后收盘收回 |
| SOS | Sign of Strength | 放量收盘站上吸筹上沿（Creek），其后不立刻吐回中轴 |
| JAC | Jump Across the Creek | 一根或两根离开上沿，回撤小 |
| BUEC | Backup to the Edge of the Creek | SOS 后缩量回踩上沿 |
| LPS | Last Point of Support | 拉升初期最后一个缩量低点，常与 BUEC 重合 |
| PSY / BC | Preliminary Supply / Buying Climax | 上涨减速或买盘高潮 |
| Ice | Ice | 派发区间下沿 |
| UT / UTAD | Upthrust / Upthrust After Distribution | 刺破上沿后收回 |
| LPSY | Last Point of Supply | 派发末段缩量反弹 |
| SOW | Sign of Weakness | 放量收盘跌破 Ice，反弹到不了中轴 |

**Creek** = 吸筹上沿。**Ice** = 派发下沿。它们是手画水平区域，不是算法线。

合格事件至少同时满足：有区间、收盘关系清楚、能量柱对照。缺一项就降级为预警，不升级为阶段结论。

## 永续里必须改的读法

股票教材默认有收盘集合竞价、隔夜、借券成本。U 本位永续把这些换掉了。详见 [perpetual-futures.md](./perpetual-futures.md)、[perp-screen.md](./perp-screen.md)。

| 股票教材习惯 | 永续改法 |
|---|---|
| 用收盘缺口当证据 | 24h 交易，用流动性切换和已收盘 K 线 |
| 轻量上涨 = 无供给 | 先看资金费和持仓量，拥挤时不当 SOS |
| 绝对成交量 | 只看相对近 20 根同周期均量 |
| 单一成交价 | 结构看最新价 K 线；强平与止损条件看标记价 |
| 数周吸筹 | 4H 上数天也可能走完一个教学区间 |

教学量柱阈值（经验对照，不是参数真理）：

| 称呼 | 相对 20 均量 | 用法 |
|---|---|---|
| 地量 | < 0.5× | 区间内常见，单独不说明问题 |
| 缩量 | 0.5–0.8× | 回踩或失败突破的候选 |
| 均量 | 0.8–1.3× | 普通流转 |
| 放量 | 1.5–2.5× | 有人认真做，要看结果 |
| 高潮量 | > 3× | 可能是 SC/BC，也可能是清算；等下一根 |

清算制造的量：持仓量骤降 + 价格 V 回，默认当假努力。见 [liquidation-cascade.md](./indicators/liquidation-cascade.md)。

## 何时有用 / 何时失效

有用：已能画出摆动高低点，并且愿意等收盘；用日线定阶段、4H 定事件。

失效：只用 15m 命名弹簧；把未收盘日线升级成最终阶段；把清算瀑布当趋势启动；把费率极端当成定时反转。

## 常见误区

1. 没有区间就喊 Spring / UTAD。
2. 影线刺破当成收盘离开。
3. 把健康 BUEC（突破外侧缩量回踩）当成派发。
4. 背离或高潮量单独反手。
5. 山寨事件不对照 BTC 日线 / 4H。

## 可组合对象

- 结构：摆动结构、趋势线
- 量能：成交量、持仓量、CVD（瀑布中暂停解释）
- 拥挤：资金费率、多空比
- 系统：多周期、仓位、订单、止损

禁止把上述组合成「Spring 就是开多」。
