# 术语表（Glossary）

本表统一全站交易用语。Content / Strategy / QA 引用术语时以本文件为准。

写法约定：

- 首次出现写 **中文（English，缩写）**
- 后文可用中文或缩写
- 同一概念不混用两个「正式名」
- 观察用语（超买、背离、金叉等）不得写成买卖指令

---

## 1. 市场与合约

### 现货（Spot）

按当前市场价格买卖标的资产本身。买入现货后持有的是资产，没有到期日，也不会因为杠杆不足被交易所强制平仓。现货仍有价格下跌的本金亏损风险。

### 合约（Futures / Derivatives）

约定未来按规则结算价格差的衍生品。交易者可以做多（Long）或做空（Short），常见用途是投机、对冲，而不是领取现货。合约有保证金与强平机制。

### 交割合约（Delivery / Dated Futures）

有明确到期日的合约。到期后按规则交割或现金结算，价格会受到期日临近的影响。本站主讲对象不是交割合约。

### 永续合约（Perpetual Futures / Perpetual Swap，Perp）

没有到期日的合约。通过**资金费率（Funding Rate）**周期性在多空之间收费，使合约价格尽量靠近现货指数。可并列英文 Perpetual Swap；不用「无限期期货」作正式中文名。

详见 [perpetual-futures.md](./perpetual-futures.md)。

### U 本位（USDT-margined / Quote-margined）

用稳定币（教学默认 **USDT**）作保证金，盈亏也以该稳定币结算。例如 BTCUSDT 永续：涨跌按 BTC 的 USDT 价格计，盈亏记入 USDT。

与之对照：

- **币本位（Coin-margined）**：用标的币（如 BTC）作保证金与结算。币价波动会同时影响仓位盈亏和保证金本身的价值。

本站默认语境是 **U 本位永续合约**。

### 标的 / 交易对（Underlying / Symbol）

被报价的对象。教学里常见写法：`BTCUSDT`、`ETHUSDT`。写案例时必须同时记录交易对、图表周期、数据来源、时间区间。

### 做多（Long）与做空（Short）

- 做多：预期价格上涨，先买后卖（或持有多头仓位），价格涨则浮动盈利增加。
- 做空：预期价格下跌，先卖后买（或持有空头仓位），价格跌则浮动盈利增加。

方向判断错误时，亏损同样会被杠杆放大。

### 开仓 / 平仓 / 加仓 / 减仓（Open / Close / Add / Reduce）

- 开仓：新建仓位。
- 平仓：把已有仓位关掉，盈亏从浮动变为已实现。
- 加仓：同方向增加仓位。
- 减仓：减少部分仓位。

开仓增加**持仓量（OI）**的条件是对手方也是新开仓；一方开仓、一方平仓则 OI 可以不变。详见 [open-interest.md](./indicators/open-interest.md)。

## 2. 保证金、杠杆与强平

### 保证金（Margin）

开仓并维持仓位所需冻结的资金，不是「这笔钱已经亏掉」。保证金用来吸收浮动亏损。

### 起始保证金（Initial Margin，IM）

开仓时至少要冻结的保证金。杠杆越高，同样名义价值所需起始保证金越少，抗亏损空间也越小。

### 维持保证金（Maintenance Margin，MM）

维持仓位不被强平所需的最低保证金。账户权益跌到维持保证金附近时，交易所会按规则强制减仓或平仓。

### 风险限额（Risk Limit）与仓位档位（Position Tier）

交易所按仓位**名义价值**分段规定保证金要求的规则。名义做大，可能升入更高档，**维持保证金率可能升高**，预估强平价靠近标记价。有的档位还会压低可用杠杆展示。

这是大仓位的风险参数，不是「做大了更稳」。屏幕上怎么读见 [perp-screen.md](./perp-screen.md)；机制见 [perpetual-futures.md](./perpetual-futures.md)。

### 仓位名义价值（Notional Value）

仓位规模用报价货币衡量的价值。教学近似：

> 名义价值 ≈ 仓位数量 × 标记价格

杠杆与盈亏百分比通常相对于名义价值或保证金来理解，写文章时必须说清分母。

### 杠杆（Leverage）

用较少保证金控制较大名义价值。常见展示为 `10x`、`20x`。

杠杆同时放大盈利与亏损。高杠杆会让较小的逆向波动就触及强平。本站**不鼓励使用高杠杆**，教学示例优先用低杠杆说明机制。

### 逐仓（Isolated Margin）与全仓（Cross Margin）

- 逐仓：该仓位只用分配给它的保证金。亏完这部分，通常只强平这一仓，其他资金不自动补入。
- 全仓：可用余额共同为仓位提供保证金。抗波动空间可能更大，但极端情况下可能亏及账户内更多资金。

两种模式都有强平风险，只是亏损波及范围不同。

### 账户权益 / 保证金余额（Equity / Wallet Balance）

不同交易所名称不同。教学中区分：

- **钱包余额**：已结算、可再分配的资金。
- **未实现盈亏（Unrealized PnL）**：持仓按标记价格估算、尚未平仓的浮动盈亏。
- **权益**：余额与未实现盈亏等项合计后的账户净值（以交易所定义为准）。

### 已实现盈亏（Realized PnL）

平仓后锁定的盈亏，还会受手续费、资金费影响。

### 标记价格（Mark Price）

交易所用来计算未实现盈亏和估算强平的参考价，通常结合现货指数、资金费率基础（溢价）等，减少最新价被短暂操纵就触发强平的情况。

### 最新价格（Last Price）

最近一笔成交价。图表上的 K 线收盘价通常来自成交价序列，**不等于**标记价格。

### 指数价格（Index Price）

由一篮子现货市场价格合成的参考价，用来锚定永续合约，避免合约价格长期偏离现货。

### 强平（Liquidation）

当保证金不足以满足维持保证金时，交易所按规则强制减少或关闭仓位。口语常称「爆仓」。教学正文用**强平**；需要照顾口语时写「爆仓（即强平）」。

强平是机制结果，不是技术指标信号。杠杆越高、波动越大、保证金越薄，越容易被强平。

强平单通常以市价进入订单簿；薄盘里会插针，并可能引发**清算瀑布（Liquidation Cascade）**。见 [liquidation-cascade.md](./indicators/liquidation-cascade.md)。

### 保险基金（Insurance Fund）与自动减仓（Auto-Deleveraging，ADL）

穿仓（亏损超过该仓保证金）时，交易所可能先用**保险基金**填补，使对手方不必立刻被强制减仓。保险基金仍不够时，可能触发 **ADL**：按规则减少盈利且杠杆较高的对手仓位。二者都是结算机制，不提供交易时机。详见 [perpetual-futures.md](./perpetual-futures.md)。

### 破产价格（Bankruptcy Price）

权益理论上被亏到零附近的价格。强平通常在到达破产价之前、按维持保证金触发，具体以交易所规则为准。

### 手续费与滑点（Fee / Slippage）

- 手续费：开平仓成本。
- 滑点：意图价格与实际成交价的差距，流动性差或行情剧烈时更明显。

回测与实盘评估都要把成本算进去。历史成交不能代表未来相同的滑点。

## 3. 价格图与均线

### K 线（Candlestick / K-line）

把一段时间的 **开盘价（Open）、最高价（High）、最低价（Low）、收盘价（Close）** 画成一根柱，简称 OHLC。实体表示开收差，影线（上影 / 下影）表示最高最低超出实体的部分。

详见 [kline.md](./indicators/kline.md)。

### 趋势线（Trendline）

在一段可见推进里，用至少两个摆动低点（上升）或两个摆动高点（下降）连成的斜线。第三点是回测观察，不是对未来的保证。手连结构不是均线：均线每根重算。

详见 [trendlines.md](./indicators/trendlines.md)。

### 摆动结构（Market Structure / Swing Structure）

把相邻的**摆动高点（Swing High）**与**摆动低点（Swing Low）**排成序列，用来看这段是在抬高还是压低。常用 **HH / HL**（更高高点 / 更高低点）描述上升结构，**LH / LL**（更低高点 / 更低低点）描述下降结构。推进不是自动延续，回撤不是自动反转。

斜线与水平区域怎么画，见趋势线篇；摆动序列与假突破怎么记，见 [market-structure.md](./indicators/market-structure.md)。

### 图表周期（Timeframe）

一根 K 线代表的时间长度，如 `5m`、`15m`、`1H`、`4H`、`1D`。同一指标在不同周期上的含义不能直接混用。

### 回看参数（Period / Length）

计算指标时向前取多少根已完成的 K 线，如 MA 20、RSI 14。不要把「图表周期」和「回看参数」都简称为「周期」而不加说明。

### 均线（Moving Average，MA）

对过去 N 根收盘价（或其他价格）做平均后连成的线。单独写 **MA** 时，本库默认指 **简单移动平均（Simple Moving Average，SMA）**。

详见 [ma.md](./indicators/ma.md)。

### 指数均线（Exponential Moving Average，EMA）

对近期价格给予更高权重的均线，通常比同参数 SMA 更贴近新价格，但仍滞后于价格。

详见 [ema.md](./indicators/ema.md)。

### 趋势（Trend）与震荡（Range / Sideways）

- 趋势：价格在一段时间内更常沿某一方向推进，均线斜率常较明显。
- 震荡：价格在区间内来回，均线走平，动量指标更容易在高低区来回摆动。

市场环境会切换。一个指标在趋势里好用，在震荡里可能失效，反之亦然。

### 支撑与阻力（Support / Resistance）

价格曾经多次止跌或受阻的**区域**，不是一根精确价。它们是观察位置，不是价格必须停住的墙。判断站上或跌破时，教学上优先看已收盘是否离开该区；影线扫到只说明到过。突破之后原区域角色可能互换，也可能假突破。

详见 [trendlines.md](./indicators/trendlines.md)。

### 假突破（False Breakout）

影线越过支撑 / 阻力或前高 / 前低所在区域，收盘回到区内。教学上记「到过，未收盘离开」，不是反转指令，也不鉴定庄家诱多诱空。细节见 [market-structure.md](./indicators/market-structure.md)；区域怎么画见 [trendlines.md](./indicators/trendlines.md)。

### 波动率（Volatility）

价格变动幅度的大小。波动率高不等于方向明确；波动率低也不等于即将突破。布林带带宽常用来观察波动率的扩张与收缩。

### 真实波幅（True Range，TR）与平均真实波幅（Average True Range，ATR）

**真实波幅**取三者最大：本根高−低、|高−前收|、|低−前收|。**ATR** 是对最近 N 根 TR 的平滑，测量近期普通波动宽度，**不给方向**。ATR 是尺子；布林带是通道。详见 [atr.md](./indicators/atr.md) 与 [bollinger-bands.md](./indicators/bollinger-bands.md)。

### 流动性（Liquidity）

以较小冲击成交较大数量的能力。流动性差时，滑点、价差、插针更常见，指标也更容易出现一次性极端值。

## 4. 动量、成交与合约数据

### 动量（Momentum）

价格在一段时间内上涨或下跌的力度与速度。RSI、MACD、KDJ 都属于动量观察工具。动量强不保证趋势延续，动量弱也不保证立即反转。

### 平滑异同移动平均线（MACD）

用两条 EMA 的差值及其信号线，观察趋势力度变化与交叉。详见 [macd.md](./indicators/macd.md)。

### 相对强弱指标（Relative Strength Index，RSI）

用一段时间内平均涨幅与平均跌幅的关系，把动量映射到约 0–100。详见 [rsi.md](./indicators/rsi.md)。

### 随机指标 / KDJ（Stochastic Oscillator / KDJ）

看收盘价在最近 N 根高低区间中的相对位置，再平滑得到 K、D，并衍生 J。详见 [kdj.md](./indicators/kdj.md)。

### 布林带（Bollinger Bands，BB）

中轨为均线，上下轨为均线加减若干倍标准差，用来观察波动率与价格相对位置。详见 [bollinger-bands.md](./indicators/bollinger-bands.md)。

### 成交量（Volume）

一段时间内成交的数量。U 本位合约上要分清：标的数量、张数，还是报价货币成交额（如 USDT）。详见 [volume.md](./indicators/volume.md)。

### 持仓量（Open Interest，OI）

当前尚未平仓的合约总量。成交量是「这段时间转手多少」，持仓量是「此刻还挂着多少仓」。详见 [open-interest.md](./indicators/open-interest.md)。

### 资金费率（Funding Rate）

永续合约按周期在多空之间收费的比率。费率为正时，多头支付空头；为负时，空头支付多头。**资金费（Funding Payment）**是实际划转的金额。详见 [funding-rate.md](./indicators/funding-rate.md) 与 [perpetual-futures.md](./perpetual-futures.md)。

### 多空比（Long/Short Ratio，LSR）

多头相对空头的比值。不同交易所、不同接口的口径不同：账户数比、持仓量比、大户账户比、大户持仓比。没有口径的多空比无法解释。详见 [long-short-ratio.md](./indicators/long-short-ratio.md)。

### 累计成交量差（Cumulative Volume Delta，CVD）

把主动买成交量减主动卖成交量后累加。反映的是主动成交方向的累积，不是普通成交量，也不是持仓量。详见 [cvd.md](./indicators/cvd.md)。

### 主动买 / 主动卖（Taker Buy / Taker Sell）

吃掉对方挂单的成交。主动买通常是市价买或抬价吃卖单；主动卖通常是市价卖或砸价吃买单。分类依赖交易所字段或重建规则，数据会有误差。

## 5. 观察用语（不是信号）

下列词汇只描述图表上常见的相对关系。它们**不是**入场、出场或反转指令。

### 超买（Overbought）与超卖（Oversold）

动量指标进入传统高位区或低位区的说法。例如 RSI 传统上把 70 附近看作超买区、30 附近看作超卖区。

超买不代表价格即将下跌；超卖不代表价格即将上涨。强趋势里，指标可以在极端区停留很久。

### 背离（Divergence）

价格创新高（或新低），对应指标没有同步创新高（或新低）。

- **顶背离（Bearish divergence）**：价格更高高点，指标更低高点。
- **底背离（Bullish divergence）**：价格更低低点，指标更高低点。

背离是观察现象，不是反转已被确认。趋势行情中背离可以反复出现而价格继续走。

### 金叉（Golden Cross）与死叉（Death Cross）

快线从下向上穿过慢线称金叉；从上向下穿过称死叉。可用于均线（如 MA50 与 MA200），也可用于 MACD、KDJ 的快慢线。

交叉发生在已经走完的一段价格之后，具有滞后性。金叉不代表此后只涨，死叉不代表此后只跌。

### 钝化（Flattening / Failure to reverse at extremes）

指标进入极端区后不再随价格继续创新高或新低，或在极端区来回小幅波动。常见于 RSI、KDJ。钝化提示动量变化，不单独构成反转。

### 量价配合 / 量价背离（Volume confirmation / Volume divergence）

价格变动时成交量同步放大或缩小的观察。放量上涨或缩量回调都只是常见搭配，不是充分条件。

### 拥挤（Crowding）

较多交易者站在同一方向，可从极端资金费率、一边倒的多空比、快速上升的 OI 等侧面观察。拥挤可以提高反向波动时的清算连锁风险，但不能据此定时反转。

## 6. 教学与风险用语

### 观察工具 vs 交易信号

本站把指标、形态、交叉、背离称为**观察工具**。只有当某篇策略文档写明「规则化条件」时，才谈入场出场；即便如此，规则也只是可回测的假设，不是对未来结果的承诺。

### 市场环境（Market Regime）

至少区分趋势、震荡、高波动、低波动。先判断环境，再解释指标，避免把单一读数套用到所有行情。

### 风险（Risk）

交易可能亏损，永续合约还可能被强平、亏掉保证金，极端情况下还可能出现额外结算风险（视交易所保险基金与自动减仓规则）。任何策略、指标组合都不能写成没有风险。

### 回测（Backtest）

用历史数据按规则模拟。回测结果不能代表未来。必须记录样本区间、手续费、滑点、交易次数与回撤。

### 仓位管理（Position Sizing）

单笔亏损占权益的上限、总敞口上限等规则。它解决的是「错了能活下来」，不是提高胜率的保证。

### 热度（Account Heat）

当前所有未平仓计划风险之和（按 R 或权益百分比加总，并考虑品种是否同向、是否都跟 BTC）。多笔各 1% 且高度相关时，账户风险不是 1%。热度碰到上限时的动作（先平、先减、或禁止开新仓）由系统事先写死。本知识库只立定义；规则展开归 Strategy。

### 决策周期（Decision Timeframe）与执行周期（Execution Timeframe）

事先写死的两层图表周期：高周期（决策周期）定环境与方向，低周期（执行周期）只找触发。两周期打架时，默认不交易或等对齐，不要切到「更能讲通」的周期。未收盘的低周期不能推翻已收盘的高周期。细则留给多周期课。

## 7. 订单用语

### 只减仓（Reduce-Only）

这笔单最多减小已有仓位，不会在平仓方向上开出反向新仓。认错离场、止损常用。它不保证成交，也不阻止强平。详见 [order-types.md](./order-types.md)。

### 只做 maker（Post-Only）

只挂到订单簿当 maker；若下单瞬间会变成 taker，通常撤单或不接受。用来避免吃单，不用来保证成交。详见 [order-types.md](./order-types.md)。

| 买入信号 / 卖出信号 | 把观察写成指令 | 可观察的交叉 / 区域 / 背离 |
| 超买就是要跌 | 把区域当反转 | 处于传统超买区，趋势中仍可延续 |
| 金叉看多、死叉看空 | 把滞后交叉当方向结论 | 出现金叉，需结合趋势与波动再解释 |
| 把套利写成没有风险 | 误导 | 说明机制与剩余风险 |
| 收益承诺、确定性预测 | 违禁 | 删除该类表述 |
| 爆仓（作为唯一正式名） | 口语含糊 | 强平；必要时括号注明爆仓 |

收益承诺与绝对化预测的禁用词清单见 `AGENTS.md` 第 6 节与 `.cursor/rules/trading.mdc`，本知识库正文不重复列举。
