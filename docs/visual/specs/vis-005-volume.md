# vis-005 成交量与价格

## 教学说明

三种组合并排，是为了建立「先看价格、再看量」的阅读顺序。不要把「量增」写成「主力进场」或「必然延续」。

U 本位永续的成交量口径因交易所而异（张、USDT），示意图只比较相对高低。
