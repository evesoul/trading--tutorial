# vis-025 多周期

## 教学说明

与 `docs/strategy/multi-timeframe.md`、`docs/product/curriculum-upgrade.md` 第 3.5 节对齐。三格只讲「谁定场、谁找触发、打架怎么办」，不是三层周期共振仪表盘。

正例：4H 偏空仍在，15m 金叉只记低周期回撤，不开多。反例：切到更能讲通的周期，或用第三根周期当裁判。图内交叉只标「观察」，不是开多指令。

## 局限

本图把周期收成一对：决策 + 执行。日线 / 4H / 15m 三层投票不在本图范围内。抽象阴线与阳线不是某品种真实行情。
