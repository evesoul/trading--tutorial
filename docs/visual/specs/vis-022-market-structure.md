# vis-022 摆动结构与假突破

## 教学说明

这是结构图，不是某次交易。三格是对照，不是一段连续行情。

与 `docs/knowledge/indicators/market-structure.md` 对齐：左格只标 HH/HL；中格区分推进与回撤；右格用开收关系对照「到过」和「收在」。不画订单块，不画庄家箭头，不放下单按钮。

建议配文：先标已收盘的摆动点，再写序列，最后才谈假突破。默认读图顺序是结构 → 均线 → 副图，本图不画均线。

## 局限

本图不解释均线，也不证明某种结构后续有效。不同人选出的摆动点会不一样。真实行情练习窗见 vis-109。
