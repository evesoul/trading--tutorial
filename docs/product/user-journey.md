# 用户旅程：零基础首次访问

画像：听说过比特币或合约，没系统学过指标，分不清均线和振荡指标，担心亏钱，也容易被「稳赚」话术吸引。

成功标准（首次访问结束时）：

1. 知道这是**教程站**，不是喊单或自动交易
2. 知道永续合约有较高风险，杠杆会放大亏损，可能爆仓
3. 选中并打开一篇课（推荐：导学或 K 线）
4. 读完该篇后，能指出**下一篇是什么、为什么**

不作为首次成功标准：开户、下单、学会全部指标、得到买卖点。

## 主路径（一次会话）

```text
落地 / 
  → 读定位与风险
  → 点「开始学习」
  → /course 认路、再读风险
  → 选推荐起点（K 线；若导学未读完则先停在本页导学）
  → 文章页读完
  → 「下一步」进入下一篇或回到 /course
```

### 1. 落地 `/`

用户 10 秒内应能回答：这是什么站？适不适合我？有没有风险？

页面按此顺序呈现（产品顺序，不规定视觉稿）：

1. 标题：U 本位永续合约交易教程（教育）
2. 三阶段各一句
3. **风险块**（不可仅放页脚）：杠杆、爆仓、历史案例不能代表未来
4. **边界块**：不提供信号、荐股、喊单、自动交易
5. 主按钮：开始学习 → `/course`
6. 辅助：已有一点基础？指标目录 → `/indicators`（次要，避免分流走丢）

禁止：收益数字、胜率宣传、模拟账户余额、实时多空比大屏作为首页主视觉。

### 2. 认识风险 `/course#risk` + 导学正文

用户在点进 K 线前，应再看到一次风险，且比首页更具体：

- 保证金会亏完
- 高杠杆会更快触发强平
- 本站图表与案例用于理解概念，不代表按图交易会赚钱

导学同时说明怎么学：一篇一个问题；先指标、再组合、再系统；遇到词去术语表。

若用户从首页「从 K 线开始」直达文章，文章页底仍要有精简风险句，避免完全跳过。

### 3. 选课 `/course`

不是让用户在 30+ 个标题里随便点。

默认决策：

| 用户状态 | 推荐动作 |
|---|---|
| 第一次来 | 读本页导学，然后去 K 线 |
| 已读导学、未读 K 线 | 去 `/indicators/kline` |
| 主路径读到一半 | 下一篇（由 `learning.next`） |
| 想浏览全部指标 | 去 `/indicators`，主路径 4 篇置顶 |
| 点进组合 / 系统（MVP 无正文） | 空状态解释「先学看图」，带回指标 |

「选课」在 MVP 的含义是：**确认从推荐起点开始**，而不是自组课表。

### 4. 学完知道下一步（文章页）

一篇课结束时，用户应同时看到：

1. **本篇只解决了哪个问题**（小结，来自正文）
2. **本篇不能解决什么**（局限，来自正文）
3. **下一篇标题 + 一句话原因**（来自学习路径，经 `learning.next`）
4. **可选：回阶段目录** 或 **回怎么学**

K 线读完 → 下一步是 MA：「先用均线看价格的平滑方向」。  
RSI 读完（Sprint 002 主路径末）→ 下一步是 Volume；并提示阶段 2 / 3 尚未开放正文，可回 `/course` 复习已读篇。

上一篇 / 下一篇缺失时：下一篇按钮改为「返回怎么学」，不要链到 404。

## 分支与恢复

| 偏离 | 产品处理 |
|---|---|
| 从外链直达 `/indicators/rsi` | 页头展示先修（K 线 / MA / EMA），允许继续读 |
| 打开 `/combinations`（空） | 说明组合课依赖已学指标，按钮回 `/indicators` |
| 打开 `/trading-system`（空） | 说明系统课是第三阶段，按钮回 `/course` |
| 打开 `/glossary` | 查完用浏览器返回；词条可链回相关课文（有则链，无则不链） |
| 点「编写中」 | 不可进入空文章 URL；仅禁用或弹一层「尚未发布」 |

## 各页「首次」检查清单（给 UI）

- 用户不需要懂交易术语也能点对主按钮
- 风险不是灰色六号字藏在页脚
- 当前在三阶段的哪一段，始终可见
- 学完有下一步，不会停在「全文结束」无出口
- 任何页面都能用主导航回到 `/course`

## 刻意不做的旅程

- 注册后推送每日信号
- 「一键复制策略」
- 模拟盘开奖式盈亏
- 用回测曲线吸引开户
