# MVP 范围（Sprint 001 / 002）

## 本站是什么 / 不是什么

**是：** 面向零基础的 U 本位永续合约**教育网站**。用教程、示意图和案例，帮助用户理解指标、指标组合，以及如何思考自己的交易系统、风险和复盘。

**不是：**

- 交易信号或策略跟单
- 荐股、喊单、币种推荐
- 自动交易、API 下单、交易所网关
- 实时行情交易终端
- 保证收益或「可复制的盈利系统」

任何 Agent 的产出若听起来像上述产品，即超出范围。禁止用语见 `AGENTS.md`：一定、必然、100%准确、稳赚、必赚、无风险、保证盈利。

## Sprint 001 / 002 明确不做

### 课程正文

- 阶段 1：Volume、MACD、KDJ、布林带、OI、资金费率、多空比、CVD 的正式教程
- 阶段 2：全部组合教程
- 阶段 3：全部交易系统教程与完整案例
- 把 Strategy 框架直接当用户可读长文发布

### 产品形态

- 实时 K 线交易盘、下单面板、持仓面板
- 信号订阅、价格预警当「买卖提示」
- 用户账号、云端学习进度、社区、评论
- 回测引擎、参数优化器、策略商城
- 多语言、多交易所深度对接
- 支付、会员、拉新裂变

### 内容与表达

- 用虚构行情证明某方法能赚钱
- 把超买/金叉写成开仓指令
- 暗示学完即可实盘或可控制风险到可忽略
