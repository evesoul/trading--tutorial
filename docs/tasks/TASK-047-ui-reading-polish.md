# TASK-047 教程阅读壳与外观优化

课序、路由、课文正文不改。只改阅读壳：层次、找路、首屏行动。

## Owner
UI Agent（用户授权布局与外观）

## 产品判断

1. 课文是主产品。先让人读得下去，再让人知道下一篇在哪。
2. 首页主行动要和标题在一起。风险仍可见，但不把「开始学习」压到折页下。
3. 侧栏按主路径 / 对照层 / 合约层分组。16–20 条扁平编号扫不动。
4. 纸感、青绿、教育站气质保留。不做交易终端皮肤。

## 必须

- 课文页：面包屑、分组侧栏、当前篇高亮、进度
- 正文标题链不再整页发蓝
- 首页 CTA 提到首屏；阶段卡去掉重复标签
- 目录卡编号；怎么学二十步用紧凑列表
- Desktop + Mobile 可扫
- 不改 slug、课序、课文 Markdown
