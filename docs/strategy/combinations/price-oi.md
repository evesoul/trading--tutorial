# 价格 + 持仓量（Price + OI）

本文件是教学框架，不是教程正文，也不是交易信号。

持仓量（Open Interest，OI）衡量未平仓合约数量。它回答仓位存量如何变化，不回答价格下一步走哪里。定义以 Knowledge 的 OI 条目为准。

## 教学目的

1. 价格说“涨了还是跌了”，OI 说“市场上未平仓合约是增了还是减了”。
2. 四象限是读图语言，不是四条交易指令。
3. 同一象限至少有两种参与者解释，教学必须同时写出。
4. OI 有延迟、口径和交易所差异，不能当成实时主力行踪。

## 各指标回答什么问题

| 观察对象 | 主要回答 | 不负责回答 |
|---|---|---|
| Price | 这一段谁在账面赢，价格往哪边走 | 新仓还是平仓、拥挤程度的成本 |
| OI | 未平仓合约规模变大还是变小 | 这些仓位是多头开的还是空头开的（单看 OI 无法拆开） |

关键限制：OI 增加只说明“市场上多了一对多空仓位”，不说明是新多还是新空主导。要讨论谁更拥挤，需要资金费率、多空比等其他观察，见 [funding-oi.md](./funding-oi.md)。

## 观察框架：价格与 OI 的四象限

下面用“教学读法”而不是“操作建议”。每格都列出至少两种解释。

| 价格 | OI | 常见读法 | 同样说得通的其他读法 |
|---|---|---|---|
| 上涨 | 上升 | 趋势推进时有新仓进入 | 空头止损或被动减仓与新多混合，OI 仍可能升 |
| 上涨 | 下降 | 空头回补推动价格 | 多头主动平仓，上涨可能是平仓行情，后续参与可能变弱 |
| 下跌 | 上升 | 下跌过程中有新仓进入 | 多头被强平或止损，空头新开，二者都可能抬高 OI |
| 下跌 | 下降 | 多头平仓、风险撤出 | 空头获利了结，下跌是减仓过程，不自动到底 |

教学时先让学习者填表：“价格怎样、OI 怎样、我能确定什么、我不能确定什么”。能确定的通常只有“存量增减 + 价格方向”；不能确定的是“哪一方主导”。

## 共振

对本组合，共振指：价格方向清楚，同时 OI 的增减让“这是加仓过程还是减仓过程”比较好讨论。

- 价格沿结构上行，OI 同步上升：更值得讨论“是否有新仓在支持这段涨”。仍可能随后失败。
- 价格沿结构下行，OI 同步上升：更值得讨论“下跌是否伴随仓位扩张”。在永续里，这可能包含被迫平仓。
- 急涨或急跌后价格停滞，OI 明显下降：更值得讨论“是否在消化仓位”，而不是“趋势已经确认结束”。

共振只进入 Setup 层：它帮助描述市场在加仓还是在减仓，不给出入场价。

## 冲突

| 冲突 | 可能的读法 | 教学处理 |
|---|---|---|
| 价格新高，OI 持续下降 | 涨，但仓位在收缩 | 可能是平仓推动；方向观察仍在，参与存量变弱 |
| 价格横盘，OI 快速上升 | 价格没动，仓位在堆积 | 可能在积累能量，也可能在对赌区间；不能预判突破方向 |
| 价格急跌，OI 先升后降 | 先有新仓或强平，随后集中平仓 | 需要把时间顺序讲清，不要合成一个“见底信号” |
| 价格与 OI 同步剧烈抖动 | 数据噪声或清算瀑布 | 先检查数据与爆仓事件，而不是立刻解释结构 |

冲突时的默认处理：不把 OI 当方向指标去推翻价格结构，也不为了“OI 看起来不对”而随意反手。

## 适用环境

- 能拿到同一合约、同一交易所、连续口径的 OI。
- 价格有可描述的一段趋势或一段区间，而不是单根噪声。
- 课时能同时讲永续特有现象：价格下跌时 OI 上升，可能包含多头强平。

## 失效环境

- 跨交易所加总 OI，或把币本位与 U 本位混在一张图。
- OI 更新频率远慢于交易决策周期，用 5 分钟图去解释小时级才更新的 OI。
- 新上线合约、活动补贴、套利资金进出，使 OI 台阶式变化。
- 只看 OI 绝对值高低，不看变化方向和变化速度。高 OI 只说明市场大，不说明马上要反向。

## 放入交易系统的位置

| 链路步骤 | 可以提供的观察 | 不能代替 |
|---|---|---|
| Market Regime | 仓位是在扩张还是收缩；是否处于清算密集后的减仓 | EMA、波动、成交量给出的环境 |
| Direction | 很弱。OI 不决定方向 | 价格结构或趋势规则 |
| Setup | 加仓推进 vs 减仓推进的上下文 | 入场触发 |
| Entry | 一般不单独作为触发 | 若写入系统，必须与价格条件同时可检查 |
| Stop Loss 及之后 | 无 | 爆仓风险要在风险管理里单独处理 |

更稳妥的写法：OI 只用于“允许或禁止某类前提”。例如“减仓上涨时，不把这次上涨当成趋势加速的前提”。这仍是过滤，不是信号。

## 常见误区

1. **OI 上升就是有主力在做多。** OI 上升是多空各多了一份合约。
2. **OI 下降就是要反转。** 减仓可以出现在趋势中途，也可以出现在结束段。
3. **把四象限背成买卖口诀。** 口诀会删掉“多种解释并存”这一核心。
4. **用 OI 替代成交量。** 成交量是流量，OI 是存量，见 [oi-volume.md](./oi-volume.md)。
5. **忽略强平。** 永续里价格与 OI 同时快速变化，常常与清算有关，不是自愿的“看好/看空”。
6. **把一张汇总 OI 图用在单一交易所的下单决策教学上。** 口径要一致。

## 风险

- 学习者若把“OI 上升 + 价格上涨”理解成安全做多，会在拥挤的多头里加大杠杆。这与本项目的风险原则相反。
- OI 高、流动性变差时，离场滑点更大，止损成交价可能远离计划价。
- 清算瀑布中，价格、OI、成交量会同时剧烈变化，任何单一象限读法都会过时。
- 数据延迟会导致“以为在加仓、实际已经在降仓”。

## 给 Content Agent

- 开篇用“停车场里的车位数”类比存量：车位数增加，不知道新来的是哪些人。
- 四象限用表格 + 两张对立案例，不要用四条“应该开多/开空”。
- 必须有一节“OI 无法区分多空谁开的仓”。
- 必须有一节永续强平：下跌 + OI 上升，可能是被动减多和主动开空混在一起。
- 不要用虚构 OI 数字证明某象限之后价格会怎么走。
- 下一步可链到 OI + Volume，以及 Funding + OI。

## 给 Visual Agent 的图需求

- 四象限示意图（明确标注示意图）
- 价格上涨 + OI 上升 vs 价格上涨 + OI 下降对照
- 下跌过程中 OI 骤升再骤降（用于讲清算，不用于证明见底）
- 图注必须写数据源与合约，避免“全网 OI”与单交易所混用
