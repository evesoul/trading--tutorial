# 趋势 + 成交量

本文件是教学框架，不是教程正文，也不是交易信号。

覆盖两套观察：

- EMA + Volume
- Price + Volume（量价）

课程位置：在趋势 + 动量之后。学习者应已理解：成交量描述的是成交活跃程度，不是涨跌方向本身。

## 教学目的

1. 成交量回答“有没有人在参与”，不回答“该多还是该空”。
2. 价格或均线给出方向上下文，成交量用来看推动是否得到参与度配合。
3. 放量可以出现在推进里，也可以出现在派发、吸筹或踩踏里；放量本身没有方向。
4. 缩量突破、放量滞涨是常见冲突，处理方式是等待或缩小观察范围，不是立刻反向开仓。

## 各指标回答什么问题

| 观察对象 | 主要回答 | 不负责回答 |
|---|---|---|
| EMA | 均价方向和价格相对均价的位置 | 这一段有多少人成交 |
| Price（K 线结构） | 涨跌、突破、拒绝、停滞实际发生在哪 | 参与是否放大、仓位是否增加 |
| Volume | 这一根或这一段的成交活跃程度，相对近期是否放大或缩小 | 多空谁开的仓、资金费率、下一步方向 |

成交量是市场参与度，不是“主力意图说明书”。同一根放量阳线，可能是新开多、空头回补、或两者混合。要看仓位增减，需要再引入 OI，见 [price-oi.md](./price-oi.md) 和 [oi-volume.md](./oi-volume.md)。

## 组合 A：EMA + Volume

### 为什么搭配

EMA 把价格平滑成一条可讨论的方向线。成交量检查：当价格离开或回到这条线时，市场是否比近期更活跃。

没有成交量，学习者容易把每一次回踩都当成“趋势继续”；没有 EMA，成交量只是高低柱，缺少“相对哪条方向线放大”。

### 观察顺序

1. EMA 判断环境：分向还是走平。
2. 看价格与 EMA 的关系：在上方推进、回踩、跌破，或反复穿越。
3. 用成交量比较：推进时是否比回踩时更活跃；跌破时是否突然放大。

比较对象应固定，例如“相对最近 N 根的平均成交量”。不要用肉眼觉得“好像比较大”。

### 共振

- 价格在上行 EMA 一侧推进，同时成交量高于近期均值：参与度与方向暂时一致。
- 回踩 EMA 时成交量缩小，随后离开均线时成交量重新放大：更接近“休息后的再参与”，仍需触发规则，不是自动加仓。
- 价格跌到 EMA 下方且成交量明显放大：下跌过程得到更多成交，可能是推进，也可能是恐慌平仓。教学上先描述“参与度上升”，再讨论多种解释。

### 冲突

| 冲突 | 可能的读法 | 教学处理 |
|---|---|---|
| 价格沿 EMA 创新高，成交量逐步缩小 | 方向还在，参与度变弱 | 趋势可能难持续，但不自动见顶 |
| 价格跌破 EMA，成交量几乎没有放大 | 均线被穿过，但缺少参与 | 可能是假跌破，也可能是流动性差；先等待确认 |
| 均线走平，成交量间歇性脉冲 | 没有方向，只有短促活跃 | 这套组合的方向层不成立 |

### 适用与失效

适用：有可辨认的均线方向，且成交量能分出“相对高”和“相对低”。

失效：

- 24 小时成交量结构本身有时段差异（亚洲、美洲活跃度不同），未做同时段比较时，容易误读“放量”。
- 合约换月、活动拉量、刷量或数据源切换会造成成交量台阶，指标含义被污染。
- 极低流动性品种上，少量成交就能撑起一根高量柱。

## 组合 B：Price + Volume

### 为什么搭配

有的走势用均线描述并不清楚，例如区间上下沿、长上影、收盘回撤。这时直接用价格结构 + 成交量，问的是：“这一段价格做了什么，参与度有没有跟上？”

EMA + Volume 强调“相对均价的方向”。Price + Volume 强调“这一根或这一段结构本身”。

### 观察顺序

1. 先用文字说出价格做了什么：突破前高、上影拒绝、收盘回到区间内、连续收窄。
2. 再看成交量是放大、缩小，还是只在影线那根突然放大。
3. 把两者合成一句观察，而不是合成一句指令。

### 共振

- 价格收盘离开整理区，同时成交量高于整理区内的均值：突破得到更多成交配合。这仍只是观察，突破失败同样常见。
- 长上影或长下影伴随明显放量：这一价位有过激烈成交。后续可能继续，也可能原路返回。
- 回撤过程缩量、再推进过程放量：参与度与价格节奏一致。

### 冲突

| 冲突 | 可能的读法 | 教学处理 |
|---|---|---|
| 价格越过前高，成交量低于前一轮推进 | 结构上像突破，参与度不足 | 称为“弱参与突破”，等待收盘或回踩后再谈前提 |
| 价格几乎不前进，成交量却很大 | 大量换手发生在原地 | 可能是争夺、也可能是对倒或清算；不能读成单边信号 |
| 连续阴线但成交量越来越小 | 价格仍在降，参与在退 | 可能接近暂时平衡，也可能只是无兴趣下跌 |

量价的“价涨量增、价跌量缩”是教科书口诀，只能当观察清单，不能当永续市场的规律。加密货币永续在恐慌时，经常出现价跌量增。

### 适用与失效

适用：结构清楚的突破、回踩、拒绝；成交量有稳定的近期参照。

失效：

- 插针后立刻恢复，成交量集中在影线，收盘价与盘中故事不同。
- 只看成交量颜色跟 K 线颜色，不看相对大小。
- 把 CVD、主动买卖与成交量混成一个指标。CVD 是另一层观察，本组合先把“总量”讲清。

## 两套组合的分工

| 问题 | 更合适的组合 |
|---|---|
| 现在还有没有均线方向？顺着方向推进时有没有人参与？ | EMA + Volume |
| 这一次突破、拒绝或停滞，有没有异常成交？ | Price + Volume |
| 这些成交是在加仓还是在平仓？ | 本组合回答不了，转到 OI |

同一课时可以两套都讲，但要明确：不是叠得越多越准，而是场景不同。

## 放入交易系统的位置

| 链路步骤 | 可以提供的观察 | 不能代替 |
|---|---|---|
| Market Regime | 均线分向或走平；成交是否活跃到足够交易 | 资金费率极端、持仓拥挤 |
| Direction | 价格相对 EMA 或相对结构高低点 | 动量是否过快（那是 RSI/MACD 的问题） |
| Setup | 回踩缩量、突破伴随相对放量 | 触发的精确规则 |
| Entry | 可把“收盘确认 + 成交量高于 N 根均值”写成可检查条件 | 止损与仓位 |
| 其后各步 | 无 | 风险与离场必须另写 |

成交量阈值如果写进系统，必须可复算，例如“大于最近 20 根成交量的平均值”。不要写“明显放量”。

## 常见误区

1. **放量等于看涨，缩量等于看跌。** 成交量没有方向。
2. **突破必须放量才算数，缩量突破一律当假。** 缩量突破和放量失败都存在。量只改变观察权重，不给真假盖章。
3. **用单根天量预测反转。** 天量可能是高潮，也可能是趋势加速的第一根。
4. **把不同交易所、不同合约的成交量加在一起比较。** 口径不一致。
5. **忽略时段。** 同一品种在不同交易时段的“正常量”不同。
6. **用成交量代替止损。** 参与度变弱不能告诉你认错价位在哪。

## 风险

- 短周期里按放量触发，交易次数会上去，手续费和滑点会侵蚀盈亏比。回测必须计入成本。
- 杠杆下，回踩缩量看起来“很安全”，但一根反向放量就可以打到止损或逼近强平。
- 数据源刷量或指数合约与单一交易所合约不一致时，量价阅读会失真。
- 本组合看不到持仓是否拥挤。价格仍在沿 EMA 上升、成交活跃，同时资金费率很高的情况，需要另一课处理。

## 给 Content Agent

- 先让学习者给成交量“去掉方向颜色”，再叠加价格或 EMA。
- 正案例：趋势推进放量、回踩缩量。反案例：放量滞涨、缩量跌破后迅速收回。
- 避免口诀化标题，如“量价齐升必涨”。
- “怎么使用”写成比较步骤：选参照区间 → 描述价格动作 → 比较成交量 → 判断共振或冲突 → 决定是否进入前提。
- 若要写规则示例，必须同时写失效环境和禁止条件。
- 图上标注“相对哪一段的平均成交量”，避免读者以为柱子高就是绝对标准。

## 给 Visual Agent 的图需求

- EMA 上行 + 推进放量 + 回踩缩量（示意图）
- 价格新高但成交量递减
- 放量但价格横盘
- 突破伴量 vs 突破缩量的对照（同一结构，不同量）
