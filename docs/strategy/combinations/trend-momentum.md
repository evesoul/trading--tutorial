# 趋势 + 动量

本文件是教学框架，不是教程正文，也不是交易信号。

课程位置：Part 2 指标组合的第一组。学习者应已理解 EMA、RSI、MACD 各自测量什么（定义以 `docs/knowledge/` 为准）。

覆盖两套观察：

- EMA + RSI
- EMA + MACD

## 教学目的

学完本框架后，Content 课时应让学习者能说明：

1. EMA 负责方向和位置，RSI / MACD 负责涨跌力度或力度变化。
2. 趋势和动量同向时，观察更清楚；反向时优先等待，而不是任选一边。
3. 震荡市里，均线来回穿越、动量指标反复交叉，是常见失效，不是“指标坏了”。
4. 这两套组合只进入交易系统的环境、方向、前提和触发层，不代替止损和仓位。

## 为什么把趋势和动量放在一起

价格可以沿一个方向移动，同时涨跌力度在加强或减弱。只看均线，容易忽略力度已经变弱；只看 RSI 或 MACD，容易在没有方向上下文时把超买、交叉当成反转指令。

趋势指标回答：“这段时间价格更偏向哪一侧？”
动量指标回答：“最近这段涨或跌，力度怎样？”

它们回答的是不同问题，所以适合作为入门组合。它们仍都来自价格，不是两份独立信息。

## 各指标回答什么问题

| 指标 | 主要回答 | 不负责回答 |
|---|---|---|
| EMA | 当前周期里价格相对均价的位置和均线方向，用来辅助判断环境和偏向 | 参与人数、持仓增减、拥挤程度、该在哪一价位止损 |
| RSI | 一段时间内上涨收盘与下跌收盘的相对强弱，用来观察力度是否过快或过弱 | 趋势是否成立、成交是否活跃 |
| MACD | 快慢均线差及其变化，用来观察力度是在扩张还是收缩 | 超买超卖的固定区间、持仓与资金费率 |

RSI 有上下界，适合讨论“相对过快”。MACD 无固定上下界，适合讨论“快慢均线差是否扩大”。两者都是动量视角，选一组与 EMA 搭配即可；同时堆上 RSI 和 MACD，见 [rsi-macd.md](./rsi-macd.md) 和 [multi-indicator.md](./multi-indicator.md)。

## 组合 A：EMA + RSI

### 观察顺序（不是下单顺序）

1. 先用 EMA 判断环境与方向：价格在均线哪一侧、均线向上还是走平、是否频繁穿越。
2. 再用 RSI 看力度：是顺着方向伸展、回到中轴附近，还是已经与价格结构不一致。
3. 最后才谈“有没有交易前提”。没有环境与方向，不解释 RSI 的高低。

### 共振

共振指两份观察指向同一方向上下文，仍不是开仓指令。

常见观察（教学用，需配正反图）：

- 价格在上行 EMA 之上，RSI 从高位回落后再抬头：更像趋势里的力度喘息，而不是单独的“超卖买入”。
- 价格在下行 EMA 之下，RSI 从低位反弹后再走弱：更像下跌过程中的力度再弱。
- 价格创新高且仍在 EMA 之上，RSI 同步走高：动量与方向暂时一致。

共振后仍要走完整链路：环境 → 方向 → 前提 → 触发 → 止损 → 止盈 → 仓位。

### 冲突

冲突时，默认降低仓位或空仓等待，而不是“相信更灵的那个指标”。

| 冲突 | 可能的读法 | 教学处理 |
|---|---|---|
| EMA 仍向上，RSI 一波比一波低 | 方向未改，力度在减弱 | 趋势可能变缓或进入震荡，不自动反手 |
| EMA 走平且反复穿越，RSI 在中轴上下摆动 | 缺少稳定方向 | 这套组合的前提不成立 |
| 价格贴近 EMA，RSI 已在极端区停留很久 | 强趋势里 RSI 可以长时间偏高或偏低 | 不能把极端值当成马上反向的理由 |

### 适用环境

- 价格大多数时间待在均线一侧，回踩后仍回到原侧。
- 波动足够让 RSI 出现回落或反弹，但又没有把均线打成一条锯齿。
- 学习者能先指出“现在像趋势还是像震荡”，再解释 RSI。

### 失效环境

- 窄幅震荡：EMA 走平，RSI 在 40–60 附近来回，容易把每一次摆动都当成机会。
- 消息驱动的长影线：收盘回到均线一侧，但盘中 RSI 已被瞬间推到极端。
- 单边急速行情：RSI 长时间停在高位或低位。此时“超买/超卖”作为反向依据失效。
- 周期错配：用很短周期的 RSI 去否定更长周期的 EMA 方向。

## 组合 B：EMA + MACD

### 观察顺序

1. EMA 判断环境与方向。
2. MACD 看快慢均线差：柱状图是在变长还是变短，零轴上下只表示快线相对慢线的位置，不是多空指令。
3. 金叉、死叉是观察点，用来问“力度是否转向”，不是用来自动开平仓。

### 共振

- 价格在上行 EMA 之上，MACD 在零轴上方且柱状图由短变长：方向与力度扩张一致。
- 价格在下行 EMA 之下，MACD 在零轴下方且柱状图向负向扩大：下跌力度仍在加。
- 价格沿 EMA 推进，MACD 回抽零轴附近后再次离开：更接近“趋势中的力度回撤”，仍需等待触发，不能把回抽本身当入场。

### 冲突

| 冲突 | 可能的读法 | 教学处理 |
|---|---|---|
| EMA 向上，MACD 柱状图缩短或下穿信号线 | 方向还在，短周期力度变弱 | 先问环境是否还在趋势，不立刻反手 |
| 价格仍在均线之上，MACD 已到零轴下方 | 中期均价偏向与快慢差不一致 | 可能转震荡或转势，属于等待区 |
| EMA 频繁穿越，MACD 连续交叉 | 两份价格平滑都在噪声里 | 组合失效，不是“再加一个指标就能修好” |

### 适用环境

- 有一段可持续的方向，快慢均线差能拉开，而不是贴在一起抖动。
- 学习者能区分“零轴位置”和“柱状图变化”是两个观察，不是同一个买卖点。

### 失效环境

- 震荡市：MACD 在零轴附近来回交叉，滞后且频繁。
- 突然跳空或插针后立刻反向：MACD 来自均线差，反应慢于单根 K 线。
- 把不同参数的 MACD 叠在同一张图上找“更准的那条”，属于过拟合观察，不是组合逻辑。

## 两套组合如何选择

| 更想观察的问题 | 更合适的搭配 | 代价 |
|---|---|---|
| 力度是否过快、是否回到中性区 | EMA + RSI | 强趋势里极端区可以持续 |
| 力度是在扩张还是收缩 | EMA + MACD | 交叉多、滞后更明显 |
| 既想看极端又想看扩张 | 不要默认两套一起上 | 容易重复同一份动量信息 |

入门教学建议先完整讲 EMA + RSI，再讲 EMA + MACD，最后用一小节对比：换掉的是动量的表达方式，不是又增加了一层“更准确的确认”。

## 放入交易系统的位置

| 链路步骤 | 本组合可以提供的观察 | 本组合不能代替 |
|---|---|---|
| Market Regime | EMA 走平还是分向、价格是否频繁穿越 | 波动制度、成交量枯竭、数据质量 |
| Direction | 价格相对 EMA 的位置与均线方向 | 更高级别结构的独立规则 |
| Setup | 回踩均线、RSI 回落未破坏方向、MACD 回抽未破坏零轴上下文 | 入场触发本身 |
| Entry | 可把“收盘回到均线一侧 + 动量重新顺着方向”写成触发 | 止损位置、下单方式 |
| Stop Loss 及之后 | 无 | 必须另写结构、比例或 ATR 规则 |

## 常见误区

1. **把 RSI 超买写成“该空了”。** 上升趋势里 RSI 可以反复进入高位。超买是力度过快的标签，不是反向指令。
2. **把 MACD 金叉写成“该多了”。** 没有环境时，金叉只是快慢差由负转正的观察。
3. **用动量指标去“预测顶和底”。** 这两套组合更适合讨论顺势中的力度变化，不适合当作抄底逃顶工具。
4. **EMA 周期随便换，直到图看起来顺眼。** 参数可以讨论，但必须先固定，再谈回测；否则无法复盘。
5. **冲突时挑选对自己持仓有利的那个指标。** 这是事后解释，不是系统。
6. **认为趋势加动量已经构成完整系统。** 还缺止损、止盈、仓位、禁止条件和复盘。

## 风险

- 永续合约带杠杆时，均线回踩过程中的来回穿越足以造成较大浮亏，甚至靠近强平。
- 动量指标都滞后于价格。等“共振看起来很清楚”时，价格可能已经走出一大段，这时若把止损放得很远，单笔风险会被放大。
- 两套组合都无法处理持仓拥挤、资金费率极端、流动性突然变差。这些要另看 [funding-oi.md](./funding-oi.md) 和风险管理文档。
- 教学案例里的一次顺畅走势，不能代表这套观察在其他区间仍适用。

## 给 Content Agent

- 课时标题避免“EMA+RSI 战法”“稳准组合”一类措辞。
- 先用一个生活类比讲清“方向”和“速度”不同，再出图。
- 每套组合至少两张图：一张趋势中动量回落后再顺着走，一张震荡中交叉和超买超卖反复出现。
- 讲解超买、金叉时，原文保留“观察工具”四个字或同等表述。
- 不要给出具体下单清单。若写“怎么使用”，写成观察步骤，并指向系统模板第 4–7 节。
- 术语：首次出现“超买/超卖、金叉/死叉、零轴、柱状图、回踩”时用一句话解释。
- 需要 Visual 时，分别申请趋势共振示意图、震荡失效图、冲突对照图。真实行情图标注 symbol、timeframe、source、period。

## 给 Visual Agent 的图需求（规格，不是出图）

- 趋势中价格在 EMA 之上、RSI 回落后再抬头（示意图或真实行情）
- 趋势中 RSI 长时间停留高位（用来讲失效）
- EMA 走平、MACD 零轴附近连续交叉
- EMA 向上但 MACD 柱状图缩短的冲突对照
