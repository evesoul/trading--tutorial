# RSI + MACD

本文件是教学框架，不是教程正文，也不是交易信号。

先修：[trend-momentum.md](./trend-momentum.md)。RSI 与 MACD 都属于动量观察。本课的核心不是“两个动量一起用更稳”，而是：**它们常常在回答同一个问题。**

## 教学目的

1. RSI 看一段收盘涨跌的相对强弱，有上下界。
2. MACD 看快慢均线差及其变化，无固定上下界。
3. 两者同向，常常只是同一段价格被算了两次，不构成独立确认。
4. 两者冲突时，优先回到市场环境和价格结构，而不是再找第三个动量指标来投票。
5. **硬约束：冲突时回结构 / 环境，不要再叠 KDJ 或第三把动量尺。** 周期打架见 [multi-timeframe.md](../multi-timeframe.md)。本文件不扩写成新课。

## 各指标回答什么问题

| 指标 | 主要回答 | 表达特点 | 不负责回答 |
|---|---|---|---|
| RSI | 这段时间里上涨收盘相对下跌收盘有多强 | 有界，便于谈“相对过快或过慢” | 趋势是否成立、成交与持仓 |
| MACD | 快速均价相对慢速均价的差距，以及差距是否在扩大 | 无界，便于谈“力度扩张或收缩” | 固定的超买超卖区间、拥挤程度 |

它们的共同来源都是价格。没有成交量、OI、资金费率时，本组合无法讨论参与度和拥挤。

差别在于平滑方式和是否有界，不在于“一个看趋势、一个看买卖点”。把 MACD 当成趋势指标、把 RSI 当成反转指标，是常见错位。MACD 来自均线差，只能算带滞后的动量；RSI 也不是反转开关。

## 为什么还要并排看

并排看的正当理由只有这些：

- 检查自己是否把“有界的相对强弱”和“均线差的扩张”当成了两件独立证据。
- 观察同一段行情里，两种平滑是否同时变弱或同时变强。
- 作为反面教材：说明确认偏差是怎么发生的。

不正当理由：

- 金叉加上 RSI 离开 30，就当作双重确认开多。
- 认为两个指标都来自价格，所以“更不容易错”。来源相同不会降低价格本身的不确定性。

## 共振

共振在这里要降级理解：更像“同一份动量的两种画法一致”，不像“两个独立证人说了同样的话”。

- RSI 上行且 MACD 柱状图伸长：力度在两种平滑下都表现为加强。
- RSI 从高位回落且 MACD 柱状图缩短：力度在两种平滑下都表现为减弱。
- 价格新高，RSI 与 MACD 都未同步新高：两种平滑都显示这段上涨的力度弱于前一段。这叫动量背离观察，仍不是反转指令。

教学上每讲一次共振，都补一句：如果只保留其中一个指标，结论是否仍相同？若相同，第二个指标没有提供新问题的答案。

## 冲突

| 冲突 | 可能的读法 | 教学处理 |
|---|---|---|
| RSI 已到高位，MACD 仍在零轴上方伸长 | 有界指标显示相对过快，均线差仍在扩大 | 强趋势里两者本来就会不同步，回到 EMA 或结构 |
| MACD 死叉，RSI 仍在中轴上方 | 快慢差转负，相对强弱尚未转弱 | 不要用其中一个去宣布趋势结束 |
| RSI 出现背离，MACD 没有 | 回看长度和算法不同 | 背离不是投票器；一个有、一个没有，不能折中成“半个反转” |
| 两者同时频繁交叉、进出 50 | 可能处于震荡 | 先改环境判断，不要微调参数让它们重新对齐 |

冲突时的规则：回到 [trend-momentum.md](./trend-momentum.md) 的做法，用趋势工具给方向，动量只描述力度。两个动量互相投票，没有裁判。**不要再叠 KDJ、随机指标或其他第三把动量尺来打破平局。**

## 适用环境

- 作为“动量指标如何重复”的专题课，放在趋势 + 动量之后。
- 用来训练学习者拆问题：这张图上有几个独立问题，还是一个问题画了两次。
- 在已经用 EMA 或结构完成环境和方向之后，选择 **RSI 或 MACD 其中一个** 描述力度。

## 失效环境

- 把本组合当成主策略骨架。缺少环境时，两个动量会一起在震荡里来回打脸，或一起在趋势里过早喊反转。
- 再加入 KDJ、随机指标等更多有界动量，用多数决。这会把重复信息伪装成民主。
- 为了让 RSI 与 MACD 同时金叉才开仓：条件越严，样本越少，越容易只记住那几次好看的图。

## 放入交易系统的位置

| 链路步骤 | 建议 | 不建议 |
|---|---|---|
| Market Regime | 不由本组合决定 | 用 RSI 进 70 或 MACD 零轴定义趋势 |
| Direction | 交给价格结构或 EMA | 两个动量投票决定方向 |
| Setup / Entry | 最多保留一个动量条件 | RSI 与 MACD 同时满足才触发 |
| 其后各步 | 无 | 用背离代替止损 |

若一套系统已经包含 EMA + RSI，就不要再把 MACD 交叉写成第三条入场条件，除非能证明 MACD 在回答一个 RSI 回答不了的新问题。通常证明不了。

## 常见误区

1. **两个动量同时确认，准确率会提高。** 本项目明确反对这一点。详见 [multi-indicator.md](./multi-indicator.md)。
2. **RSI 管超买超卖，MACD 管金叉死叉，所以职责不同。** 那是形态名字不同，问题仍是动量。
3. **背离叠加背离更可靠。** 两种算法的背离仍来自同一段价格。
4. **冲突时再看 KDJ 来打破平局。** 又增加一个高度相关的动量。
5. **参数调到历史图上每次转折都对齐。** 这是拟合图画，不是发现规律。

## 风险

- 重复确认会让人提高杠杆或放大仓位，因为“两个指标都同意”。账户风险来自止损距离和仓位，不来自同意的指标个数。
- 震荡市里双动量会给出很多看起来很完整的交叉，交易次数和手续费上升。
- 趋势市里双动量会一起过早提示减弱，诱发频繁止盈后又踏空，或频繁反手。
- 学习者若在这一课形成“指标越多越踏实”的习惯，后面的多指标课会很难纠正。

## 给 Content Agent

- 本课建议做成“纠错课”：先展示一张双指标都很整齐的图，再揭开“去掉其中一个，故事不变”。
- 用叠图作业：同一段行情只留 RSI、只留 MACD、两者都留，让学习者写“新得到了什么信息”。
- 不要设计“RSI + MACD 买入步骤”。
- 冲突段只加一句硬约束：回结构 / 环境，不要再叠 KDJ 或第三把动量尺。不要扩写成新课。
- 可以给一句允许的用法：“若你更习惯看有界指标，用 RSI；若你更习惯看扩张收缩，用 MACD。不要两个都当确认。”
- 正案例不是盈利案例，而是“识别出信息重复”的案例。反案例是“两个指标投票后仍然失败”。
- 禁止把本课放进“高胜率组合”系列。

## 给 Visual Agent 的图需求

- 同一段趋势：上格价格，下格 RSI，再下格 MACD，标注两者同步
- 同一段去掉 RSI 或去掉 MACD 的对照（示意图）
- 震荡中双交叉密集
- 一个有背离、一个没有背离的对照，标题写“算法不同，不是第二个证据”
