# 资金费率 + 持仓量（Funding + OI）

本文件是教学框架，不是教程正文，也不是交易信号。

先修：永续合约与资金费率的概念（Knowledge），以及 [price-oi.md](./price-oi.md)。本组合只在 U 本位永续语境里有意义。现货没有资金费率。

## 教学目的

1. 资金费率回答“现在谁在为持仓付费，多头和空头谁更拥挤、持有成本多高”。
2. OI 回答“这些付费发生在多大的仓位存量上”。
3. 高费率不是倒计时反转器。拥挤可以维持很久，也可以突然释放。
4. 本组合主要用于风险过滤和持有成本意识，不用于寻找开仓点。

## 各指标回答什么问题

| 观察对象 | 主要回答 | 不负责回答 |
|---|---|---|
| Funding Rate | 多头还是空头在支付资金费；持有该方向的成本是否偏高 | 价格何时反向、OI 有多大 |
| OI | 未平仓规模以及它在扩大还是收缩 | 谁在付费、费率是否极端 |
| Price（上下文） | 拥挤是出现在上涨后、下跌后还是横盘里 | 单靠价格看不到持有成本 |

资金费率为正，通常表示多头向空头支付；为负则相反。具体结算规则以交易所和 Knowledge 条目为准。教学只强调：它是持有成本与拥挤程度的观察，不是涨跌预测。

极端与否必须相对该品种自己的历史分布来谈，不要写死“高于某百分数就是顶部”。不同品种的常态费率差异很大。

## 观察框架

把费率和 OI 同时看，是为了区分“少数人在付费”和“很多人在付费”。

| Funding | OI | 教学读法 | 不能推出的结论 |
|---|---|---|---|
| 明显偏正 | 上升或已经很高 | 多头拥挤且存量大，多头持有成本高 | 价格即将下跌，该开空 |
| 明显偏正 | 下降 | 多头仍在付费，但仓位在减少 | 拥挤已经解除，或空头已经胜利 |
| 明显偏负 | 上升或已经很高 | 空头拥挤且存量大，空头持有成本高 | 价格即将上涨，该开多 |
| 接近零 | 上升 | 仓位在增加，但费率还没有显示一边倒的拥挤 | 趋势更健康、可以加大仓位 |
| 极端费率 | OI 急速下降 | 拥挤可能正在通过平仓或清算释放 | 释放结束、可以抄反向 |

“明显”“极端”在系统里若要使用，必须改成可检查的定义，例如相对该合约过去 N 个资金费周期的分位。框架课只讲逻辑，不给全市场统一阈值。

## 共振

对本组合，共振指：拥挤方向和仓位规模指向同一风险画面。

- 价格已大涨，费率为正且偏高，OI 同步升高：多头拥挤风险上升。教学重点是“继续持有多头的成本与拥挤风险”，不是“做空信号出现了”。
- 价格已大跌，费率为负且偏低，OI 同步升高：空头拥挤风险上升。同样不是自动做多。
- 费率从极端回到常态，同时 OI 下降：拥挤释放过程。它解释“刚才为什么波动大”，不告诉人现在该反向开仓。

## 冲突

| 冲突 | 可能的读法 | 教学处理 |
|---|---|---|
| 费率极端，但 OI 很低或在下降 | 拥挤更多停留在费率上，存量并不大 | 不要用费率单独宣布顶部或底部 |
| OI 很高，费率接近零 | 市场很大，但多空支付尚未一边倒 | 高 OI 是规模，不是拥挤方向 |
| 价格继续沿拥挤方向走，费率越来越极端 | 拥挤可以自我加强 | 这是本组合最重要的失效：费率可以在趋势里维持极端 |
| 不同交易所费率符号相反 | 套利资金、资金费机制差异 | 不要把单一交易所费率当成全市场情绪 |

冲突时默认：本组合只调整风险评价（是否允许加仓、是否缩短持有、是否提高对滑点的警惕），不单独改方向。

## 适用环境

- 学习者已经知道永续为何存在资金费：让合约价格贴着现货。
- 讨论持仓数小时到数天的场景。资金费按周期结算，用它做超短线触发通常不匹配。
- 能展示同一品种在趋势中费率维持偏高的例子，用来打破“极端即反转”。

## 失效环境

- 把资金费当成 RSI 那样的超买超卖指标。
- 忽略结算周期：费率数值、预测费率和已结算费率被混用。
- 只看当前一根费率，不看它持续了几个周期。
- 新品、低流动性合约上，少量仓位就能把费率打到看起来很极端。
- 用费率解释现货，或用现货情绪解释费率，却不说明二者机制不同。

## 放入交易系统的位置

本组合在链路里更靠近 **Market Regime 的风险过滤** 和 **Position Size / 禁止条件**，而不是 Direction 或 Entry。

| 链路步骤 | 可以提供的观察 | 不能代替 |
|---|---|---|
| Market Regime | 是否处于一边倒的拥挤；持有成本是否已经很高 | 趋势或震荡的价格定义 |
| Direction | 不提供方向。拥挤方向常常与正在进行的价格方向相同 | 结构或均线规则 |
| Setup | 可作负面过滤：拥挤同向时，不把“追趋势加速”当前提 | 入场触发 |
| Entry | 不建议作为触发 | 避免“费率转负就开多” |
| Position Size | 拥挤同向时降低风险预算或缩短计划持有时间 | 具体仓位公式仍见仓位文档 |
| 禁止条件 | 费率数据缺失、跨所费率混乱、结算前后无法可靠估价 | — |
| Stop Loss / Take Profit | 不提供价位 | 成本应计入回测，见 [backtest.md](../backtest.md) |

系统里如果写“资金费过高则不开同向新仓”，这是风险规则，不是预测规则。

## 常见误区

1. **费率转正就是顶部。** 上涨趋势里费率可以长时间为正。
2. **负费率是抄底信号。** 下跌里空头拥挤可以持续，价格仍可再跌。
3. **OI 高 + 费率高 = 稳妥的反向单。** 反向单同样会被趋势再走一截打到爆仓。
4. **只比费率绝对值，不比该品种自己的历史。**
5. **忽略资金费本身就是交易成本。** 方向判断对了，持有过久仍可能被费率磨损。
6. **把预测资金费当成已经结算的费用。**

## 风险

- 这是最容易被写成反向喊单的一组观察。Content 必须反复落到“过滤与成本”，而不是“反向开仓”。
- 拥挤释放时波动常突然加大。高杠杆账户可能在解释完成之前就被强平。
- 资金费每隔一个周期都会改变账户权益，回测若只算开平手续费，会高估持有型规则。
- 低流动性品种上，费率极端可能来自很少的仓位，反向时滑点很大。

## 给 Content Agent

- 先用一小节讲清：永续为什么要有资金费，它不是奖惩谁对谁错。
- 用“电影院票很贵且座位都满了”类比拥挤：票价高不代表电影马上散场。
- 正反案例必须成对：费率偏高后价格继续走、以及拥挤释放时的剧烈回撤。两者都只用于解释机制。
- 课程结尾给学习者的作业应是：“指出持有成本变高了没有”，而不是“写出开空条件”。
- 禁止用语之外，再避免“捕捉空头挤压”“必反向”一类标题。
- 下一步可回到多指标共振：强调本组合是风险层，不要和第 4 个动量指标叠成“更准”。

## 给 Visual Agent 的图需求

- 费率轴 + OI 曲线 + 价格（三栏，示意图）
- 趋势中费率维持偏高的案例（真实行情，完整元数据）
- 拥挤释放：费率回落同时 OI 下降、波动加大
- 标注结算周期，避免读者把连续曲线当成每分钟都在结算
