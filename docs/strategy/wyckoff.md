# 威科夫读图在交易系统里的位置

本文件只划边界，不颁布可跟单规则。定义见 `docs/knowledge/wyckoff.md`。

## 它回答哪一类问题

威科夫四阶段回答：**当前更像区间内测试，还是已经离开区间。**  
量价回答：**这次努力有没有换来位移。**  
永续过滤器回答：**插针、费率、清算有没有让这次观察降级。**

它们不回答「现在该开多还是开空」。方向仍按阶段 3 的 [方向判断](../product/learning-path.md) 链路：环境 → 多周期 → 方向 → 订单。

## 与已有系统课的分工

| 已有课 | 威科夫模块补什么 | 不重复什么 |
|---|---|---|
| 摆动结构 | 把 HH/HL 放进吸筹 / 派发区间 | 不重写摆动点怎么标 |
| 成交量 | 努力 vs 结果、相对 20 均量 | 不重讲成交量公式 |
| 多周期 | 日线定阶段、4H 定事件、15m 只触发 | 不另开第二套周期理论 |
| 仓位管理 | 深针时 S 变大、N 变小 | 不重开 `N = R / S` 专篇 |
| 资金费率 / 清算瀑布 | 拥挤与假努力过滤器 | 不把费率写成反转指令 |

## 教学上允许的「练习记法」

课文可以示范：

- 先定阶段，再谈事件
- 缺收盘确认则降级
- 量价冲突时仓位系数下降或空仓
- 过滤器用来否决满仓，很少单独反向开仓

课文不可以：

- 把 Spring / SOS / UTAD / SOW 写成确定性买卖信号
- 用一段历史盈利证明方法有效
- 鼓励高杠杆或「心里止损」
- 颁布「必须 5x」一类杠杆指令；数字只作账户作业纸示例

## 在系统模板里填哪几格

若读者把威科夫写进自己的系统，建议只占用：

1. 市场环境：四阶段或「不明」
2. 多周期：决策周期（日线 / 4H）与执行周期
3. 入场前提：事件名称 + 收盘 + 量价
4. 禁止条件：结算窗口、标记价撕裂、清算当根、阶段不明

止损、仓位、热度、复盘仍用阶段 3 原文。一次只改一条规则，见系统优化课。
