# 风险管理

本文件是教学框架，不是风控软件，也不是仓位推荐。

Part 3 里，风险管理要在“感觉行情很好”之前出现。指标组合不降低爆仓速度；杠杆和仓位才会。

配套：[position-sizing.md](./position-sizing.md)、[backtest.md](./backtest.md)、[cost-vs-r.md](./cost-vs-r.md)、[execution.md](./execution.md)、[system-template.md](./system-template.md) 第 7、9、10 节。账户热度细则写在本文件；Content 的 `account-heat` 课转写这里，不另开策略一级主题。

## 教学目的

1. 风险先被定义，交易才能被重复。没有单笔风险上限，就没有可回测的系统。
2. 永续合约除了价格亏损，还有杠杆、强平、资金费、滑点。
3. 风险管理回答“错了能活下来吗”，不回答“对了能赚多少”。
4. 高杠杆不是效率，是把同一错误更快推到强平。本项目不鼓励高杠杆。

## 先分清几层风险

| 层级 | 问题 | 典型后果 |
|---|---|---|
| 单笔风险 | 这一笔如果打到止损，账户权益会少多少 | 一次亏损过大 |
| 同向/同类风险 | 几笔其实押了同一段行情 | 看起来分散，实际一起亏 |
| 账户热度 | 所有未平仓计划风险加总后，账户同时暴露多少 | 多笔「每笔只亏一点」叠成一次大亏 |
| 账户回撤 | 一段时间累计亏了多少 | 后面即使规则还在，执行也会变形 |
| 爆仓风险 | 保证金是否还够维持仓位 | 未到计划止损就被强制平仓 |
| 生存风险 | 连续亏损或极端行情后还能不能按原规则交易 | 账户过小或心态崩溃后开始即兴下单 |

教学顺序：单笔 → 账户 → 爆仓 → 禁止条件。不要一上来讲复杂公式。

## 单笔风险

单笔风险是：

> 入场价到止损价的距离 × 仓位数量，再换成账户权益的百分比。

它必须在开仓前算完。开仓后才“看情况设止损”，风险没有被定义。

教学原则：

- 先写止损，再写仓位。见仓位文档。
- 单笔上限用账户权益的一小部分来表达，而不是用“这回很有把握，可以多一点”。
- 共振、多个指标对齐，不能成为提高单笔风险的理由。见 [combinations/multi-indicator.md](./combinations/multi-indicator.md)。
- 具体百分比由学习者在系统模板里自己写，并在回测里检查连续亏损后是否还能执行。本框架不颁布“标准仓位”。

永续里还要检查：计划止损价是否仍远于预估强平价。如果强平价更近，真实风险不是你写在纸上的止损，而是强平。

## 账户热度与相关品种

热度（教学定义）：

> 当前所有未平仓仓位的**计划风险**之和，按 R 或按权益百分比加总。

计划风险是入场到计划止损的亏损金额，不是保证金占用，也不是「我觉得亏不到」。三笔各 1%、同一方向或都跟 BTC 波动，账户风险按相关后不是 1%。

检查方法（写进模板第 9 节）：

1. 列出每笔：品种、方向、单笔计划 R、与 BTC 是否同向。
2. 把同向、或都随 BTC 同向波动的计划 R 加总。
3. 与事先写死的热度上限比较。碰到上限：先平、先减、或禁止开新仓，动作事先写死。

**BTC 是多数 U 本位山寨的共同风险因子。** 换交易对不是自动分散。同时开 5 个山寨多头、每笔「只亏 1%」，常见结果是 BTC 一跳，五笔一起接近止损。教学上把它们看成同一风险篮子，而不是五个独立赌注。

本框架不教组合对冲公式、期权或推荐品种篮子。相关如何折算，由学习者在第 9 节自己写可检查的规则（例如「与 BTC 同向的山寨，按满额计入热度」）。写不出折算句时，默认满额加总。

正例：已有一笔 BTC 偏多 1R，ETH 同向只允许加到热度上限以内，否则不做。  
反例：换几个山寨就认为风险已经分散。

Content 的账户热度课转写本节，不要再发明第二套热度公式。

## 账户与连续亏损

即使每一笔都遵守单笔上限，连续亏损也会把权益打出一条回撤。回测必须记录最大回撤和最长连亏，见 [backtest.md](./backtest.md)。

系统模板第 9、10 节应写清：

- 单日亏损达到多少后，当天不再开新仓
- 连续亏损达到多少笔或多少 R 后，暂停并复盘
- 账户回撤达到多少后，降低单笔风险或停机
- 热度上限碰到后的动作

这些是刹车，不是认输。没有刹车的规则，遇到一连串正常亏损就会被执行者改掉。

## 回撤恢复算术

亏损百分比和赚回百分比不对称。这是算术，不是收益承诺，也不能代表未来。

教学演算（权益从 10,000 起，只演示恢复倍数）：

| 先亏掉 | 剩余权益 | 要回到原权益，需要再涨 |
|---|---|---|
| 10% | 9,000 | 约 11.1% |
| 20% | 8,000 | 25% |
| 33% | 约 6,700 | 约 50% |
| 50% | 5,000 | 100% |

亏 20% 之后，不是「再赚 20% 就平」，而是剩余部分要涨 25%。回撤越深，恢复所需的涨幅越大。因此第 9、10 节的回撤刹车，是在保护「还能按原规则做下去」，不是在讨论怎样快点赚回来。

为回本而加仓、加杠杆，等于在剩余更小的权益上放大下一步的亏损百分比。见下方执行偏差。

## 杠杆与爆仓

杠杆决定你用多少保证金去支撑名义仓位。它不决定这笔交易“对不对”。

需要教清的事实：

- 名义仓位相同、止损相同，则单笔价格风险相近；杠杆更高只是保证金更少，强平更近。
- 强平是交易所规则下的强制离场，成交价可能劣于计划止损，尤其在剧烈波动里。
- 维持保证金、标记价格、资金费扣减都会移动强平距离。细节以 Knowledge 的永续条目为准。
- 高杠杆把正常噪声变成生存事件。教学案例若展示杠杆，只能用来说明爆仓路径，不能用来展示“小本金放大收益”。

本项目表述要求：不鼓励高杠杆；不把低保证金占用写成优点而不提强平。

## 永续合约额外风险

| 项目 | 为什么算风险 | 教学处理 |
|---|---|---|
| 资金费 | 持有期间周期性支付或收取，改变权益 | 持有超过一个结算周期的规则，回测必须计入 |
| 滑点 | 成交价与信号价不同 | 市价止损、清算时尤其明显 |
| 流动性 | 点差变宽、薄订单簿 | 写入禁止条件 |
| 数据中断 | 指标或 OI、费率缺失 | 不做，或只平不开 |
| 相关品种连动 | BTC 波动带动一篮子 | 多开几个山寨不等于分散 |
| 机制与活动 | 结算、下架、补贴拉量 | 不套用平时的量价读法 |

## 禁止交易条件

与系统模板第 10 节对齐。建议课时用清单，而不是散文。

市场侧：

- 无法为计划仓位挂出可靠止损
- 点差或滑点估计已经大到接近单笔风险本身
- 成交量、OI、资金费数据缺失或口径突变
- **连续强平**：盘口一跳数个点、连锁平仓进行中，不套用平时的量价或 CVD 读法
- **事件**：重大公布、上币/下架、结算窗口前后，是否禁止开新仓事先写死
- **周末与假期**：流动性变薄、点差变宽时，是否缩小到只平不开

账户侧：

- 达到日亏损、连亏或回撤限制
- 热度已到上限
- 权益已小到“按原止损距离算出的仓位低于最小下单量”，却仍想硬做

执行侧：

- 规则读完仍需要现场解释
- 决策周期与自己能盯盘的时间不匹配
- 无法确认止损看最新价还是标记价，或无法挂只减仓

主观侧 / 执行偏差（每条对应日志字段 + 事先动作，不写成鸡汤）：

| 偏差 | 事先动作 |
|---|---|
| 错过触发后市价追 | 视为条件不成立，记日志，当天不再用同一触发 |
| 浮盈怕还回去，提前平 | 走止盈句；未到句则留下，复盘再改句 |
| 浮亏把止损往远处拖 | 视为改规则，记违规笔，不进规则成绩 |
| 赢了加频率、输了加仓位 | 走频率 / 热度刹车 |
| 为回本加仓、因共振加杠杆 | 禁止条件，空仓 |
| 把「看对」当成身份，不肯止损 | 触及即走；否决止损的副图理由无效 |
| 切到更能讲通的周期 | 视为换系统，停机，不进原规则成绩 |

触发后的动作预先写好：空仓、只平不开、或转到复盘作业。不要写“灵活处理”。不教冥想或成功学。

## 与指标组合的关系

指标组合可以提供环境和过滤，不能提供风险上限。

| 组合观察 | 风控上可以做的 | 不可以做的 |
|---|---|---|
| 趋势与动量冲突 | 不满足 Setup，空仓 | 立刻反向加杠杆 |
| 放量但 OI 下降 | 不把突破当趋势加速 | 认定顶部已现 |
| 费率极端且 OI 高 | 禁止追同向、降低持有时间 | 当作稳妥反向信号 |
| 多指标对齐 | 仅说明画面清楚 | 提高单笔风险 |

## 常见误区

1. **止损很近，所以风险很小。** 止损近只说明距离短；若仓位按“能开多少开多少”，单笔风险仍然很大，且更容易被扫。
2. **不设止损，改用“心态很好”。** 永续里这会直接通向强平。
3. **亏了就加仓摊平。** 这是把单笔风险改写成未知的账户风险。
4. **回测胜率高，所以可以加大杠杆。** 胜率不描述连亏和回撤。
5. **风险已经用对冲或很多品种分散掉了。** 同一风险因子上的多个仓位仍会一起动。换交易对不是分散。
6. **亏 20% 再赚 20% 就回来了。** 恢复算术是 +25%；更深的回撤需要更大的涨幅。这是算术，不是盈利保证。
7. **热度是保证金用了多少。** 热度是计划风险之和。保证金低只说明杠杆高、强平更近。
8. **教育站点的规则示例可以拿去实盘。** 本项目不提供实盘建议。

## 给 Content Agent

- 开篇先讲爆仓和单笔风险，再讲任何“怎么看图”。
- 用“汽车刹车距离”类比：先知道刹得住，才谈开多快。
- 至少准备一个“计划止损远于强平价”的反例，说明纸面止损无效。
- 热度用加总作业：已有 BTC 多头 1R，再开同向 ETH 时热度怎么变。Content `account-heat`（TASK-037）转写本节，不要另编公式。
- 事件 / 周末 / 连续强平写成清单，不要散文。
- 回撤恢复用「亏 20% 需 +25%」这道教学算术，标明不是收益承诺。
- 执行偏差用表，每行「偏差 → 日志字段 → 事先动作」。`execution-bias`（TASK-037）转写上表。
- 不要给出“建议杠杆倍数”。可以给出检查清单：强平价、止损价、单笔权益百分比、热度上限。
- 禁止把风控课写成“只要风控好就能长期盈利”。风控提高的是生存概率的讨论质量，不消除亏损。
- 作业：让学习者用系统模板第 7、9、10 节各写三条自己的刹车，并写一句热度上限动作，而不是抄一串指标条件。
