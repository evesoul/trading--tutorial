# 多指标共振

本篇收束阶段 2。核心命题：**不是指标越多越准确。**

先修至少读完 [趋势 + 动量](/combinations/trend-momentum)。建议把前六篇也读完：[趋势 + 成交量](/combinations/trend-volume)、[RSI + MACD](/combinations/rsi-macd)、[价格 + OI](/combinations/price-oi)、[OI + Volume](/combinations/oi-volume)、[Funding + OI](/combinations/funding-oi)。本课不补讲公式，只练分工。

**共振（教学定义）**：在已经识别的市场环境里，方向、力度、参与度或拥挤程度等**不同维度**的观察没有互相否定。

不叫共振：

- RSI、MACD、KDJ 同时金叉
- 5、10、20、60 周期均线全部排成一个方向，就当作四重确认
- 把同一根 EMA 的斜率、MACD 零轴、价格新高数三遍

后一类只是同一份价格信息的重复采样。重复采样不能降低未来的不确定性，却容易提高主观信心，从而加大杠杆。这是本课要拆开的习惯。

类比：问三个不同的人「路往哪、车多不多、票贵不贵」，得到相近画面，叫对照。问三个看同一块时速表的人，再数一次票，叫重复。证人变多，不等于路况更清楚。

## 学习目标

读完本篇，你应该能：

- 用自己的话说：共振是多个不同问题得到相近答案，不是条件越多越可靠
- 先填问题槽，再选指标；一个问题槽只留一个代表
- 在堆满副图的画面上，删到最多三个问题槽
- 冲突时选择等待或空仓，而不是加第 6 个指标投票
- 把止损和仓位留在指标层之外，不因为对齐就省略风控

## 概念

每个指标只占一个问题槽。先填问题，再选代表。

| 问题槽 | 要回答的问题 | 可选代表（择一） | 常见重复项（不要再堆） |
|---|---|---|---|
| 环境 / 方向 | 现在更像趋势还是震荡，偏向哪一侧 | 价格结构，或一条 / 一组 EMA | 再加 MA，再加一条同向 MACD 当趋势 |
| 力度 | 涨跌是在加强还是减弱，是否过快 | RSI **或** MACD | RSI + MACD + KDJ |
| 参与度（流量） | 成交是否相对活跃 | Volume | 多交易所混加的总量、未解释的 CVD |
| 仓位存量 | 未平仓在增还是在减 | OI | 把 OI 再解释成方向指标 |
| 拥挤与持有成本 | 谁在为持仓付费，存量大不大 | Funding，并与 OI 对照 | 把费率当反向计时器 |
| 风险与执行 | 亏得起多少，错了在哪退 | 止损、仓位、禁止条件 | 任何指标都代替不了这一槽 |

表里「可选代表」不是推荐参数，是分工示例。

教学上建议的上限：

1. 一个环境 / 方向工具
2. 一个力度工具（可空）
3. 一个参与度或存量工具（可空）
4. 风险规则（必有，且不是指标）

例如：EMA + RSI + Volume，再加止损与单笔风险。  
例如：价格结构 + OI + Funding 过滤，再加止损与单笔风险。

不建议：EMA + MA + MACD + RSI + KDJ + 布林带 + Volume + OI + Funding 全部亮绿灯才开仓。条件看起来很严，实际要么几乎没有样本，要么只是在拟合一段历史。

它回答：我现在问了几个**不同**的问题，它们有没有互相否定。

它不回答：入场价已经出现、胜率更高、可以放大仓位或提高杠杆、可以省略止损。

## 观察步骤

1. **先写环境。** 更像趋势、震荡，还是波动突然放大。没有环境，后面的格子没有上下文。
2. **列出你图上的每一个指标，把它填进问题槽。** 两个指标进了同一槽，删到只留一个。
3. **看不同槽有没有互相否定。** 没有互相否定，只说明画面比较清楚，可以进入「是否存在交易前提」的讨论。
4. **仍要等入场规则，仍要先写止损，再谈仓位。** 共振只覆盖链路前半：环境 → 方向 → 前提 → 触发。
5. **若因为对齐就想多开一点，停下来。** 这是仓位纪律问题，不是指标问题。
6. **冲突时按下面的顺序处理，不要加图层。**

冲突指：两个**不同问题槽**给出难以同时成立的画面，或同一槽内部的代表互相打架。

处理顺序：

1. 先问是不是同一槽在重复。同一槽冲突，删到只留一个代表。
2. 不同槽冲突（例如方向仍上、参与度明显变弱、拥挤已经极端）：前提不成立，默认等待或空仓。
3. 不要引入第三个同类指标来投票。
4. 已经持仓时，冲突用来检查离场规则是否被触发，而不是即兴反手。

| 冲突例子 | 槽 | 处理 |
|---|---|---|
| EMA 向上，RSI 与 MACD 一个强一个弱 | 力度槽内部重复 | 只保留一个力度工具 |
| EMA 向上，成交量递减，OI 下降 | 方向 vs 参与 / 存量 | 不把上行当成加速前提 |
| 价格创新高，费率极端且 OI 很高 | 方向 vs 拥挤风险 | 降低风险预算或禁止追单，不是自动开空 |
| 短周期动量向上，长周期结构向下 | 周期未对齐 | 先统一决策周期，再谈组合 |

## 正反案例

下面两段必须对照着看。它们是教学情景，不是真实行情，不能代表未来结果。

### 正例：三个不同槽一致，仍写止损，后来仍可能失败

环境：价格大多数时间在上行 EMA 之上。  
力度：你只保留 RSI，它从高位回落后再抬头。  
流量：推进段成交量高于你选的近期均值。  
拥挤：本例先不看费率，或费率未显示极端一边倒。

三个不同槽没有互相否定。你写下：画面比较清楚，可以讨论是否存在交易前提。你同时写下止损价位和单笔最多亏多少。随后价格仍可能折返，打到止损。

这是正例：分工清楚，并且你没有因为对齐就省略风控。正例包含「后来仍可能失败」。失败不证明格子填错了，只说明共振不是胜率放大器。

### 反例：五个动量指标一致后继续震荡

图上同时开着 RSI、MACD、KDJ，再加两条均线的金叉。它们几乎同时抬头。有人写成「五重共振，开多」，并提高杠杆。随后价格仍在区间里来回，五把尺子一起金叉、一起死叉。

这是同一槽的重复采样。一致提高的是信心，不是新信息。震荡里，重复的动量会一起给出很多看起来很完整的交叉。

另一幅：方向、力度、流量都对齐，同时费率极端且 OI 很高。有人写成「都同意了，追加速」。不同槽其实已经冲突：拥挤风险在否定「追加速」这个前提。正确处理是降低风险预算或禁止追单，不是自动开空，也不是假装没看见费率。

再补一条过严过滤：要求上面所有格子加费率、加 OI、加布林带同时亮绿灯。历史图上只剩下很少几段。很少交易的漂亮成绩更容易是运气。过滤变严，风险也不会变成零。

## 常见错误

1. 指标越多越准确。相关指标增加的是信心，不见得会增加新信息。
2. 全部对齐才做，所以很安全。过滤过严会剩很少交易。
3. 多数指标同意就可以加大杠杆。杠杆放大的是亏损速度。永续有爆仓。
4. 冲突说明市场要变盘，应该提前反手。冲突首先是「现在不清晰」。
5. 回测里不断加入能抬高历史曲线的新指标。那是拟合。
6. 没有指标的结构规则不算系统。清晰的价格结构可以单独占方向槽。
7. 因为共振就省略止损。
8. 把教育内容误当成信号源。

## 局限性

- **确认偏差**：只看见对齐的格子，看不见没对齐的。
- **过拟合**：历史图上能对齐的条件，换一段行情就消失。
- **执行瘫痪**：格子太多，盘中无法按同一规则复述。
- **数据质量差、流动性差、清算进行中**：更该触发禁止交易条件，而不是要求所有格子对齐。
- **共振覆盖不了后半链路**：止损、止盈、仓位、离场、复盘必须离开指标层。
- **阶段 3 尚未写正文**：本课只把你送到「该写系统了」，不提供可跟单的策略。

永续合约有强平风险。信心上升快于风控规则落地时，杠杆会先出问题。本站不鼓励高杠杆。历史案例不能代表未来结果。学完阶段 2，也不等于已经具备稳定交易的能力。

## 总结

记住五句话：

1. 共振是不同问题得到相近答案，不是指标越多越准确。
2. 先填问题槽，一个槽只留一个代表。
3. 对齐只说明画面清楚，可以讨论前提，不是入场，更不是加大杠杆。
4. 冲突时等待或空仓，不要加第 6 个指标投票。
5. 止损和仓位不属于任何一张副图。
