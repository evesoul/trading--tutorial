# RSI + MACD

本篇把两把动量尺并排放，用来检查你是否把同一段价格算了两次。

[RSI](/indicators/rsi) 和 [MACD](/indicators/macd) 都属于动量观察。核心不是「两个动量一起用更稳」，而是：它们常常在回答同一个问题。

先修：[RSI](/indicators/rsi)、[MACD](/indicators/macd)。上一篇 [趋势 + 成交量](/combinations/trend-volume) 看的是转手；本篇回到价格本身的两种平滑。方向上下文仍建议用 [EMA](/indicators/ema)，见 [趋势 + 动量](/combinations/trend-momentum)。公式见阶段 1，本课不重讲。

类比：同一辆车，一块表显示时速是否偏快，另一块表显示加速度是在加大还是减小。两块表都同意「在加速」，不等于来了第二个证人。它们读的是同一段路。

## 学习目标

读完本篇，你应该能：

- 说出 RSI 有界、MACD 无界，差别在表达方式，不在「一个管反转、一个管趋势」
- 在并排图上问：去掉其中一把尺子，结论是否仍相同
- 把两副图一致或分歧，只写成观察冲突或重复，而不是自动方向
- 冲突时回到均线或价格结构，而不是再找第三把动量尺来投票
- 拒绝「金叉加上离开超卖区就是双重确认」这种写法

## 概念

| 指标 | 它在回答 | 表达特点 | 它不回答 |
|---|---|---|---|
| RSI | 这段时间上涨收盘相对下跌收盘有多强 | 有界，便于谈相对过快或过慢 | 趋势是否成立、成交与持仓 |
| MACD | 快速均价相对慢速均价的差距，以及差距是否在扩大 | 无界，便于谈力度扩张或收缩 | 固定的超买超卖区间、拥挤程度 |

它们的共同来源都是价格。没有成交量、持仓量、资金费率时，本组合无法讨论参与度和拥挤。

差别在于平滑方式和是否有界，不在于「一个看趋势、一个看买卖点」。把 MACD 当成趋势指标、把 RSI 当成反转指标，是常见错位。MACD 来自均线差，只能算带滞后的动量；RSI 也不是反转开关。

**背离（Divergence）** 在这里指价格创新高或新低，而指标没有同步。MACD 名字里的 Divergence 还指快慢均线分开。两个词不要混成一件事。背离是观察现象，不是反转指令。

并排看的正当理由：

- 检查自己是否把「有界的相对强弱」和「均线差的扩张」当成了两件独立证据
- 观察同一段行情里，两种平滑是否同时变弱或同时变强
- 作为反面教材：看确认偏差是怎么发生的

不正当理由：金叉加上 RSI 离开 30，就当作双重确认开多；或认为两个指标都来自价格，所以更不容易错。来源相同，不会降低价格本身的不确定性。

## 观察步骤

1. **先有环境。** 用价格结构或 EMA 判断更像趋势还是震荡。本组合不负责定义趋势。
2. **只选一把动量尺描述力度。** 更习惯看有界指标，用 RSI；更习惯看扩张收缩，用 MACD。
3. **再并排对照，做检查而不是投票。** 问：如果只留其中一个，故事变了吗？
4. **一致时，降级理解。** 更像同一份动量的两种画法一致，不像两个独立证人。
5. **分歧时，回到环境。** 不要用其中一个宣布趋势结束，也不要折中成「半个反转」。
6. **不要为了对齐去改参数。** 把 RSI 和 MACD 调到每次转折都重合，是在拟合图画。

共振在这里要降级：

- RSI 上行且 MACD 柱状图伸长：力度在两种平滑下都表现为加强。若去掉其中一个，结论仍相同，第二个指标没有提供新问题的答案。
- RSI 从高位回落且 MACD 柱缩短：两种平滑都显示力度减弱。
- 价格新高，RSI 与 MACD 都未同步新高：两种平滑都显示这段上涨的力度弱于前一段。这叫动量背离观察，仍不是反转指令。

冲突时优先回到 [趋势 + 动量](/combinations/trend-momentum) 的做法：趋势工具给方向，动量只描述力度。两个动量互相投票，没有裁判。

| 对照 | 可能的读法 | 先记下什么 |
|---|---|---|
| RSI 已到高位，MACD 仍在零轴上方伸长 | 有界指标显示相对过快，均线差仍在扩大 | 强趋势里两者本来就会不同步 |
| MACD 死叉，RSI 仍在中轴上方 | 快慢差转负，相对强弱尚未转弱 | 不要用其中一个宣布趋势结束 |
| RSI 出现背离，MACD 没有 | 回看长度和算法不同 | 不能折中成半个反转 |
| 两者同时频繁交叉、进出 50 | 可能处于震荡 | 先改环境判断，不要微调参数 |

## 正反案例

下面两段必须对照着看。它们是教学情景，不是真实行情，不能代表未来结果。

### 正例：识别出信息重复

同一段上升里，价格沿结构上行。RSI 同步走高，MACD 柱状图也同步伸长。你先只看 RSI 写一句：「窗口内涨幅占优。」再只看 MACD 写一句：「快慢差在扩大。」再两格都留着，第三句没有新问题。

这是正例：你认出两把尺子在重复同一份价格信息。正例不是盈利案例。允许的用法是：此后只保留 RSI 或只保留 MACD 其中一个，去描述力度。

### 反例：两个指标投票后仍然对不上价格

震荡里，RSI 从 30 附近抬头，MACD 同时金叉。有人写成「双重确认，开多」。随后价格继续在区间里折返，下一次又同时死叉、同时掉回中轴。两把尺子一起在噪声里打转。

另一幅：趋势里 RSI 出现顶背离，MACD 没有；或反过来。有人写成「一个有背离，先空一半」。算法不同，不是第二个证据。背离可以失败，也可以过早。

再补一条确认偏差：为了让 RSI 与 MACD 同时金叉才开仓，历史图上只剩下很少几段「很好看」的对齐。条件变严，不等于判断更清楚，只是样本变少。

## 常见错误

1. 两个动量同时确认，就当成准确率会提高。
2. RSI 管超买超卖，MACD 管金叉死叉，所以职责不同。那是形态名字不同，问题仍是动量。
3. 背离叠加背离更可靠。
4. 冲突时再看 [KDJ](/indicators/kdj) 来打破平局。又增加一个高度相关的动量。
5. 把金叉加上 RSI 离开 30 写成开多步骤。
6. 用 RSI 进 70 或 MACD 零轴来定义趋势。
7. 参数调到历史图上每次转折都对齐。
8. 因为「两个都同意」就提高杠杆。账户风险来自止损距离和仓位，不来自同意的指标个数。

## 局限性

- **缺少环境**：两个动量会一起在震荡里来回打脸，或一起在趋势里过早喊反转。
- **信息重复**：来源都是价格，并排看不能降低未来的不确定性。
- **多数决无效**：再加入 KDJ 等有界动量，只是把重复信息伪装成投票。
- **过滤过严**：同时要求两把尺子对齐，样本变少，好看的图更容易被记住。
- **看不见仓和量**：参与度与拥挤要另看后面的组合课。

若一套观察已经包含 EMA + RSI，就不要再把 MACD 交叉写成第三条入场条件，除非你能指出 MACD 在回答一个 RSI 回答不了的新问题。通常指不出来。更多讨论见 [多指标共振](/combinations/multi-indicator)。

永续合约有强平风险。本站不鼓励高杠杆。历史案例不能代表未来结果。

## 总结

记住五句话：

1. RSI 和 MACD 都是动量，来自同一段价格。
2. 一致常常只是算了两次，不是独立确认。
3. 分歧只说明观察冲突，不自动给出方向。
4. 冲突时回到均线或结构，不要再加第三把动量尺。
5. 更习惯看有界就用 RSI，更习惯看扩张收缩就用 MACD；不要两个都当确认。
