# 趋势 + 成交量

本篇把「价格做了什么」和「有没有人在转手」分开看。

[K 线](/indicators/kline) 或 [EMA](/indicators/ema) 给出方向或结构。[成交量](/indicators/volume) 回答参与度。组合用来对照，不是把放量叠成看涨、把缩量叠成看跌。

先修：[K 线](/indicators/kline)、[EMA](/indicators/ema)、[成交量](/indicators/volume)。上一篇 [趋势 + 动量](/combinations/trend-momentum) 看的是力度；本篇换问题。公式见阶段 1，本课不重讲。

类比：价格是车子往哪开，成交量是这段路有多少车经过。车多，不告诉你该往东还是往西。同一根放量柱，可能是新开多、空头回补，或两者混合。

## 学习目标

读完本篇，你应该能：

- 说出价和量是两个问题：一个看涨跌或结构，一个看转手
- 先描述价格动作，再比较成交量相对近期是放大还是缩小
- 把「量价齐升」当成观察清单，而不是开仓指令
- 指出缩量突破、放量滞涨是冲突，处理方式是等待，不是立刻反向
- 知道本组合分不清这些成交是开仓还是平仓

## 概念

| 观察对象 | 它在回答 | 它不回答 |
|---|---|---|
| EMA | 均价方向，以及价格相对均价的位置 | 这一段有多少人成交 |
| 价格 / K 线结构 | 涨跌、突破、拒绝、停滞实际发生在哪 | 参与是否放大、仓位是否增加 |
| Volume | 这一根或这一段相对近期是否更活跃 | 多空谁开的仓、资金费率、下一步方向 |

成交量是市场参与度，不是主力意图说明书。**放量** 指这一段成交明显高于你事先选好的参照（例如最近 N 根的平均成交量）。**缩量** 指明显低于同一参照。比较对象要固定，不要用「好像比较大」。

本课覆盖两套场景，不是两套更准的信号：

- **EMA + Volume**：还认得出均线方向时，问推进或回踩有没有人参与。
- **Price + Volume**：结构比均线更清楚时（区间沿、长影线、收盘回撤），问这一段动作有没有异常成交。

要问这些成交是加仓还是平仓，需要再引入持仓量，见 [价格 + OI](/combinations/price-oi) 和 [OI + Volume](/combinations/oi-volume)。本篇先把「总量」讲清，不提前把 CVD 混进来。

它回答：

- 现在还有没有可讨论的方向或结构？
- 价格离开、回到或穿过某条线时，转手有没有比近期更活跃？
- 突破、拒绝或横盘，是伴随着放量、缩量，还是量能对不上？

它不回答该多还是该空。放量没有方向。

## 观察步骤

1. **先去掉成交量柱的涨跌颜色。** 绿柱红柱通常只是跟着 K 线涨跌上色，不表示多方或空方独有。
2. **选一个参照。** 例如最近 20 根成交量的平均值。写下来，后面都跟它比。
3. **用一句话说价格做了什么。** 沿 EMA 推进、回踩、跌破、越过前高、长上影、收盘回到区间内。
4. **再比较量。** 这一段相对参照是放大、缩小，还是只在影线那根突然放大？
5. **合成一句观察。** 「收盘离开整理区，量高于区内均值。」不要合成「该追多」。
6. **注意时段。** 同一品种在不同交易时段的「正常量」不同。不要拿亚洲清淡时段去比美洲活跃时段。

**量价齐升** 是教科书里「价涨且量增」的观察说法。永续里恐慌下跌时，经常出现价跌量增。口诀只能当清单，不能当规律。

共振指方向或结构清楚，同时参与度与价格节奏暂时一致：

- 价格在上行 EMA 一侧推进，成交量高于近期均值：参与度与方向暂时一致。
- 回踩 EMA 时成交量缩小，随后离开均线时成交量重新放大：更接近休息后的再参与，仍需触发规则。
- 价格收盘离开整理区，成交量高于整理区内均值：突破得到更多成交配合。突破失败同样常见。

冲突时先等待或缩小观察范围：

| 对照 | 可能的读法 | 先记下什么 |
|---|---|---|
| 价格沿 EMA 创新高，成交量逐步缩小 | 方向还在，参与度变弱 | 趋势可能难持续，但不自动见顶 |
| 价格越过前高，成交量低于前一轮推进 | 结构上像突破，参与度不足 | 称为弱参与突破，等待收盘或回踩 |
| 价格几乎不前进，成交量却很大 | 大量换手发生在原地 | 可能是争夺，不能读成单边 |
| 价格跌破 EMA，成交量几乎没有放大 | 均线被穿过，但缺少参与 | 可能是假跌破，也可能是流动性差 |
| 均线走平，成交量间歇性脉冲 | 没有方向，只有短促活跃 | 方向层不成立 |

## 正反案例

下面两段必须对照着看。它们是教学情景，不是真实行情，不能代表未来结果。

### 正例：推进相对放量，回踩相对缩量

价格沿上行 EMA 推进时，成交量高于你选的 20 根均值；回踩均线时，成交量落到均值以下；再次离开均线时，成交量重新高于均值。

你可以记录：参与度与价格节奏一致。它帮助你区分「有人在跟着走」和「只是价格自己滑」。它不授权你在缩量回踩处加仓，也不证明趋势会继续。

同一套语言也可以用在结构上：整理区内均量较低，收盘离开该区时量明显高于区内均值。这仍只是观察。

### 反例：放量滞涨，或缩量跌破后迅速收回

价格几乎走平，成交量却连续高于近期均值。有人写成「放量就是要突破，该开多」。原地放量只说明换手激烈，方向未分。

另一幅：价格跌破 EMA 或前低，成交量几乎没有放大；随后几根又收回均线上方。把「跌破」写成开空，会在缺少参与的穿越里反复被打回。

再补一条口诀反例：价格创新高，成交量一波比一波低。有人写成「量价背离，将见顶」。参与度变弱，不等于顶部已被确认。对称地，单根天量可能是高潮，也可能是趋势加速的第一根。

## 常见错误

1. 放量等于看涨，缩量等于看跌。成交量没有方向。
2. 把「量价齐升」写成开仓条件。
3. 缩量突破一律当假，放量突破一律当真。量只改变观察权重，不给真假盖章。
4. 用单根天量预测反转。
5. 把不同交易所、不同合约的成交量加在一起比较。
6. 忽略时段，把清淡时段的柱子当成异常缩量。
7. 只看柱子颜色，不看相对大小。
8. 用成交量代替止损。参与度变弱，不能告诉你认错价位在哪。

## 局限性

- **时段结构**：24 小时市场里，「正常量」随交易时段变化。
- **刷量、活动拉量、数据源切换**：成交量会出现台阶，含义被污染。
- **低流动性**：少量成交就能撑起一根高量柱。
- **影线集中成交**：盘中故事和收盘价可能不同。
- **看不见开平仓**：放量加仓和放量减仓，在本组合里长得一样。
- **看不见拥挤**：价格仍沿 EMA 上升、成交活跃，同时资金费率很高，要另看 [Funding + OI](/combinations/funding-oi)。

永续合约有强平风险。杠杆下，回踩缩量看起来「比较安静」，一根反向放量就可以打到止损或靠近强平。本站不鼓励高杠杆。历史案例不能代表未来结果。

## 总结

记住五句话：

1. 价和量是两个问题。
2. 成交量回答转手，不回答方向。
3. 先固定参照，再比较放量或缩量。
4. 量价齐升、放量滞涨、缩量突破，都是观察，不是开仓指令。
5. 本组合分不清这些成交是开仓还是平仓。
