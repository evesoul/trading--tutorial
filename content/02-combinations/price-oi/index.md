# 价格 + OI

本篇把「价格往哪走」和「市场上还挂着多少仓」分开看。

[K 线](/indicators/kline) 说涨了还是跌了。[持仓量](/indicators/open-interest)（Open Interest，OI，也称未平仓合约）说存量变大还是变小。组合用来对照加仓过程还是减仓过程，不是把四象限背成开多开空。

先修：[K 线](/indicators/kline)、[持仓量](/indicators/open-interest)。上一篇 [RSI + MACD](/combinations/rsi-macd) 仍在价格内部打转；本篇换到合约特有数据。公式和口径见阶段 1，本课不重讲。

类比：停车场里的车位数是存量。车位数增加，只说明多停了一对「进场的车和对应的车位占用」，不知道新来的是哪些人，也不知道是谁把车开走的。

## 学习目标

读完本篇，你应该能：

- 用一句话说清：价格管涨跌，OI 管未平仓增减
- 填四象限表：能确定什么，不能确定什么
- 解释为什么 OI 上升只说明多空各多了一份合约，分不清谁开的仓
- 在永续语境里想到强平：下跌且 OI 上升，可能混着被动减多
- 拒绝把某一象限写成买卖口诀

## 概念

| 观察对象 | 它在回答 | 它不回答 |
|---|---|---|
| 价格 | 这一段谁在账面赢，价格往哪边走 | 新仓还是平仓、拥挤的持有成本 |
| OI | 未平仓合约规模变大还是变小 | 这些仓位是多头开的还是空头开的 |

关键限制：OI 增加只说明「市场上多了一对多空仓位」，不说明是新多还是新空主导。要讨论谁更拥挤，需要资金费率和多空比等其他观察，见 [Funding + OI](/combinations/funding-oi)。成交量是流量，OI 是存量，下一篇 [OI + Volume](/combinations/oi-volume) 会拆开。

四象限是读图语言。每一格至少有两种解释：

| 价格 | OI | 常见读法 | 同样说得通的其他读法 |
|---|---|---|---|
| 上涨 | 上升 | 趋势推进时有新仓进入 | 空头止损或被动减仓与新多混合，OI 仍可能升 |
| 上涨 | 下降 | 空头回补推动价格 | 多头主动平仓，上涨可能是平仓行情 |
| 下跌 | 上升 | 下跌过程中有新仓进入 | 多头被强平或止损，空头新开，二者都可能抬高 OI |
| 下跌 | 下降 | 多头平仓、风险撤出 | 空头获利了结，下跌是减仓过程，不自动到底 |

能确定的通常只有「存量增减 + 价格方向」。不能确定的是「哪一方主导」。

它回答：

- 这一段是加仓过程，还是减仓过程，比较好讨论吗？
- 价格新高或新低时，仓位存量有没有同步变大？
- 急涨急跌之后，OI 是在继续堆，还是在明显下降？

它不回答下一步涨跌，也不单独告诉你该开多还是开空。高 OI 只说明市场大，不说明马上要反向。

## 观察步骤

1. **先确认口径。** 同一合约、同一交易所、连续口径。不要把全网 OI 和单交易所下单画面混用，也不要把币本位与 U 本位加在一张图。
2. **用一句话说价格。** 沿结构上行、下行、横盘、急涨后停滞。
3. **看 OI 的变化方向和速度。** 升、降、还是几乎不变。不要只看绝对值高低。
4. **填表：我能确定什么，不能确定什么。** 能确定的是存量和价格；不能确定的是谁开的仓。
5. **永续里补问强平。** 价格急跌且 OI 急升，可能包含多头被动减仓，不是一份自愿的「看空说明书」。
6. **OI 只过滤前提，不给方向。** 例如：减仓上涨时，不把这次上涨当成趋势加速的前提。这仍是过滤，不是信号。

共振指价格方向清楚，同时 OI 的增减让「加仓还是减仓」比较好讨论：

- 价格沿结构上行，OI 同步上升：更值得讨论是否有新仓在支持这段涨。仍可能随后失败。
- 价格沿结构下行，OI 同步上升：更值得讨论下跌是否伴随仓位扩张。永续里可能包含被迫平仓。
- 急涨或急跌后价格停滞，OI 明显下降：更值得讨论是否在消化仓位，而不是「趋势已经确认结束」。

冲突时，不把 OI 当方向指标去推翻价格结构，也不为了「OI 看起来不对」而随意反手：

| 对照 | 可能的读法 | 先记下什么 |
|---|---|---|
| 价格新高，OI 持续下降 | 涨，但仓位在收缩 | 可能是平仓推动；方向观察仍在，存量变弱 |
| 价格横盘，OI 快速上升 | 价格没动，仓位在堆积 | 可能在对赌区间，不能预判突破方向 |
| 价格急跌，OI 先升后降 | 先有新仓或强平，随后集中平仓 | 把时间顺序讲清，不要合成见底信号 |
| 价格与 OI 同步剧烈抖动 | 数据噪声或清算瀑布 | 先检查数据，而不是立刻解释结构 |

## 正反案例

下面两段必须对照着看。它们是教学情景，不是真实行情，不能代表未来结果。

### 正例：先填表，不先下指令

价格沿前高方向上行，OI 同步上升。你写下：能确定「涨 + 存量增加」；不能确定「是新多主导还是空头被动离场混在里面」。

另一格对照：价格同样上行，OI 下降。你写下：能确定「涨 + 存量减少」；不能确定「是空头回补还是多头主动平仓」。两格都没有开仓授权。正例是你会填表。

### 反例：把四象限背成买卖口诀

有人把「涨 + OI 升」写成开多，「跌 + OI 升」写成开空，「OI 降」写成将反转。随后同一象限走出相反结果：减仓上涨继续走一段，或加仓下跌继续走一段。

口诀删掉了「多种解释并存」这一核心。OI 分不清谁开的仓，所以任何一格都不能单独当指令。

再补一条永续反例：价格急跌，OI 骤升。有人写成「新空进场，继续空」。画面里也可能是多头被强平，被动成交抬高了 OI。随后 OI 又骤降，只说明仓位在被拆除，不是见底信号。

再补一条绝对值反例：OI 处于近期高位，有人写成「拥挤到顶，该反向」。高 OI 是规模。谁在付费、是否一边倒，要另看费率。

## 常见错误

1. OI 上升就是有主力在做多。OI 上升是多空各多了一份合约。
2. OI 下降就是要反转。
3. 把四象限背成买卖口诀。
4. 用 OI 替代成交量。流量和存量不是同一个数。
5. 忽略强平。永续里价与 OI 同时快速变化，常常与清算有关。
6. 跨交易所加总，或把全网 OI 用在单一交易所的读图练习上。
7. 只看 OI 绝对值高低，不看变化方向和速度。
8. 把「OI 上升 + 价格上涨」理解成可以加大杠杆的安全做多。

## 局限性

- **分不清开仓身份**：单看 OI 拆不开多头和空头。
- **口径与延迟**：更新频率慢于你看的 K 线周期时，解释会过时。
- **活动补贴、新上线合约、套利进出**：OI 可能台阶式变化。
- **清算瀑布**：价格、OI、成交量同时剧烈变化，单一象限读法会过时。
- **不提供方向**：方向仍来自价格结构或趋势规则。
- **看不到持有成本**：拥挤要和资金费率对照。

永续合约有强平风险。OI 高、流动性变差时，离场滑点可能更大。本站不鼓励高杠杆。历史案例不能代表未来结果。

## 总结

记住五句话：

1. 价格管涨跌，OI 管未平仓增减。
2. 四象限是解释框架，不是四条交易指令。
3. OI 分不清谁开的仓。
4. 下跌且 OI 上升，永续里可能混着强平。
5. 能确定的是存量加减，不能确定下一步方向。
