# 交易所屏幕上有什么

本页只回答一件事：打开 U 本位永续合约界面时，**哪些数字决定你还活着**，哪些只是展示。

先修：[怎么学这门课](/course)。那里已经见过保证金、杠杆、强平和三个价格。本篇把它们按屏幕上的位置拆开。下一篇才进入 [K 线](/indicators/kline)。

本站只提供交易教育，不提供买卖信号、荐股、喊单或自动交易。不教开户，不推荐交易所，不颁布杠杆倍数。

类比：进厨房先看火和油温，再看菜谱。标记价和预估强平是火，K 线是菜谱。

## 学习目标

读完本篇，你应该能：

- 说出钱包余额、未实现盈亏、权益不是同一个数
- 在屏幕上指出最新价、指数价、标记价各干什么
- 解释预估强平价、逐仓 / 全仓，以及「杠杆是展示、不是风险本身」
- 读懂资金费倒计时：它是收费时点，不是反转闹钟
- 认出风险限额 / 仓位档位：名义做大，维持要求可能升高，强平线靠近

## 概念

**永续合约屏幕（Perp Screen）**指合约界面上与账户、价格、保证金、资金费有关的一排数字。它们回答「仓位现在值多少、还差多远会被强平、下一笔资金费何时收」，**不是** K 线形态，也不是买卖指令。

各交易所用词不同。下面用规范名；界面上可能写成别的，行为还在。

建议阅读顺序（正例）：

1. 先读**标记价**、**预估强平价**、保证金模式（逐仓 / 全仓）与当前杠杆展示。
2. 再读钱包余额、未实现盈亏、权益，确认三者不是同一个数。
3. 再看资金费倒计时与下一笔费率。
4. 最后才读 K 线。

反例：只看最新价浮动盈亏的颜色，配上很高的杠杆。本站不鼓励高杠杆。

### 钱包余额、未实现盈亏、权益

| 字段 | 英文 | 它是什么 |
|---|---|---|
| 钱包余额 | Wallet Balance | 已结算、记在钱包里的资金。平仓盈亏、资金费、手续费入账后会改这个数。 |
| 未实现盈亏 | Unrealized PnL | 持仓按**标记价格**估算、尚未平仓的浮动盈亏。不是已经到手的钱。 |
| 权益 | Equity | 余额与未实现盈亏等项合计后的账户净值（以交易所定义为准）。全仓时，强平看的往往是权益是否还够维持保证金。 |

要点：

- 最新价跳动时，屏幕上的浮动盈亏颜色可能跟着最新价走；**用于强平与未实现盈亏的正式口径，仍以该所标记价规则为准**。
- 未实现盈利加进权益，不等于可以全部再拿去开新仓；可用余额还要扣冻结与保证金占用。
- 已实现盈亏进钱包余额；未实现盈亏平仓前可以消失。

不要用「权益涨了」代替「策略有效」。权益含浮动，历史路径不能代表未来。

### 三个价格

| 价格 | 英文 | 屏幕上通常干什么 |
|---|---|---|
| 最新价 | Last Price | 最近成交价。K 线多按它合成；不少止损单默认按它触发（以设置为准）。 |
| 指数价 | Index Price | 一篮子现货合成的参考。用来锚定永续，避免合约价单独乱飞。一般不直接触发你的止损。 |
| 标记价 | Mark Price | 算未实现盈亏、估预估强平价。强平流程看它，不看你刚看到的那根上影。 |

剧烈波动时，三者可以分开。分析走势看 K 线（最新价）；问「还会不会被强平」看标记价与预估强平价。

### 预估强平、逐仓 / 全仓、杠杆是展示

**预估强平价（Estimated Liquidation Price）**是交易所按当前仓位、保证金、模式、标记价规则估算的「再走到这里可能进入强平」的价格。它是**估算值**，会随加仓、减仓、资金费、风险限额档位变化。不要把它当成保证触发的止损价。

**维持保证金（Maintenance Margin，MM）**是维持仓位不被强平所需的最低保证金。屏幕上常见「维持保证金率」「保证金比率」。权益落到维持水平附近，就会进入强平流程。

**逐仓（Isolated）**：该仓只用划给它的保证金。亏完这部分，通常只强平这一仓。  
**全仓（Cross）**：可用余额共同支撑。抗波动的钱更多，错的时候亏及的范围也更宽。

两种都有强平风险。模式是风险隔离方式，不是「哪个更安全」。

屏幕上的 `10x`、`20x` 多半是**起始保证金与名义价值的展示关系**（口径因所而异）。真正决定你还活着的，是：

- 名义有多大
- 保证金（或权益）还剩多少
- 维持保证金要多少
- 预估强平价离标记价有多远
- 止损单看哪个价、能不能成交（见 [订单与成交](/trading-system/order-types)）

同样 10x，全仓厚权益与逐仓薄保证金，强平距离可以差一截。不要把杠杆数字当成风险的唯一度量。本站示例优先用低杠杆说明机制，不鼓励高杠杆。

### 可用、冻结、下单占用

| 字段 | 含义 |
|---|---|
| 可用 | 当前还能再拿去开仓或划转的资金（以界面定义为准） |
| 冻结 | 已被占用、暂时不能再支配的资金 |
| 下单占用 | 挂着的委托已经按规则锁住的保证金或额度 |

限价单挂着就会占用。可用看起来「还有很多」，可能有一部分已被未成交单锁住。撤单后占用通常释放，但成交与手续费会留下结果。

不要用可用余额去除以最新价，直接当成「还能开多少」而不看维持保证金与风险限额。

### 资金费倒计时

屏幕上常见：

- 下一笔**资金费率（Funding Rate）**（预测值，结算前会变）
- 倒计时（距下一次结算还有多久）

只有持仓越过结算时点才收付**资金费（Funding Payment）**。倒计时不是反转计时器。费率怎么观察，见 [资金费率](/indicators/funding-rate)。

持有多个周期的成本近似（教学乘法，各周期费率不同，不能拿去对账）：

> 资金费累计 ≈ 名义价值 × 费率 × 周期数

算术如何对照 1R，留给 [成本对照 R](/trading-system/cost-vs-r)。

### 风险限额 / 仓位档位

**风险限额（Risk Limit）**与**仓位档位（Position Tier）**是交易所按名义价值分段规定保证金率的规则。

1. 名义做大，可能从低档进入高档。
2. 进入更高档后，**维持保证金率可能升高**。
3. 维持要求升高，同一保证金能撑的逆行距离变短，**预估强平价靠近标记价**。
4. 有的档位还会限制最高可用杠杆展示。

这不是奖励，也不是「做大了更稳」。加仓、对冲、或价格推动名义上升，都可能在你没改杠杆数字的情况下把你推到下一档。

## 原理

导学里已经用「租柜台」讲过保证金和名义。本篇只补屏幕上的分母：

- 浮动盈亏的颜色，常常跟最新价走；强平的尺子是标记价。
- 杠杆数字回答「起始保证金大概占名义多少」，不回答「这次会不会被强平」。
- 预估强平价是估算，不是墙上的砖。档位升高、资金费入账、全仓其他仓位变动，都会改这个数。

教学演算（忽略手续费与资金费，不能拿去对账，不能代表未来结果）：

名义 5,000 USDT，逐仓，起始保证金 500 USDT，屏幕可能显示约 10x。同一名义若只放 250 USDT 保证金，展示杠杆更高，预估强平通常更近。风险差在保证金厚度和强平距离，不在「10 这个数字好不好看」。

## 怎么看

![交易所屏幕字段示意图](/images/concept/vis-030-perp-screen.svg)

上图是**示意图**，不是某家交易所的截图，也不是下单面板。先找权益、标记价、预估强平、资金费倒计时，再读 K 线。

打开合约屏时，按这个顺序看：

1. **标记价在哪？预估强平价在哪？** 两者离多远？
2. **逐仓还是全仓？** 这一仓亏完会不会拖到别的钱？
3. **杠杆数字是展示。** 先看名义和保证金，再看那个 `x`。
4. **钱包余额 / 未实现盈亏 / 权益**是否对得上「一个是已结算、一个是浮动、一个是合计」？
5. **可用、冻结、下单占用**：挂单有没有把钱锁住？
6. **资金费倒计时与下一笔费率**：离结算还有多久；费率是预测还是已结算。
7. **风险限额 / 档位**：名义做大之后，维持率有没有提示升高？
8. **然后才读 K 线。**

名称因所而异。界面上找不到「权益」三个字，仍要能指出净值、标记价、强平价、资金费这四样。

## 怎么使用

本篇用来建立读屏习惯，不是用来选杠杆或选交易所。

1. 先回 [怎么学这门课](/course)，确认你记得强平和三个价格。
2. 用示意图在自己常用的界面上对号：权益、标记价、预估强平、资金费倒计时各在哪。
3. 写一句自己的话：「强平看标记价；浮动盈亏颜色可以骗人。」
4. 再进入 [K 线](/indicators/kline)。读图时记住：K 线用最新价合成。
5. 以后写规则时，止损单看哪个价、会不会先被强平，见 [订单与成交](/trading-system/order-types)。

本站不规定「几天学完」，也不说「认完屏幕即可交易」。

## 正反案例

下面两段必须对照着看。它们是教学情景，不是真实行情，不能代表未来结果。

### 正例：先读标记价和强平，再读 K 线

你打开合约屏。先找到标记价和预估强平价，确认这一仓是逐仓还是全仓，再看资金费还有多久结算。最后才把眼睛移到 K 线。浮动盈亏是绿色，你仍先问：「绿色用的是哪个价？平仓前能不能当已经到手？」

这是正例：颜色是展示，强平距离才是活着的尺子。正例不保证接下来会赚钱，只说明阅读顺序对了。

### 反例：只看浮动盈亏颜色，配上很高的杠杆

同一屏上，最新价跳了一下，未实现盈亏变成很亮的绿。有人把它读成「已经赚了」，并把杠杆开得很高，好让绿色数字更大。标记价其实没走那么远；预估强平已经很近。下一跳若反向，颜色变红之前，账户可能先进入强平流程。

只盯最新价盈亏颜色、再用很高的杠杆，是本篇要拆掉的习惯。本站不鼓励高杠杆。

## 常见错误

1. 绿色未实现盈亏 = 钱包里已经多了这笔钱。
2. 只盯最新价盈亏颜色，不问标记价。
3. 把预估强平价当成保证会在那里停住的墙。
4. 杠杆数字小就安全；杠杆数字大就更会做。
5. 资金费倒计时快到了就会反转。
6. 风险限额是交易所在保护你的利润。
7. 界面上找不到的字段就可以忽略。
8. 用可用余额直接除最新价，当成还能开多少。

## 局限性

- 本页不教开户，不推荐交易所，不颁布杠杆。
- 各交易所的字段名称、标记价公式、维持保证金和强平流程并不完全相同。
- 预估强平价是估算值，滑点、档位变化、全仓其他仓位都会改它，成交价也可以越过它。
- 数字例子是教学演算，忽略部分费用，不能拿去对账，不能代表未来结果。
- 认完屏幕不等于会交易。规则还要能变成可能成交的单，见阶段 3 的 [订单与成交](/trading-system/order-types)。
- 永续合约有强平（爆仓）风险。杠杆会放大亏损。

## 总结

记住五句话：

1. 钱包余额、未实现盈亏、权益不是同一个数。
2. 读图看最新价；问还会不会被强平，看标记价和预估强平。
3. 杠杆是展示；风险看名义、保证金和强平距离。
4. 资金费倒计时是收费时点，不是反转闹钟。
5. 先读屏幕，再读 K 线。历史案例不能代表未来结果。
