# 怎么学这门课

本页只回答一件事：这门课怎么学，以及进入屏幕和 K 线之前，你至少要知道永续合约会怎样亏钱。规则写完之后，还要能变成可能成交的单。

需要查词时，可以打开 [/glossary](/glossary)，查完回到原文。术语页不占主路径。

## 学习目标

读完本页，你应该能：

- 说出本站是教育站，不是信号站、荐股站或自动交易工具
- 画出三阶段地图：指标 → 组合 → 交易系统
- 用自己的话解释保证金、杠杆、强平、标记价格
- 区分最新价和标记价：读图看前者，估算强平看后者
- 记住：历史案例不能代表未来结果

## 概念

### 本站是什么

这是一门面向零基础读者的 **U 本位永续合约（USDT-margined Perpetual Futures）** 教程。

- **U 本位**：保证金和盈亏用稳定币结算，教学默认 **USDT**。
- **永续合约**：没有到期日的合约，可并列英文 Perpetual Swap。不用「无限期期货」当正式名。

本站帮你做四件事：

1. 看懂常用指标在观察什么
2. 看懂多个指标何时互相支持、何时打架
3. 把观察写成可重复的规则
4. 理解风险、仓位和回测各自解决什么问题

### 本站不是什么

本站**不是**：

- 买卖信号
- 荐股或喊单
- 自动交易系统
- 交易终端

学完任一阶段，都不等于已经具备稳定交易的能力。

指标、形态、交叉、背离、超买超卖，在本站都叫**观察工具**。它们描述图上发生了什么，不代替你决定开仓或平仓。

## 原理

先把永续合约和现货分开。永续不是「加了杠杆的现货」。它是单独的合约市场。

| 项目 | 现货（Spot） | U 本位永续 |
|---|---|---|
| 持有物 | 标的资产本身 | 价格差合约 |
| 方向 | 通常先买后卖 | 可做多，也可做空 |
| 到期 | 无 | 无（靠资金费锚定） |
| 杠杆 | 一般无 | 用保证金放大名义价值 |
| 强平 | 无此机制 | 保证金不足会被强制平仓 |
| 持有成本 | 无资金费 | 周期性资金费 |

**做多（Long）**：预期价格上涨。  
**做空（Short）**：预期价格下跌。  
方向判断错误时，亏损同样会被杠杆放大。

### 保证金、杠杆、名义价值

把开仓想成租柜台做生意：

- **保证金（Margin）**像押金。它被冻结，用来吸收浮动亏损，不是「这笔钱已经亏掉」。
- **仓位名义价值（Notional Value）**像柜台上的货值。教学近似：名义价值 ≈ 仓位数量 × 标记价格。
- **杠杆（Leverage）**是「货值 / 押金」的展示方式，常见写成 `10x`、`20x`。

生意亏到押金不够，柜台会被清走。这就是后面要讲的强平。

教学近似（忽略手续费与资金费）：

> 起始保证金（Initial Margin）≈ 名义价值 / 杠杆

例子：0.1 BTC 的 `BTCUSDT` 仓位，标记价 80,000 USDT，名义价值约 8,000 USDT。

| 杠杆 | 约需起始保证金 | 教学含义 |
|---|---|---|
| 10x | 800 USDT | 同一仓位，缓冲相对厚一些 |
| 50x | 160 USDT | 反向波动更小的幅度，就可能碰到维持保证金 |

杠杆**同时放大**盈利与亏损。本站不鼓励使用高杠杆，也不给「推荐倍数」。示例只用低杠杆讲机制。

还要分清两种保证金：

- **起始保证金（IM）**：开仓时至少要冻结的钱。
- **维持保证金（Maintenance Margin，MM）**：维持仓位不被强平的最低水平。权益掉到这附近，交易所会按规则强制减仓或平仓。

两种保证金模式：

- **逐仓（Isolated）**：只拿划给这一仓的钱冒险。亏完通常只强平这一仓。
- **全仓（Cross）**：钱包里的可用余额一起撑仓位。更能扛波动，错了亏的范围也更宽。

没有「更安全的模式」，只有「亏损先吃哪一部分钱」的差别。

### 三个价格

同一屏幕上至少要分清三个价：

| 名称 | 它是什么 | 你用它做什么 |
|---|---|---|
| **最新价格（Last Price）** | 最近一笔成交价 | K 线通常按它合成；读图用它 |
| **指数价格（Index Price）** | 若干现货价合成的参考价 | 回答「现货大概在哪」 |
| **标记价格（Mark Price）** | 结合指数与溢价等算出的参考价 | 算未实现盈亏，估算强平 |

教学要点：

- 分析走势看 K 线（最新价）。
- 浮动盈亏和强平线看标记价。
- 两者接近是常态。剧烈波动时可能分开。
- 你刚看到的那根上影线，不见得会触发强平。

### 强平

**强平（Liquidation）**：保证金不够维持仓位时，交易所按规则强制减少或关闭仓位。口语常称「爆仓」。本站正文用**强平**；照顾口语时写「爆仓（即强平）」。

强平是保证金耗尽的结果，不是某根 K 线发出的指令。

常见组合是：高杠杆 + 高波动 + 薄保证金。不要把它概括成「运气不好」。

### 资金费（先认识名字）

永续没有到期交割。为了让合约价不要长期远离指数价，交易所按周期在多空之间收费：

- **资金费率（Funding Rate）**：比率，用来观察拥挤和溢价。
- **资金费（Funding Payment）**：实际划转的 USDT 金额。

费率为正时，多头付给空头；为负时，空头付给多头。它是持仓成本或持仓收益的一部分，不是「费率高了就会反转」的计时器。细节见 [资金费率](/indicators/funding-rate)。

## 怎么看

读本站时，按这个顺序看：

1. **先看本页风险**：保证金、杠杆、标记价、强平。
2. **再看阶段 1 主路径**：先会读 K 线，再连趋势线，再读摆动结构，再叠加均线、动能、量能和波动尺子。
3. **先修写在每篇文章开头**：例如学 RSI 前，建议先读完 K 线、MA、EMA。
4. **一篇只解决一个问题**：不要把目录当成指标清单去背。

读永续盘面时，按这个顺序看：

1. 这是最新价，还是标记价？
2. 仓位是逐仓还是全仓？杠杆大概多大？
3. 保证金还剩多少缓冲？
4. 然后才读 K 线和指标。

指标不能降低强平的数学可能性。任何永续图表，背后都是带强平机制的市场。

## 怎么使用

建议每次 20–40 分钟，只读一篇。

1. 从本页进入 [交易所屏幕上有什么](/course/perp-screen)，再进入 [K 线](/indicators/kline)。
2. 按主路径读到布林带（趋势线 → 摆动结构 → … → Volume → ATR → 布林带），需要组合先修时再读 MACD；KDJ 是对照层。再读已发布的合约数据层：[持仓量](/indicators/open-interest) → [资金费率](/indicators/funding-rate) → [多空比](/indicators/long-short-ratio) → [CVD](/indicators/cvd) → [清算瀑布](/indicators/liquidation-cascade)。
3. 每读完一篇，试着用自己的话复述：**这一篇在回答什么问题？**
4. 阶段 2、3 每次只选一篇。阶段 3 二十篇都已开放：多周期、订单、成本、热度、执行偏差都在链路里。案例读完后回本页复习。

使用约定：

- 单独说「均线 / MA」时，默认指**简单移动平均（SMA）**。指数均线要写成 **EMA**。
- **图表周期（Timeframe）**是一根 K 线代表多久，如 `15m`、`1H`、`4H`。
- **回看参数（Period / Length）**是指标向前取多少根，如 MA 20、RSI 14。
- 这两个词都可能被人口头叫「周期」。本站会写清是哪一种。
- 真实行情图必须写交易对、图表周期、数据来源、时间区间。没有实盘数据时，只用标明「示意图」的图。

本站不规定「几天学完」，也不说「学完即可交易」。

## 正反案例

### 正例：把目录当成问题清单

你打开指标目录，先问：「K 线在回答什么？」再问：「MA 比 K 线多回答了什么？」

这样学，后面看到金叉、超买，你会先问「它在观察什么」，而不是先问「该不该开仓」。

### 反例：把观察当成指令

同一段行情里出现均线金叉。有人把它读成「必须做多」。

金叉只说明：较快的那条均线从下方穿过较慢的那条。交叉发生在已经走完的一段价格之后，具有滞后性。震荡市里交叉会反复出现。

把观察写成开仓指令，是本站要帮你拆掉的习惯。

另一个反例：只用最新价上的止损，却用很高的杠杆。止损单还没成交，标记价可能已经触发强平。

以上都是教学对照，不是某次实盘记录，更不能代表未来结果。

## 常见错误

1. 把本站当成信号源或跟单频道。
2. 把永续当成加了杠杆的现货，忽略标记价、强平和资金费。
3. 认为全仓比逐仓更安全。全仓只是缓冲来源不同。
4. 认为收到资金费就证明方向正确。资金费是拥挤方向的补偿，不是趋势证明。
5. 读完案例后继续寻找「实盘策略」或未发布页。案例是教学作业纸，不证明有效，之后请回本页。
6. 用极高杠杆做「很小的止损」。手续费、滑点和盘中噪声会占很大比重，计划中的风险控制容易失效。

## 局限性

- 本页只讲机制和学法，不讲买卖时机。
- 数字例子忽略手续费与资金费，不能拿去对账。
- 各交易所的标记价、维持保证金、强平流程并不完全相同。
- 学完已发布课文，仍不等于已经具备稳定交易的能力。案例是作业纸，不证明有效，不能代表未来结果。
- 任何策略、指标组合都带有亏损可能。永续合约还可能被强平、亏掉保证金；极端情况下还可能遇到额外结算规则（视交易所保险基金与自动减仓而定）。

## 总结

记住五句话：

1. 本站是教育站，不是信号站。
2. 先学「图上在看什么」，再学「多条信息如何对照」，最后才写规则。
3. 读图看最新价；估算强平看标记价。
4. 杠杆同时放大盈利与亏损。本站不鼓励高杠杆。
5. 历史案例不能代表未来结果。
