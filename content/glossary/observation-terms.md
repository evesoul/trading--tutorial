# 观察用语

下列词汇只描述图表上常见的相对关系。它们不是入场、出场或反转指令。

### 超买（Overbought）与超卖（Oversold）

动量指标进入传统高位区或低位区的说法。例如 RSI 传统上把 70 附近看作超买区、30 附近看作超卖区；KDJ 常用 80 / 20。超买不代表价格即将下跌；超卖不代表价格即将上涨。强趋势里，指标可以在极端区停留很久。详见[RSI](/indicators/rsi)、[KDJ](/indicators/kdj)。

### 背离（Divergence）

价格创新高（或新低），对应指标没有同步创新高（或新低）。顶背离：价格更高高点，指标更低高点。底背离：价格更低低点，指标更高低点。背离是观察现象，不是反转已被确认。趋势行情中背离可以反复出现而价格继续走。

注意：MACD 名字里的 Divergence 还指快慢均线分开，和「价格与指标不同步」不是同一句话。详见[MACD](/indicators/macd)。

### 金叉（Golden Cross）与死叉（Death Cross）

快线从下向上穿过慢线称金叉；从上向下穿过称死叉。可用于均线（如 MA50 与 MA200），也可用于 MACD、KDJ 的快慢线。交叉发生在已经走完的一段价格之后，具有滞后性。金叉不代表此后只涨，死叉不代表此后只跌。详见[MA](/indicators/ma)、[MACD](/indicators/macd)、[KDJ](/indicators/kdj)。

### 钝化（Flattening / Failure to reverse at extremes）

指标进入极端区后不再随价格继续创新高或新低，或在极端区来回小幅波动。常见于 RSI、KDJ。钝化提示动量变化，不单独构成反转。

### 量价配合 / 量价背离（Volume confirmation / Volume divergence）

价格变动时成交量同步放大或缩小的观察。放量上涨或缩量回调都只是常见搭配，不是充分条件。详见[成交量](/indicators/volume)。

### 拥挤（Crowding）

较多交易者站在同一方向，可从极端资金费率、一边倒的多空比、快速上升的持仓量等侧面观察。拥挤可以提高反向波动时的清算连锁风险，但不能据此定时反转。相关合约数据课文尚未发布。

### 收口 / 开口（Squeeze / Expansion）

布林带带宽变窄称收口或挤压，变宽称开口或扩张。收口只说明最近波动小，不预告突破方向；开口只说明波动在扩大，不是开仓指令。趋势里价格还可以沿上轨或下轨走轨道。详见[布林带](/indicators/bollinger-bands)。
