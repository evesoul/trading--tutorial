# 市场与合约

下面每个词用两三句说清。需要展开时，点「详见」回到已发布课文。术语页不是第二套教程。

### 现货（Spot）

按当前市场价格买卖标的资产本身。买入现货后持有的是资产，没有到期日，也不会因为杠杆不足被交易所强制平仓。现货仍有价格下跌的本金亏损风险。

### 合约（Futures / Derivatives）

约定未来按规则结算价格差的衍生品。交易者可以做多或做空，常见用途是投机或对冲，而不是领取现货。合约有保证金与[强平](/glossary)机制。

### 交割合约（Delivery / Dated Futures）

有明确到期日的合约。到期后按规则交割或现金结算。本站主讲对象不是交割合约。

### 永续合约（Perpetual Futures / Perpetual Swap，Perp）

没有到期日的合约。通过资金费率周期性在多空之间收费，使合约价格尽量靠近现货指数。可并列英文 Perpetual Swap；不用「无限期期货」作正式中文名。详见[怎么学这门课](/course)。

### U 本位（USDT-margined / Quote-margined）

用稳定币（教学默认 USDT）作保证金，盈亏也以该稳定币结算。例如 BTCUSDT 永续：涨跌按 BTC 的 USDT 价格计，盈亏记入 USDT。对照：**币本位（Coin-margined）**用标的币作保证金与结算。本站默认语境是 U 本位永续合约。

### 标的 / 交易对（Underlying / Symbol）

被报价的对象。教学里常见写法：`BTCUSDT`、`ETHUSDT`。写案例时要同时记录交易对、图表周期、数据来源、时间区间。

### 做多（Long）与做空（Short）

做多：预期价格上涨，先买后卖（或持有多头仓位），价格涨则浮动盈利增加。做空：预期价格下跌，先卖后买（或持有空头仓位），价格跌则浮动盈利增加。方向判断错误时，亏损同样会被杠杆放大。

### 开仓 / 平仓 / 加仓 / 减仓（Open / Close / Add / Reduce）

开仓是新建仓位。平仓是把已有仓位关掉，盈亏从浮动变为已实现。加仓是同方向增加仓位。减仓是减少部分仓位。一方开仓、一方平仓时，持仓量可以不变；两边都是新开仓，持仓量才会增加。持仓量课文尚未发布，先记住它和成交量不是同一个数。
