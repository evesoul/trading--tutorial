# 拉升：SOS 与 BUEC

吸筹解决「像不像底部区间」；拉升解决「有没有收盘离开」。常见错法不是看错底，而是弹簧后不敢等、SOS 时追在高潮、回踩时又当成破位。

## 学习目标

- 用四条对照合格 SOS 和上冲收回
- 说明 BUEC 为什么是主观察点
- 回踩放量时把拉升降级，而不是加仓

## 概念

| 术语 | 含义 | 图上要看到什么 |
| --- | --- | --- |
| SOS | 需求压过供给，离开吸筹区 | 放量收盘站上 Creek，其后不立刻回到中轴 |
| Creek | 吸筹上沿 | 4H 水平阻力，曾多次压住价格 |
| JAC | 跳过小溪 | 一根或两根离开上沿，实体长、回撤小 |
| BUEC | 回踩小溪边 | SOS 后缩量回踩上沿，阻力改观察为支撑 |
| LPS | 最后支撑点 | 拉升初期最后一个缩量低点，常与 BUEC 重合 |

## 原理

合格 SOS 四条对照：前面已有吸筹骨架；**收盘**站上，不是只有上影；当根量大约 ≥ 1.5× 均量；标记价同步站上。缺一条就降级。

回踩量应明显小于 SOS。若回踩量再次大于 SOS，供给回来了，BUEC 作废。

## 怎么使用

练习时主观察 BUEC：SOS 已收盘成立 → 回踩 Creek 或 SOS 实体中段 → 更短周期缩量止跌。SOS 当根追价只作减半观察，止损用 Creek 下，不用当根低点。

跌破 BUEC 且 4H 收盘回到区间中轴：视为拉升失败候选，先按计划离开，不等「再给一次」。费率偏高且你是付费方时，先减观察仓，不是反向乱空。

## 案例

### 题

Creek 被一根放量 4H 收盘站上，随后两根缩量回踩到沿上，1H 出现长下影。如何命名？

## 常见错误

1. 区间内的放量阳线当 SOS。
2. SOS 当根市价追全仓。
3. 用 15m 破前低否定 4H BUEC。
4. 山寨 SOS 后用过高杠杆。回踩可以很深。

## 局限性

等距目标是几何练习，不是价格会走到那里。高潮上影后仍可能再创新高。停止加仓不是自动开空。

## 总结

离开看收盘和量，跟上看缩量回踩。
