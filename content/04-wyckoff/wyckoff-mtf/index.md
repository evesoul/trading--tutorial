# 多周期怎么对阶段

单周期威科夫会把你做成显微镜交易员：15m 天天有弹簧。共振不是四个周期都完美才动手，而是 **大周期定阶段，中周期定事件，小周期只负责触发。**

先修：[多周期](/trading-system/multi-timeframe)。本篇只把四阶段装进那套决策 / 执行周期。

## 学习目标

- 按日线 → 4H → 1H → 15m 的顺序打开图
- 用 A/B/C 给观察仓分级
- 止损归属 4H，不归属 15m

## 概念

| 周期 | 职责 | 可以决定 | 不可以决定 |
| --- | --- | --- | --- |
| 日线 | 阶段 | 吸筹 / 拉升 / 派发 / 下跌 / 不明 | 具体进出场价 |
| 4H | 结构 | Creek / Ice、SOS / SOW、弹簧 / UTAD | 精确撮合 |
| 1H | 确认 | Test、BUEC、LPSY 的质量 | 推翻日线阶段 |
| 15m | 执行 | 限价微调、减少滑点 | 方向、阶段命名 |

A 级：日线阶段 + 4H 事件 + 1H 确认。B 级：日线中性 + 4H 事件。C 级：仅 1H/15m 好看 → 0。冲突 → 0。

## 原理

未收盘的低周期不能推翻已收盘的高周期。15m 弹簧在日线下跌里，只是空观察的管理点，不是反手点。

## 怎么使用

入场清单从上到下：日线是否允许这个方向；4H 事件是否标准或可接受变形；1H 量价是否确认；15m 是否给到更好挂单价而不是追价；费率 / 结算 / 周末是否通过。前三项是硬条件。

T1 可以看 1H 前高前低先减一部分；T2 必须看 4H / 日线。15m 目标不能成为主目标。山寨 15m 好看、BTC 日线相反时，山寨服从 BTC 日线。

## 案例

### 题

日线吸筹末段，4H 刚 SOS，1H 正在缩量回踩，15m 已连涨你没上车又突破新高。追不追？

**先自己答，再看解析。**

<details>
<summary>解析（不是标准交易指令）</summary>

不追 15m 新高。等下一个无供给回踩。追 15m 等于把 A 级结构做成 C 级追价。

</details>

## 常见错误

1. 四周期都画满线。每个周期最多：阶段、上沿、下沿、一个事件点。
2. 15m 止损 + 4H 目标。结构不匹配。
3. 矛盾时取平均。矛盾时取大周期或空仓。

## 局限性

「A/B/C」是教学分级，不是期望保证。UTC 日线收盘和交易所展示时区可能不一致，写清你用的收盘口径。

## 总结

先打开日线。止损属于 4H。
