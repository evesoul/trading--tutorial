# 把阶段写成系统

教程读完不会自动赚钱。系统 = **少数可重复规则 + 记录 + 每次只改一件事**。本篇帮你防止「学得越多越乱」。

先修：[什么是交易系统](/trading-system/what-is-a-trading-system)、[系统优化](/trading-system/system-optimization)。

## 学习目标

- 写出自己的 v1.0 边界（品种、周期、主事件、风险、禁止条件）
- 主策略不超过两个
- 说明为什么 20 笔才改一条

## 概念

个人系统必须有边界。边界以外的机会，默认属于别人。教学示例（不是推荐）：

- 市场：U 本位永续
- 品种：BTC、ETH 为主
- 周期：日线阶段 / 4H 事件 / 1H 确认 / 15m 执行
- 方向：只做与日线阶段同向的 A/B 级
- 风险：单笔用权益百分比上限；日 / 周熔断自己写死
- 禁止：结算前追单、无 7 格计划开仓、阶段不明

## 原理

亏 3 笔就改 5 条规则，无法知道什么有效。样本不够时，先修执行，不修理论。见 [数据统计](/trading-system/statistics)。

## 怎么看

一张 A4 每笔都填：日期品种、阶段、事件、努力倍数、结果、过滤器、入场、止损、T1/T2、N / 杠杆 / 强平、仓位系数、作废条件。

前几周可以只标阶段；再只做一种主观察（例如只练 BUEC 或只练 Ice 回踩）；不要第一周把第 2–10 篇同时实盘。

复盘表字段：计划 R、实际 R、阶段对不对、事件对不对、量价、过滤器、执行偏差。偏差标签建议固定：追价、止损改最新价、随意加仓、提前砍、报复单、7 格没写。

健康曲线：小亏一串、偶发较大盈利，回撤来自连续止损，不是单笔巨大亏损。病态：单笔远超计划 R，或盈利全走、亏损单拿到很深。这是执行对称问题。

## 怎么使用

建议的 v1.0 只是作业纸起点：只做 BTC/ETH；只做 A/B 级；多观察 Spring Test 或 BUEC；空观察 LPSY 或破 Ice 回踩；止损标记价；费率偏高时同向观察仓下降。你必须改成自己的数字，不能把课文示例当成颁布标准。

v1.0 只做 BUEC 时，看到「完美 UTAD」实盘可以不做，记进纸上样本。系统的力量是放弃非主策略的完美单。

## 常见错误

1. 把全书当成同时生效的几十条规则。
2. 回撤时更换整套方法，样本被重置。
3. 只复盘亏损单。盈利单里的追价幸运也要打执行负分。
4. 每天改规则，叫做持续损坏。

## 局限性

纸上 20 笔和实盘 20 笔不是同一分布。杠杆、滑点、情绪都会变。

## 总结

先 v1.0，再 20 笔改一条。
