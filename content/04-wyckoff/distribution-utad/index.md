# 派发：UTAD 与 LPSY

派发是吸筹的镜像：筹码从愿意持有的人转到愿意接最后一棒的人。高位第一根长上影不是派发完成。

## 学习目标

- 按 PSY / BC / AR / ST / UTAD / LPSY / Ice 标高位区间
- 区分 UTAD 收回和 SOS 站上
- 说明趋势多可以阶梯减，空观察更稳的是 LPSY 或破 Ice 回踩

## 概念

PSY / BC 对应 PS / SC。Ice 对应 Creek，是派发下沿。UTAD 对应 Spring：刺破上沿后收回。LPSY 对应 LPS：最后一次缩量反弹。

识别顺序：先有上涨后的 TR，再谈 UTAD。

## 原理

BUEC 在突破后的上沿**外侧**缩量；派发 ST 在旧高**内侧**缩量不过。正费率可以在趋势里维持很久，见 [Funding + OI](/combinations/funding-oi)，费率不是入场信号。

LPSY 量应小于 UTAD 和 BC，高点更低。

## 怎么使用

已有趋势多时，PSY / BC 可以减，UTAD 收回可以清掉趋势多观察仓。空观察三档：UTAD 收回（更激进、更小仓）；LPSY 缩量失败；4H 收盘破 Ice 后回踩失败。后两档更干净。

若空后价格收盘站回上沿且放量：你可能把 SOS 当成了 UTAD，按作废离开。

## 常见错误

1. BC 当根开空。高潮当根你不知道它是不是还要再高潮。
2. 正费率就空。
3. UTAD 没收回就空。
4. 破 Ice 后立刻摸底。

## 局限性

多次上冲可以耗很久，Ice 没破之前下跌可以等很久。双顶要比重，不要只数顶。

## 总结

先上涨后的 TR，再谈上冲收回。健康突破回踩不是顶部。
