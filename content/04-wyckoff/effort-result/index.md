# 努力与结果

威科夫事件告诉你「在哪」；量价告诉你「这次有没有人认真做」。努力与结果不一致时，练习记法是减仓或空仓，而不是解释成更复杂的故事。

## 学习目标

- 写出努力（几倍均量）和结果（收盘在结构哪一侧）
- 用 OI 和清算过滤假努力
- 把背离只当成停止加仓，不当成自动反手

## 概念

努力 = 成交量、主动吃单、OI 变化。结果 = 价格位移、是否站上或跌破、下一根是否跟随。

| 组合 | 含义 | 练习记法 |
| --- | --- | --- |
| 大努力 + 大结果 | 趋势有效候选 | 可顺势等回踩 |
| 大努力 + 小结果 | 对面在吸收 | 不追 |
| 小努力 + 大结果 | 真空 | 可跟，目标保守 |
| 小努力 + 小结果 | 无兴趣 | 不做突破观察 |
| 价新高/新低 + 量更小 | 量价背离 | 停止加仓 |
| 价回撤 + 量更小 | 健康回踩候选 | 可接力观察 |

永续额外两项努力：OI 增减、清算（强制努力，结果经常立刻反抽）。

## 原理

只看相对 20 均量。价格越高，同样币数的成交额越大，不要把 USDT 金额当努力。见 [成交量](/indicators/volume)。

识别假努力：OI 骤降、费率不动或反向、标记价波幅小于最新价。不当 SOW 追空。

无需求 / 无供给是确认件，不是触发件：Ice 下的无需求给空观察加分；Creek 上的无供给给多观察加分。单独一根不够开仓。

## 怎么使用

把量价挂在第 2–5 章结构上：Spring Test 需要回测量明显小于弹簧；SOS / SOW 需要放量且收盘在外；BUEC 需要回踩量小于 SOS。结构合格 + 量价冲突 = 0 仓。只有量价、没有结构 = 0 仓。

止损宽度仍由结构定，不因为「量很大」就放到很远。量很大只意味着滑点可能更大：缓冲略加，同时减小 N。

## 案例

### 题

4H 冲击 Creek，当根 3.8×，长上影收回沿下，OI 上升，下一根缩量仍在沿下。做多、做空还是等？

**先自己答，再看解析。**

<details>
<summary>解析（不是标准交易指令）</summary>

等。大努力小结果 = 上沿吸收。做多没有 SOS。做空缺少完整派发。标 PSY/UT 候选。

</details>

## 常见错误

1. 看绝对量。
2. 背离当反手理由。
3. 15m 量价对抗 4H 结构。
4. 等量能确认却不加止损计划。

## 局限性

减半日、节日、上币会让绝对量失真。相对均量也会漂。

## 总结

先写努力数字和收盘位置。冲突则降仓。
