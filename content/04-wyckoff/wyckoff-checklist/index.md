# 检查清单与自评

把本篇当成单独一页。开仓前扫清单，每周按过程打分。清单通过不等于会赢；清单不通过 = 练习上先不点。

## 学习目标

- 按界面、阶段、事件、量价、共振、过滤器、数字把清单走完
- 用执行分而不是盈亏当总分
- 阶段不明时一票否决

## 概念

一票否决示例：日线阶段不明或与方向冲突；7 格没写完；止损用最新价且挂在整数上；结算窗口满仓追突破；清算瀑布当根追单；强平价靠近止损内侧；想靠「再给一次」取消作废；已触发自己写死的日 / 周熔断。

## 原理

分数是过程。盈亏是结果。样本不够时不讨论「策略无效」。见 [回测](/trading-system/backtesting)。

## 怎么看

界面：确认是 USDT 永续；能看到最新价、标记价、资金费率、倒计时、成交量；杠杆不是上次残留；条件单准备用标记价。屏幕字段见 [交易所屏幕](/course/perp-screen)。

阶段：日线已收盘结论，或明确这是盘中临时阶段。四阶段只选一个，含「不明」。不明则停止。

事件：沿已标；名称只选一个；收盘位置满足；不是周末枯竭时段的唯一证据；变形已降仓。

量价：写出努力倍数和结果；回踩是否缩量；OI 区分趋势增量与清算塌陷；无结构的纯背离不反手。

共振：打开顺序日线 → 4H → 1H → 15m；止损归属 4H。

过滤器：非结算前追单；费率未到你自己的满仓禁止线；无严重双价格撕裂；不是清算当根。

数字：R、S、N、数量、保证金、预估强平必须写得出。数量来自公式。

## 怎么使用

章节掌握可以按概念、图解、规则、避坑、情景题五项自评，用来找薄弱章，不是考试录取线。单笔执行分建议覆盖：阶段、事件、量价、过滤器、公式仓位、止损设置、按计划减仓、复盘记录。连续违规先停，不先改理论。

四阶段默认练习动作：

| 阶段 | 默认 | 主观察 | 禁止 |
| --- | --- | --- | --- |
| 吸筹 | 观察 / 等 Test | Spring Test | 摸 SC 当根 |
| 拉升 | 持有 / 回踩 | BUEC | SOS 高潮追满仓 |
| 派发 | 减多 | LPSY / 破 Ice | BC 当根空、Ice 下抄 |
| 下跌 | 持空 / 反弹空 | Ice 回踩 | 恐慌当根追、15m 弹簧反手 |
| 不明 | 空仓 | 无 | 一切「看起来能做」 |

## 常见错误

用一周盈亏当总分。用热力图替代清单。清单打勾但 7 格数字是空的。

## 局限性

阈值和熔断必须写成你自己的版本。抄课文百分数当「官方标准」会失效。

## 总结

活下来靠阶段对、仓位对、止损先于强平、过滤器会否决。清单是为了让激动时还能做那件无聊的事。
