# 入场规则

本篇只写开仓前的最后两层：**交易前提**和**入场触发**。环境与方向已经在前面两篇。

本站只提供交易教育，不提供买卖信号、荐股、喊单或自动交易。教学示例只说明如何写规则，不是推荐策略，不能代表未来结果。

先修：[方向判断](/trading-system/direction)、[订单与成交](/trading-system/order-types)。对照观察可复习 [趋势 + 动量](/combinations/trend-momentum)。触发后用什么单、没成交算不算入场，先修订单篇。教学默认：未成交视为未入场。

类比：前提像「跑道已清空，允许滑行」；触发像「看到指定灯号才起飞」。跑道清空不是起飞。灯号没有出现，飞机停在原地，这是规则在工作。

## 学习目标

读完本篇，你应该能：

- 把入场拆成前提 + 触发，不混在一句「看着能进」里
- 写出「必须同时满足」或「满足 A 后等待 B」
- 在只满足一部分时选择不做
- 检查三个条件是不是在问同一件事
- 写出触发后的成交假设；未成交视为未入场
- 认出金叉、回踩、超卖都只是观察，写成触发前要先有环境和方向

## 概念

| 层级 | 问题 | 还没发生什么 |
|---|---|---|
| 环境 | 现在允许交易吗？ | 还没有方向 |
| 方向 | 偏多、偏空还是不交易？ | 还不能找点位 |
| **交易前提（Setup）** | 结构、位置、指标分工已经对齐，可以开始等触发 | 还不能执行 |
| **入场触发（Entry）** | 哪一条发生后才按规则执行 | 执行后立刻进入出场与仓位检查 |

**前提**说明「可以开始找触发」。例如：环境是趋势，方向是偏多，价格回到快速均线附近，力度没有跌破你写好的中轴。

**触发**说明「这一条出现后才做」。例如：随后一根 K 线收盘重新离开该均线，且成交量高于你写好的近期均值。

前提不等于触发。把两层写在一句里，盘中很难复核，也很难复盘「到底卡在哪一层」。

它回答：在已经选定的环境和方向里，还要满足哪些可检查的观察，才允许开仓。

它不回答：止损放哪、赚多少、仓位开多大、这次会不会赢。那些是出场和仓位格。入场句写完，系统仍未完成。

条件来自指标组合时，每个条件应对应不同问题：一个管位置，一个管力度，一个管参与度。三个条件其实都在说「均线向上」，只是同一份价格信息的重复采样。分工见 [多指标共振](/combinations/multi-indicator)。

## 怎么写规则

建议写成清单，不要写成散文：

1. **先引用上游。** 环境未通过，或方向 = 不交易：入场条件整组不成立。
2. **列出前提。** 每条都能指向「它回答什么问题」。写清同时满足，还是按顺序满足。
3. **单独列出触发。** 用收盘、离开某条均线、量能达到某个可复算的标准，而不是「感觉启动了」。
4. **写只满足一部分时的动作。** 默认：不做。不要写成「先下一半意思意思」。
5. **写失效。** 等待触发的过程中，环境或方向已经变：前提作废，而不是降级成更差的触发。
6. **写决策周期和执行周期。** 例如 4H 管环境与方向，15m 只负责触发。短周期噪声更大，成本占比通常更高。周期打架见 [多周期](/trading-system/multi-timeframe)。
7. **写触发后的成交假设。** 用市价还是限价、是否允许一次追价，见 [订单与成交](/trading-system/order-types)。**未成交视为未入场。** 未写追价句，就视为未入场。部分成交须事先选定：视为未入场，或按已成交部分重算。

教学示例（只说明如何写规则，不是推荐策略）：

1. 环境：4H 收盘位于慢速 EMA 之上，且近期摆动高点高于前高。
2. 方向：按上一篇的句子，标签为偏多。
3. 前提：价格回到快速 EMA 附近，[RSI](/indicators/rsi) 从高位回落但未跌破中轴。
4. 触发：随后一根 K 线收盘重新离开该 EMA，且 [成交量](/indicators/volume) 高于最近 N 根均值。
5. 只满足 1–3、没有 4：不做。没有止损句：也不做。
6. 触发后限价未成交：视为未入场，不改方向句。

请把上面当作填空示范。换掉品种、周期、均线或 RSI，句子仍要能复核。它不是本站推荐的入场。

看图顺序：

1. 先确认环境和方向标签还在。
2. 再看位置是否进入你写的前提区。
3. 再看力度或参与度有没有否定前提。
4. 等到触发那一根收盘（或你指定的确认方式）。
5. 触发出现时，先核对禁止条件，再进入出场框架，而不是先点下单再想退路。
6. 单没成交：这一笔不存在，不占用热度。

未收盘的 K 线可以变。把「盘中已经穿过均线」当成触发，另一个人无法用收盘数据复核。触发成立但限价没成交，同样不算入场。

## 正反案例

下面两段必须对照着看。它们是教学情景，不是真实行情，不能代表未来结果。

### 正例：前提成立，触发没来，空仓等待

环境和方向都通过。价格回到快速均线附近，RSI 回落到中轴上方。你记下「前提成立，等待收盘离开均线」。随后几根都没有按你的句子离开，或成交量达不到你写的均值。你不做。前提后来被一根跌破中轴的收盘作废，你把状态改回等待环境，而不是改触发标准去迁就画面。

这是正例：入场规则的主要工作，常常是拦住你。拦住之后，行情仍可能继续涨。涨了也不证明该改规则去追，只说明漏掉一笔和遵守规则可以同时发生。

### 反例：回踩出现就当成已经触发

价格靠近均线。有人写成「回踩了，开多」。没有收盘确认，没有力度条件，也没有「只满足一部分时不做」。影线刺到均线下方又收回，另一边把同一根读成「跌破，开空」。两人看同一根 K 线，结论相反——说明句子不够规则化。

再补一条：把 [MACD](/indicators/macd) 金叉单独写成触发，却没有环境和方向。震荡里金叉会很密。金叉是力度观察，滞后，不是自动开仓。

再补一条：三个条件都在问均线有没有向上——慢线向上、快线向上、价格在上方。看起来很严，实际没有新问题。过滤变严，样本变少，风险也不会消失。

## 常见错误

1. 前提和触发写在一句里，复盘时说不清卡在哪一层。
2. 只满足一部分就「先下一半」。
3. 把回踩、金叉、超卖直接写成开仓指令。
4. 等待触发时改参数，直到图看起来能进。
5. 三个条件问的是同一件事，却当成三重确认。
6. 用未收盘的盘中穿越当触发。
7. 入场句写得很细，出场和止损仍是空白。
8. 把教育示例当成可跟单条件。

## 局限性

- **写得越细，历史样本往往越少。** 很少几笔的漂亮结果更容易是运气。
- **触发清楚时，价格可能已经离开更好的位置。** 这是可复核性的代价，不是系统坏了。
- **滑点会让实际成交价差于规则价。** 永续市价单尤其明显。
- **周期拆分会引入新冲突。** 4H 前提还在，15m 触发可能来回响。要写清以哪一根为准。
- **入场规则覆盖不了后半链路。** 没有出场框架和仓位，入场只是半句话。
- **永续合约有强平风险。** 入场冲动加上高杠杆，缓冲会先被吃掉。本站不鼓励高杠杆。历史案例不能代表未来结果。

## 总结

记住五句话：

1. 入场 = 前提 + 触发。
2. 环境和方向没过，入场整组不成立。
3. 只满足一部分时，默认不做。未成交视为未入场。
4. 每个条件应回答不同问题，不要重复采样。
5. 示例只教写法，不是信号，也不能代表未来结果。
