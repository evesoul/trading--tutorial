# 出场规则

本篇先搭架子：**开仓之前，就要能回答「何时离开」。** 止损和止盈是这个架子上的两根柱，不是开仓之后再想的两句话。

本站只提供交易教育，不提供买卖信号、荐股、喊单或自动交易。教学示例只说明如何写规则，不是推荐策略，不能代表未来结果。

先修：[入场规则](/trading-system/entry-rules)。系统全貌见 [什么是交易系统](/trading-system/what-is-a-trading-system)。

类比：进门之前先看安全出口在哪。出口图上不只一扇门：认错走一扇，目标走到一扇，待太久走一扇，规则作废走一扇。没有出口图，就不要进门。

## 学习目标

读完本篇，你应该能：

- 说出出场先有框架，再拆止损和止盈
- 列出四类离开：止损、止盈、时间、规则失效
- 把「看情况再走」从规则里删掉
- 写出持仓中环境翻转时怎么处理，而不是即兴反手
- 认出还没写止损，就不能谈止盈和加仓

## 概念

**出场规则**回答：仓位什么时候从有到无，或从大到小。它属于系统，不属于任何一张副图。指标可以对你说「力度在弱」，但不能替你规定离场价。

| 类型 | 典型问题 | 后面哪一篇细写 |
|---|---|---|
| 止损离场 | 价格触及认错位置 | [止损](/trading-system/stop-loss) |
| 止盈离场 | 价格到达目标或移动止盈 | [止盈](/trading-system/take-profit) |
| 时间离场 | 持仓超过预定根数仍无进展 | 本篇先写进框架 |
| 规则失效离场 | 环境翻转、数据异常、禁止条件出现 | 本篇先写进框架 |

只写「止盈止损」不够。很多亏损不是因为没设数字，而是因为持仓理由已经消失，人还坐在里面等一个更舒服的价。

它回答：离开的路径有几条，每条由什么触发，触发后是全平还是减仓。

它不回答：这一笔会赚多少、哪一种出场「最优」。也先不展开仓位公式——仓位要等止损距离有了再反推，见 [仓位管理](/trading-system/position-sizing)。

和入场的对称：入场拆前提 + 触发；出场也要拆「仍允许持有的前提」+「离开的触发」。持有前提一破，就走规则失效这条，而不要改口成新的入场。

## 怎么写规则

开仓前，先能填这张表：

1. **认错离开。** 错了在哪个价、以收盘还是盘中触及为准、触发后是否立即离场。细节下一篇写，本篇至少承认这一格不能空。
2. **目标离开。** 第一目标在哪、是否分批、剩下的怎么处理。细节见止盈篇。
3. **时间离开。** 例如：决策周期走满 N 根，价格仍没有朝你的方向离开前提区，按规则平掉。N 要写死。时间止损不是因为「等不及」，而是**资金费和保证金占用都在烧**：每多拿一个结算周期，来回成本继续垫 R，保证金也一直被占用。见 [成本对照 R](/trading-system/cost-vs-r)、[交易所屏幕上有什么](/course/perp-screen)。
4. **失效离开。** 环境从趋势变成震荡或看不清；方向标签改回不交易；[持仓量](/indicators/open-interest) 或费率数据缺失；点差明显变宽。写清动作：只平不开，或全平。持仓中 [RSI](/indicators/rsi) 或其他副图**不能否决已经写好的止损**；环境失效可以离场，那是本条，不是「力度还在所以不走」。
5. **持仓中禁止即兴反手。** 反向条件若要做，必须当作一笔新的入场：重新走环境 → 方向 → 前提 → 触发。出场不是自动开反向仓。
6. **顺序约束。** 止损句未完成，不写加仓，也不把止盈当成「先活下来」的替代。

教学示例（只说明如何写规则，不是推荐策略）：

> 持有前提：环境仍是趋势，方向标签仍是开仓时的那一侧。  
> 止损：入场后立即挂上事先算好的认错价（下一篇定义）。  
> 止盈：到达 2 倍于止损距离的第一目标时平一半，剩余用移动规则（止盈篇定义）。  
> 时间：4H 走满 8 根仍未触及第一目标、也未创新的有利摆动，全平。  
> 失效：4H 收盘让环境改成震荡或看不清，全平，当天不再用同一方向开新仓。

请把数字当成填空示范。换掉倍数和根数，架子仍要在。它不是本站推荐的出场。

看持仓时的顺序：

1. 先问持有前提还在不在。不在，走失效，不要先看浮盈浮亏。
2. 再问价格有没有触及认错位置。
3. 再问有没有到达目标或时间上限。
4. 最后才看副图有没有「看起来还能拿」。副图不能否决已经写好的离开句。RSI 不能否决止损；环境失效可以走本篇的失效出口。

## 正反案例

下面两段必须对照着看。它们是教学情景，不是真实行情，不能代表未来结果。

### 正例：开仓前四条离开都写了

入场触发出现前，你已经写下认错价、第一目标、最多拿几根、环境翻转就走。触发出现后，按句子挂上止损，不再把「再看看」当作第五条路径。后来价格横着走满你写的根数，你按时间离场。随后行情又朝原方向走。你记下「遵守了时间句」，而不是「早知道多拿一会」。

这是正例：框架的工作是让离开可复核。少拿一段，和遵守规则可以同时发生。一次少拿，不够用来删掉时间句。

### 反例：进场后再说看情况

触发出现，仓位已经在，止损还没想好。价格一逆行，有人把认错位往远处挪；一顺行，又把目标往远处挪。副图金叉还在，就继续拿；金叉没了，又说「力度没了该走」。同一笔交易，出口随画面改了三次。另一个人无法数出「这套规则离场了几次」。

再补一条：环境已经走平，仍死守原来的止盈数字，理由是「还没到目标」。目标是在趋势前提上写的。前提没了，应走失效，而不是把旧目标当成护身符。

再补一条：止损触发后立刻反手。出场只负责离开。反手是新的一笔，要重新满足环境和方向。把两者焊在一起，连亏时会连续打在同一段震荡里。

## 常见错误

1. 只有入场，出场写「到时候看」。
2. 只写止盈止损，不写时间和失效。
3. 还没写止损，就先写止盈和加仓。
4. 持仓中用副图否决已经写好的离开句。
5. 把出场自动焊成反手。
6. 浮亏时移动认错位，浮盈时移动目标，却不承认规则已经改了。
7. 认为出场框架能消除亏损。框架只让亏损可检查。
8. 把教学示例里的倍数抄成「标准出场」。

## 局限性

- **四条路径仍可能互相打架。** 例如时间到了但价格刚接近目标。要写清优先级，例如时间优先于未完成的目标。
- **执行价格会滑。** 规则价和成交价不是同一回事，尤其在剧烈波动里。
- **时间离场在趋势里会显得「过早」。** 这是用可复核性换弹性，不是指标坏了。
- **失效句如果太宽，你会频繁被洗出去；太窄，又会假装环境还在。** 需要记录，而不是盘中改口。
- **本篇不代替止损、止盈、仓位的专篇。** 架子搭好，柱子还要单独量。
- **永续合约有强平风险。** 没有出场框架的仓位，杠杆会先替你「出场」。本站不鼓励高杠杆。历史案例不能代表未来结果。

## 总结

记住五句话：

1. 出场先有框架，再拆止损和止盈。
2. 离开至少有四类：认错、目标、时间、规则失效。
3. 「看情况」不是规则。
4. 止损句未完成，不要谈止盈和加仓。
5. 出场不是自动反手；示例只教写法，不能代表未来结果。
