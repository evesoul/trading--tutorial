# 什么是交易系统

本篇打开阶段 3。它只回答一件事：**交易系统是事先写好的规则，加上事后能检查的记录。**

本站只提供交易教育，不提供买卖信号、荐股、喊单或自动交易。学完本篇，也不等于已经具备稳定交易的能力。文里的写法示例只说明「规则可以写成什么样」，不是推荐策略，不能代表未来结果。

先修：[K 线](/indicators/kline)、[MA](/indicators/ma)、[EMA](/indicators/ema)、[RSI](/indicators/rsi)，以及 [趋势 + 动量](/combinations/trend-momentum)。系统课假设你会看图，不再从零讲指标。阶段 2 的收束见 [多指标共振](/combinations/multi-indicator)。

类比：系统像一份菜谱加一本厨房笔记。菜谱写清什么时候开火、关火、一次放多少盐。笔记记下有没有照着做。更灵敏的温度计，代替不了菜谱。

## 学习目标

读完本篇，你应该能：

- 用自己的话说：系统 = 事先写好的规则 + 记录，不是找一个更准的指标
- 按「环境 → 方向 → 进出场 → 仓位 → 复盘」说出链路顺序
- 指出理念、规则、记录各管什么，指标只进入观察层
- 认出「先看图再编理由」不是系统
- 把本站继续当成教育站，而不是信号源

## 概念

| 零件 | 它在回答 | 它不回答 |
|---|---|---|
| 交易理念 | 你准备在什么市场、用什么周期、接受怎样的交易频率 | 下一根 K 线往哪走 |
| 规则 | 环境、方向、入场、出场、仓位、禁止条件分别怎么检查 | 哪一个指标最准 |
| 记录 | 有没有按规则做，当时环境是什么，结果和计划差在哪 | 下一次会不会赚 |

**交易理念**是你愿意遵守的边界：只做哪类品种、用哪根决策周期、一天最多看几次图。它先于指标。没有理念，后面的规则会随心情改。

**规则**要能让两个执行者得到同一结论。写「看起来要涨」不算规则。写「4H 收盘在慢速均线之上，且均线向上」才开始像规则。对错另说，至少别人能复核。

**记录**把执行和结果分开看。先问有没有遵守规则，再问规则要不要改。一次盈亏不够用来改系统。

它回答：

- 开仓前，我能不能把「做 / 不做」写成可检查的句子？
- 错了，我事先有没有写清在哪里认错、亏多少？
- 做完之后，我能不能对照记录，而不是靠记忆改规则？

它不回答该开多还是开空，也不证明某套规则能盈利。指标组合只进入链路前半的观察层，见 [趋势 + 动量](/combinations/trend-momentum)。止损、仓位、复盘不由指标自动给出。

逻辑顺序不要跳：

```text
市场环境 → 方向 → 交易前提 → 入场触发 → 止损 → 止盈 → 仓位 → 离场 → 复盘
```

环境没写清，方向是空话。方向没写清，入场是临场发挥。止损没写清，仓位没有定义。仓位没写清，盈亏数字没有教育意义。

## 怎么写规则

按这个顺序填，不要倒过来先找买卖点：

1. **先写理念。** 市场、合约类型、决策周期、你不做什么。例如：只观察 U 本位永续、用 4H 判断环境。这是作业纸上的边界，不是品种推荐。
2. **再写环境。** 趋势、震荡、高波动、低波动、看不清时是否空仓。详见下一篇 [市场环境](/trading-system/market-regime)。
3. **再写方向。** 只回答偏多、偏空或不交易，不要把下单细节混进来。
4. **把入场拆成前提 + 触发。** 前提是「可以开始找触发」；触发是「这一条发生后才执行」。
5. **先写出场框架，再拆止损和止盈。** 至少能回答：错了怎么走、对了怎么走、时间到了怎么走、规则失效怎么走。
6. **用单笔亏损上限反推仓位。** 先想赚多少，仓位没有锚。
7. **写禁止条件。** 数据缺了、点差异常、当天已达亏损上限：空仓或只平不开。
8. **留下记录栏。** 当时环境、方向、前提、触发、计划中的止损止盈、实际仓位、实际离场、有没有改规则。

教学示例（只说明如何写规则，不是推荐策略）：

> 名称：某品种-4H-趋势回调观察。  
> 环境：4H 大多数时间停在慢速均线一侧，均线有斜率，才允许找方向。  
> 方向：收盘在上行均线之上记偏多；之下记偏空；走平或频繁穿越记不交易。  
> 前提与触发、止损、仓位：后面几篇分别写，本篇先承认它们必须事先存在。

写完后做一次最小检查：换一个人，只看你的句子，能不能在历史图上数出「做了几笔」。数不出来，先改措辞，不要先调参数。

## 正反案例

下面两段必须对照着看。它们是教学情景，不是真实行情，不能代表未来结果。

### 正例：先写规则，再打开图

你先在纸上写：只在趋势环境找方向；方向未确立就不进入前提；没有止损距离就不算仓位。然后才打开图，把 [EMA](/indicators/ema) 和 [RSI](/indicators/rsi) 填进已经写好的格子。图上看起来「很顺」时，你仍对照禁止条件。对不上，就记「不交易」。

这是正例：指标是观察工具，系统是事先存在的句子。后来这笔仍可能打到止损。失败不证明不该先写规则，只说明规则不是收益开关。

### 反例：先找准指标，再补理由

上一波上涨里，有人发现某周期 [RSI](/indicators/rsi) 看起来「更贴」。于是把参数改到图顺眼为止，再补一句「这就是我的系统」。没有环境定义，没有「不交易」出口，没有记录。下一波震荡里，同一套读数来回打架。

这不是指标坏了。是把系统理解成「找一把更准的尺」。尺可以换，菜谱不能事后编。

再补一条：把 [多指标共振](/combinations/multi-indicator) 读成「对齐了就可以下单」。共振只说明不同问题暂时没有互相否定，还缺出场、仓位和记录。

## 常见错误

1. 把系统理解成「找到那个准指标」。指标回答观察问题，不代替规则。
2. 先看图，再为已经想开的仓编理由。
3. 规则写在脑子里，认为自己记得住。换一天情绪不同，执行就不同，无法复盘。
4. 只有入场句，没有「不交易」和出场句。
5. 认为阶段 2 的对照已经构成系统。对照只覆盖链路前半。
6. 把教育示例抄成跟单条件。本站不提供信号。
7. 一次盈亏之后立刻改规则。先分清是没遵守，还是规则本身要改。
8. 用「还没读完风险、回测、案例」当借口，推迟写清前八格。

## 局限性

- **写下来不等于可交易。** 句子能复核，只说明可以开始检查，不说明结果可接受。
- **同一套句子换品种、换周期，含义会变。** 流动性、资金费、滑点都会改执行。
- **理念含糊时，后面每一格都会跟着飘。**
- **记录不全时，优化没有对象。** 本篇只要求你先留栏；怎么记、怎么回测见后半的日志和回测课。
- **永续合约有强平（爆仓）风险。** 杠杆会放大规则执行过程中的浮亏。本站不鼓励高杠杆。
- **历史填写和教学案例不能代表未来结果。**

## 总结

记住五句话：

1. 系统是事先写好的规则加记录，不是找一个准指标。
2. 顺序是环境 → 方向 → 进出场 → 仓位 → 复盘，不要跳步。
3. 规则要能让另一个人复核；写「看起来要涨」不算。
4. 不满足规则时，默认出口是不交易。
5. 本站是教育站。示例只教写法，不是信号，也不证明能盈利。
