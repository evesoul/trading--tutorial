# 订单与成交

本篇只回答一件事：**规则如何变成一笔可能成交、也可能不成交的单。**

「条件满足」是观察。「单已成交」才进入仓位与热度。两件事不是同一个时刻。

本站只提供交易教育，不提供买卖信号、荐股、喊单或自动交易。教学示例只说明如何写规则，不是推荐策略，不能代表未来结果。本篇没有买卖按钮，也不写「现在开多」。

先修：[方向判断](/trading-system/direction)、[交易所屏幕上有什么](/course/perp-screen)。屏幕上的最新价和标记价，本篇要写成订单看哪一个。

类比：菜谱写「水开了下锅」，还要决定是整锅倒进去，还是一勺一勺试。倒进去不见得是你写下的那个温度；试一勺也可能永远下不了锅。

## 学习目标

读完本篇，你应该能：

- 用一句话分开：规则成立，和单已成交
- 说出市价、限价、止损市价、止损限价各承诺什么、各放弃什么
- 解释只减仓避免什么意外；只做 maker 用一句说清
- 用白话记住 GTC / IOC / FOK
- 区分最新价止损单和标记价强平；部分成交、未成交须事先写怎么算

## 概念

**订单（Order）**是把交易意图交给撮合引擎的指令：在什么价、以什么方式、开仓还是减仓。

订单不是观察工具，也不是「方向正确」的证明。挂出去之后，结果可能是：全部成交、部分成交、触发了但没成交、被自己或系统撤销、或在成交前先被强平。

教学要分清三层：

| 层 | 含义 |
|---|---|
| 计划 | 规则里写的入场价、止损价 |
| 订单 | 真正送到撮合的指令类型与条件 |
| 成交 | 实际成交价、数量、手续费与滑点 |

计划价不等于成交价。名称因交易所而异。课文写行为，不写某家所的按钮路径。

## 怎么写规则

四种常见订单，各承诺一件事，放弃另一件：

| 类型 | 英文 | 承诺 | 放弃 |
|---|---|---|---|
| 市价单 | Market Order | 尽快成交 | 成交价 |
| 限价单 | Limit Order | 价格边界 | 成交本身 |
| 止损市价 | Stop-Market | 触发后尽快成交 | 成交价 |
| 止损限价 | Stop-Limit | 触发后仍守价格边界 | 触发后的成交本身 |

**市价**：立刻按对手盘能成交的价格吃单（taker）。成交速度快，**滑点由当时盘口厚度决定**。市价解决「必须成交」；它不保证价格。

**限价**：你出的价格（或更好）。买单不会高于该价成交，卖单不会低于该价成交（常规撮合）。**可能一直不成交**。限价解决「价格边界」；它不保证成交。

**止损市价**：价格触发条件之后，**变成市价单**去吃对手盘。触发价不是保证成交价。常用于认错离场：条件到了，优先成交，而不是优先价格。

**止损限价**：价格触发条件之后，**变成限价单**。触发了仍可能不成交：行情穿过限价、簿上没有对手、或只成交一部分。教学必须把「触发 ≠ 成交」写进系统假设。

白话对照：

- 市价：要成交，价格让给盘口。
- 限价：要价格，成交让给盘口。
- 止损市价：认错后优先离场，成交价可以更差。
- 止损限价：认错后仍想守一个价，穿过去就可能还留在仓里。

### 只减仓、只做 maker、有效期

**只减仓（Reduce-Only）**：这笔单最多把已有仓位减小，不会在平仓方向上**开出反向新仓**。平仓单或止损单若写成普通单，在仓位已变、或部分成交之后，余量可能变成反向开仓。只减仓把这类意外挡住。它不保证成交，也不降低强平风险。

教学默认：认错离场、减仓、止损，优先用只减仓。

**只做 maker（Post-Only）**：只挂到订单簿当 maker。若下单瞬间就会与对手成交（变成 taker），交易所通常**撤单或不接受**，而不是让你吃单。一句记：不成交则撤，不当 taker。它不是「更安全」，只是成交角色约束。

有效期用白话记行为：

| 缩写 | 英文 | 白话 |
|---|---|---|
| GTC | Good Till Cancel | 一直挂着，直到成交或你撤 |
| IOC | Immediate Or Cancel | 能立刻成交的部分成交，其余立刻取消 |
| FOK | Fill Or Kill | 不能全部立刻成交，整笔取消 |

有效期不改变永续的强平规则。挂着 GTC 止损，账户仍可能先被强平。

### 最新价止损单 vs 标记价强平

屏幕上至少两套价格在起作用，见 [交易所屏幕](/course/perp-screen)：

- **最新价（Last Price）**：K 线与许多止损单的触发价源（以交易所设置为准）。
- **标记价（Mark Price）**：未实现盈亏与**强平估算**用的参考价。

必须事先写清：

1. 你在最新价上挂的止损，触发看的是最新价（或你选定的价源）。
2. 强平看的是标记价与维持保证金，**不等待你的止损单成交**。
3. 因此：**止损尚未成交，也可能先被强平。** 高杠杆、止损挂得比强平线更远时，尤其容易发生。
4. 部分交易所允许止损按标记价触发。课文必须写明「这份单看的是哪一个价」，不要假设全市场同一设置。

只在最新价挂很近的限价止损、同时又用很高的杠杆，是常见反例。本站不鼓励高杠杆。

### 部分成交、触发后没成交

系统必须事先写清，而不是盘中再发明。下面两种算法都可以写进系统，但**必须事先选定一种**：

| 算法 | 含义 | 写的时候要补的句子 |
|---|---|---|
| 视为未入场 | 没成交或成交不足预设比例，这一笔不存在 | 未入场不占用热度；当天是否还允许用同一触发，也要写死 |
| 按已成交部分重算 | 成交了多少，就按多少算仓位、1R 和热度 | 重算后的单笔风险若超过上限，先减到上限内或放弃续挂 |

还要单独写清：

| 结果 | 教学上要回答的问题 |
|---|---|
| 部分成交 | 已成交部分算入场吗？剩余挂单保留、改价还是撤销？止损与仓位按已成交数量重算吗？ |
| 触发后没成交 | 止损限价触发了但没吃到：视为仍持有，还是视为规则未执行？ |
| 开仓未成交 | 条件触发但限价没成交：视为**未入场**，还是追价？本库教学倾向：未成交视为未入场，除非系统另写「允许一次追价」。 |
| 止损未成交且仍持仓 | 仓位还在，计划风险已经失效，须有备用动作（例如改市价只减仓），不能假装止损还在。 |

未写追价句，就视为未入场。回测若把收盘价当成已经成交，会高估限价与止损限价的成交率。

薄盘或连续强平时，止损单往往更接近「市价扫货」，而不是你写下的那个触发价。见 [清算瀑布怎么读图](/indicators/liquidation-cascade)。

建议按这个顺序写，不要跳到「看起来能成交」：

1. 环境、方向、前提、触发已经写清。
2. 为触发选开仓订单类型：市价还是限价；是否只做 maker；有效期用哪一种。
3. 写成交假设：全部成交才算入场，还是允许部分成交。
4. 为认错选离场订单类型：止损市价还是止损限价；是否只减仓；触发看最新价还是标记价。
5. 写未成交算法：开仓没成交、止损没成交、触发后限价没挂上，各算什么。

教学示例（只说明如何写，不是推荐策略）：

> 触发成立后用限价开仓，当日有效；未成交视为未入场，不改方向句。  
> 若成交，立刻挂只减仓的止损市价。触发价源写明：标记价。  
> 部分成交则按已成交数量重算名义仓位，止损价不因「没装满」而挪近。

开仓前先能说出：「认错后用只减仓的止损市价，触发价看标记价还是最新价。」说不出来，入场句还没写完。

上图把市价、限价、止损单、只减仓画成四格。市价要成交、限价要价格、止损触发不等于成交、只减仓避免平仓单开出新仓。最新价止损线和标记价强平线可以不同步。

## 正反案例

下面两段必须对照着看。它们是教学情景，不是真实行情，不能代表未来结果。

### 正例：开仓前先能说出认错单的类型和价源

方向标签已经是偏多。触发还没来。你先在纸上写：若成交，立刻挂只减仓的止损市价；触发看标记价；开仓限价当日未成交视为未入场。触发出现后，限价成交了一部分。你按已成交数量重算名义，止损价不往近处挪。

这是正例：两个执行者对「这算不算一笔」能得到同一结论。正例不保证接下来会赚钱，只说明成交假设事先写好了。

### 反例：只在最新价挂很近的限价止损，杠杆很高

同一套方向句，有人条件一出现就随手点市价，止损回头再想。后来在最新价上挂了一张很近的限价止损，同时把杠杆开得很高。插针扫到最新价时，限价没有对手；标记价先碰到强平线。计划中的止损来不及工作，真实离场是强制平仓，成交价更差。

只在最新价挂很近的限价止损、同时又用很高的杠杆，是本篇要拆掉的习惯。本站不鼓励高杠杆。

## 常见错误

1. 图上画了止损线 = 已经有一笔会成交的单。
2. 止损限价更安全。它更守价格，不更保证离场。
3. 最新价碰到止损价 = 已经平掉。
4. 全仓 / 高杠杆可以靠更近的止损活命。止损与强平是两套触发。
5. 只减仓可以防止强平。它只防止平仓单开出新仓。
6. 只做 maker 就能省手续费。不成交时，省下的是一笔没发生的交易。
7. 部分成交可以事后决定算不算。
8. 把某交易所的按钮名称当成通用知识。

## 局限性

- 名称、默认价源、是否允许按标记价触发止损，因所而异。
- 薄盘里，止损市价的成交价可以远离触发价；止损限价更可能触发而不成交。
- 风险限额变档会导致维持保证金升高、强平线靠近，见 [交易所屏幕](/course/perp-screen)。
- 未写订单类型的回测，等于假设每笔都按信号价完全成交，短周期会被高估。
- 本篇不写具体按钮、API、刷量，也不颁布推荐杠杆。
- 永续合约有强平风险。杠杆会放大亏损。历史案例不能代表未来结果。

## 总结

记住五句话：

1. 规则成立，和单已成交，是两件事。
2. 市价要成交，限价要价格；止损市价要离场，止损限价要守价。
3. 认错离场优先用只减仓；只做 maker 是不成交则撤。
4. 最新价止损和标记价强平不是同一件事；止损未成交也可能先被强平。
5. 部分成交、未成交，必须事先写怎么算。示例只教写法，不能代表未来结果。
