# 系统优化

本篇回答：**什么情况下才允许改规则，以及怎样避免为这一段历史把句子越改越贴。** 优化不是把曲线调到最好看。

本站只提供交易教育，不提供买卖信号、荐股、喊单或自动交易。教学步骤只说明改规则的顺序，不是「优化后会更好」的承诺，不能代表未来结果。

先修：[数据统计](/trading-system/statistics)。还不会读合格卡片，本篇没有输入。没有日志，优化没有对象，见 [交易日志](/trading-system/trading-journal)。

类比：为了贴合这一张卷子不断加例外、改标准答案，换一张卷子就散。那叫过拟合，不叫进步。

## 学习目标

读完本篇，你应该能：

- 说出过拟合：为某一段历史不断加条件、改参数，使样本内变好看、样本外变脆
- 按顺序改：先措辞能否执行，再成本与滑点是否诚实，再环境是否被硬做，最后才动参数
- 解释参数一改，样本外要重做
- 区分「没遵守规则」和「规则本身要改」
- 认出一次盈亏或一段漂亮曲线都不够用来改系统

## 概念

**系统优化**是有记录、有统计之后的修改流程。它把「执行质量」和「规则质量」分开：先确认日志里多数笔是遵守的，再讨论句子要不要改。

它回答：这一处含糊要不要写得更可复核？成本假设是不是太乐观？我是不是在震荡里硬做趋势句？某个参数是不是只对这一段历史友好？

它不回答：怎样改才能以后更好看。优化不消除亏损，也不把教育示例变成可跟单策略。

**过拟合（教学定义）**：规则或参数被调到高度贴合某一段已经看见的历史，以至于换一段没见过的样本，结构就散掉。常见做法包括：为躲某一笔亏损加例外、同时优化好几个相关指标、只用近期很短的窗口反复调。

样本内（用来形成或微调规则的区间）和样本外（写完或改完规则后才看的区间）要分开。两者都好看，也不等于未来好看；两者差异很大，说明规则可能只适配某一段。历史观察不能代表未来结果。

和 [多指标共振](/combinations/multi-indicator) 连起来看：问题槽已经在问同一件事时，再加第 4 个振荡器「投票」，常常是过拟合，不是更清楚。共振不能当加大仓位或加快优化的理由。

## 怎么写规则

建议只按这个顺序改。跳步去调参数，最容易过拟合：

1. **先查执行。** 日志里违规、补做、挪止损、临时加杠杆多不多？多，先回到执行，不要改菜谱。见 [交易日志](/trading-system/trading-journal)、[执行偏差](/trading-system/execution-bias)。
2. **再改措辞能否执行。** 「明显放量」「感觉很强」改成可复算的句子。换一个人仍数不出笔数，先改第 4–8 节文字，见 [什么是交易系统](/trading-system/what-is-a-trading-system)。订单类型和未成交算法写不清，也先改这里。
3. **再查成本与滑点是否诚实。** 零成本主结果、止损无滑点、漏资金费，都先改假设，再谈参数。止损滑点不优于入场。见 [回测](/trading-system/backtesting)、[成本对照 R](/trading-system/cost-vs-r)。
4. **再看环境。** 是不是在看不清或震荡里硬做趋势句？先加「不交易」出口，而不是加更多指标。见 [市场环境](/trading-system/market-regime)。
5. **最后才讨论参数。** 一次只动一个、写明为什么动、保留旧句。参数一改，样本外要重做，统计卡片要重填。
6. **限制问题槽数量。** 三个条件若在问同一件事，先删重复，不要再加第 4 个。不要再叠 [KDJ](/indicators/kdj)。
7. **滚动前进后，验证段只看一次。** A 段调、B 段只验证；看过 B 再微调，B 就不能再当验证。见 [回测](/trading-system/backtesting)。
8. **写停改条件。** 例如：样本外尚未看完，不改；本周已改过一次，不再改；回撤中途不改参数、不加杠杆。

课堂检查句：

> 你准备改的那一条，是为了躲开已经看见的某一笔亏损，还是为了让两个执行者更容易得到同一结论？  
> 若是前者，先标「疑似过拟合」，不要当日生效。

作业（写在纸上即可）：列出你想改的三条，分别标「执行 / 措辞 / 成本 / 环境 / 参数」。参数类放到最后，并写样本外区间从哪天开始还没看。不要寻找「最优参数表」。本站不提供。

## 正反案例

下面两段必须对照着看。它们是教学情景，不是真实行情，不能代表未来结果。

### 正例：先改含糊，再重做样本外

日志显示多数笔遵守规则，但「放量」两字让两个人数出不同的笔数。你把触发改成「成交量高于最近 N 根均值，且用已收盘的那一根」。成本假设从零改成 taker + 资金费 + 止损滑点。你没有改 EMA 周期。然后在事先划出、此前没当调参用的区间重新数一遍。新卡片仍然普通。

这是正例：优化让规则更可复核。卡片没有变漂亮，不证明失败；变漂亮了，也不证明有效。不能代表未来结果。

### 反例：为躲亏损加例外，或短窗口反复调

某笔大亏之后，你加上「那天那种插针以后不做」，又把 RSI 从 14 改到图顺眼的数，再把 MACD、KDJ 一起纳入「必须同时对齐」。样本内曲线变顺。样本外一换区间，笔数塌掉或回撤变大。另一人只用最近很短的窗口天天优化，宣称「适应了当下」。当下会变成下一段历史。

再补一条：为提高 Profit Factor 删掉亏损最大的几笔。那是删数据，见 [回测](/trading-system/backtesting)。再补一条：统计略好看就提高杠杆。那是从数字到强平的捷径。本站不鼓励高杠杆。

## 常见错误

1. 一次亏损或一次盈利之后立刻改规则。
2. 执行问题当成规则问题。
3. 为某一笔已经看见的亏损加例外。
4. 同时优化好几个相关指标。
5. 用很短的近期窗口反复调，然后宣称适应了当下。
6. 参数改了，却仍用旧的样本外数字。
7. 把优化理解成「让曲线最好看」。
8. 把教育站点的示例参数抄去实盘。本站不提供实盘建议。

## 局限性

- **流程遵守了，仍可能改错，或样本外一样难看。** 优化不承诺下一笔更好。
- **样本外也只是另一段历史。** 两段都好看，不能代表未来结果。
- **市场结构、费率、流动性会变。** 旧优化在新机制里可能失效。
- **永续合约有强平风险。** 优化后的规则仍可能被强平打断。本站不鼓励高杠杆。
- **本篇不提供最优参数，也不证明某次修改有效。**
- **过拟合有时要事后才被看见。** 限制改动次数，比追求一次改对更重要。

## 总结

记住五句话：

1. 没有日志和统计，就不要谈优化。
2. 过拟合是为一段历史把规则越改越贴。
3. 顺序是措辞 → 成本 → 环境 → 最后才是参数。
4. 参数一改，样本外要重做。
5. 优化不是寻找最好看的曲线，也不能代表未来结果。
