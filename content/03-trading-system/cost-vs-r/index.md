# 成本对照 R

本篇只回答一件事：**还没看对错，来回成本已经垫掉几个 R。**

1R 先被定义，成本才有尺子。没有这把尺子，手续费和资金费只是账单上的小数。

本站只提供交易教育，不提供买卖信号、荐股、喊单或自动交易。下面的数字是**教学演算**，忽略部分费用，**不能拿去对账，不能代表未来结果**。不教哪家所更便宜，不教资金费套利。

先修：[仓位管理](/trading-system/position-sizing)、[资金费率](/indicators/funding-rate)。仓位篇已经会从亏损上限反推名义；资金费率篇已经见过「费率 × 名义」。本篇把它们除以 1R。

类比：先量杯子能装多少水（1R），再看每次倒茶洒掉几滴。洒掉的量不看杯子，会觉得「就几滴」；看过杯子，才知道这几滴已经占了半杯。

## 学习目标

读完本篇，你应该能：

- 说出 1R = 入场到计划止损的亏损金额
- 用同一笔数字算出资金费、手续费各是多少 USDT、多少 R
- 解释来回成本必须从期望里减掉；小赢规则最容易被吃穿
- 写出止损滑点不优于入场
- 认出「只报未计成本的胜率」是反例

## 概念

| 名称 | 教学含义 | 常见混淆 |
|---|---|---|
| 1R | 这一笔按计划止损认错时，账户准备亏掉的金额 | 把它当成盈利目标，或当成价格涨跌的百分比 |
| 名义仓位 | 合约值多少 USDT，价格每动 1%，盈亏多少 | 把它当成 1R |
| 来回成本 | 开平手续费 + 资金费 + 点差与滑点等 | 只记得手续费，忘了持有期间的资金费 |
| 成本占 R | 来回成本 ÷ 1R | 以为 0.05% 的费率「很小」，没除过 1R |

1R 必须和仓位公式用同一套数字。账户权益、单笔风险、止损距离变了，1R 的金额可以变，但定义不变：认错时准备亏掉的那一笔钱。

本项目不颁布「标准 1R 百分比」。下面的 100 USDT 只服务于同一道例题。

资金费率是比率；资金费是划走的钱。持有多个结算周期时，教学近似：

> 累计资金费 ≈ 费率 × 名义价值 × 周期数

各周期费率不同。这是乘法直觉，不能拿去对账。费率可正可负：本例只演示「拿着仓、每个周期都在付」。反向收取时，算术符号相反，但回测仍要逐期计入，不能假设为 0。

多空持有成本不对称：费率长期偏正更常见，多头更容易持续付费；急跌时下行滑点往往更脏。两边的持有体验并不对称。本篇不把不对称写成开空理由。

## 怎么写规则

用**同一笔**教学数字贯穿。字段不要删。

| 字段 | 教学取值 |
|---|---|
| 账户权益 | 10,000 USDT |
| 1R | 100 USDT |
| 名义仓位 | 5,000 USDT |
| 资金费率 | 0.05% / 8h（本例按持有期间持续支付） |
| 持有时间 | 3 天 |
| 开仓手续费 | taker 0.05% |
| 平仓手续费 | taker 0.05% |

3 天 = 72 小时 = 9 个 8 小时结算周期。

资金费（教学，单向支付假设）：

> 5,000 × 0.05% × 9 = 22.5 USDT = 0.225 R

开平手续费：

> 开仓 5,000 × 0.05% = 2.5 USDT  
> 平仓 5,000 × 0.05% = 2.5 USDT  
> 合计 5.0 USDT = 0.05 R

手续费 + 资金费：

> 27.5 USDT = 0.275 R

还没看对错，来回已垫约 0.28 R。

本例**忽略**（所以不能对账）：

- 点差的实时变动、强平罚金、资金费多空不对称、中间若有部分平仓、maker / taker 混用、风险限额变化、活动或返佣
- 入场滑点与止损滑点（下一小节单独加，不和上式混成「精确账单」）

### 点差与滑点：止损不优于入场

除了手续费和资金费，还要写滑点假设：

- 入场滑点、止损滑点分开写。
- **止损滑点不优于入场。** 认错离场常遇到更快的价格和更薄的盘口；假设止损滑得比开仓还少，等于在美化亏损。
- 点差可以并入滑点，或单独占一行；选定一种写法，全样本一致。

教学加一行（仍是演算，不是实测）：若入场滑点按名义的 0.02%、止损滑点按 0.04%，则

> 入场 1.0 USDT + 止损 2.0 USDT = 3.0 USDT = 0.03 R

与上一节的 0.275 R 相加，约 0.31 R。数字只用来说明「止损侧应设得更差」，不是标准滑点。

市价止损、连续强平、薄盘时，真实滑点可以远大于这道例题。超过单笔风险本身时，应对照禁止条件，而不是继续用平静时段的假设。

### 期望必须减成本

教学表述（不是预测公式）：

> 平均每笔粗算 ≈ 胜率 × 平均盈利 − 亏率 × 平均亏损 − 平均来回成本

三部分都用同一单位：USDT 或 R。不要胜率用百分比、成本用「好像不多」混在一起。

小赢规则最容易被吃穿。下表是**虚构算术，不是策略成绩**，不能代表未来结果：

| 教学对照 | 未计成本 | 减去 0.3 R 来回后 |
|---|---|---|
| 胜率 70%，平均盈利 0.4 R，平均亏损 1.0 R | 70%×0.4 − 30%×1.0 = −0.02 R | −0.32 R |
| 胜率 40%，平均盈利 2.0 R，平均亏损 1.0 R | 40%×2.0 − 60%×1.0 = +0.20 R | −0.10 R |

两行都不是推荐策略。表的唯一目的：成本是期望里的一项，不是附录。第一行这种「常赢一点」的规则，加成本后更先转负。

写仓位时，要能回答：来回成本是否已经接近计划中的平均盈利。若接近，先改周期、频率或放弃这条触发，不要用加大名义仓位去「摊薄费率百分比」——名义变大，1R 若不变，成本占 R 可以同步变大。

系统里建议写进检查：

1. 这一笔的 1R 是多少 USDT？
2. 按持有时长，手续费 + 资金费 + 滑点大约多少 USDT、多少 R？
3. 期望有没有减去第 2 步？

持有超过一个资金费周期的规则，回测必须按周期数计入，不能只记开平手续费。见 [回测](/trading-system/backtesting)。

作业：把这道例题抄进模板，换成你自己的持有时长再算一遍。数字仍是教学演算，不能对账。

## 正反案例

下面两段必须对照着看。它们是教学情景，不是真实行情，不能代表未来结果。数字与上文同一笔。

### 正例：算完来回已接近 0.3 R，于是提高决策周期或放弃过密触发

你用手算完整道例题：资金费 22.5 USDT（0.225 R），手续费 5 USDT（0.05 R），合计 27.5 USDT（0.275 R）。规则里平均盈利大约只有 0.3–0.4 R。你记下：「还没看对错，成本已经接近平均盈利。这条触发过密，提高决策周期，或放弃。」你没有先去调指标，也没有加大名义去「摊薄费率」。

这是正例：成本课的工作是改频率或放弃，不是找更便宜的交易所。正例不保证改完就会赚钱。

### 反例：回测只报未计成本的胜率

同一套规则，回测面板写着「胜率 70%」。手续费没减，资金费当 0，止损滑点还设得比入场更小，好让回撤好看。纸上的胜率很漂亮。加上约 0.3 R 来回之后，那条「常赢一点」的规则先转负。

只报未计成本的胜率，是本篇要拆掉的习惯。止损滑点设得比入场更小，等于在美化亏损。

## 常见错误

1. 费率 0.05% 看起来很小，可以忽略。除以 1R 之后，再乘来回和持有周期，就不小。
2. 只算手续费，不算资金费。隔夜或跨几天的规则，资金费常常大于一趟 taker。
3. 止损滑点设得比入场更小，让回撤好看。
4. 小赢高频可以靠胜率养活。未减成本的胜率会骗人。
5. 比较哪家所更便宜来优化系统。本课不教比价。
6. 资金费为正就去做套利。不在本项目范围。
7. 用加大名义去摊薄费率百分比，却不重算成本占 R。
8. 把教学演算里的 0.275 R 当成「标准成本」。

## 局限性

- 本例忽略点差变动、强平罚金、返佣、部分平仓、maker / taker 混用。所以不能对账。
- 各周期费率不同；0.05% / 8h 只是例题口径，不是预测。
- 资金费可正可负。本例只演示持续支付的一侧。
- 真实滑点可以远大于例题里的 0.02% / 0.04%，尤其在薄盘和连续强平时。
- 热度仍按计划风险加总。成本吃掉的是期望，不自动降低已开仓的热度。
- 本篇不比较交易所费率，不写资金费套利步骤，不颁布推荐杠杆或标准仓位百分比。
- 永续合约有强平风险。杠杆会放大亏损。历史案例不能代表未来结果。

## 总结

记住五句话：

1. 1R 是入场到计划止损的亏损金额。
2. 同一笔例题：资金费 22.5 USDT（0.225 R），手续费 5 USDT（0.05 R），合计 27.5 USDT（0.275 R）。
3. 这是教学演算，忽略部分费用，不能对账，不能代表未来。
4. 期望必须减去来回成本；止损滑点不优于入场。
5. 成本接近平均盈利时，先改周期或放弃触发，不要先调指标。
