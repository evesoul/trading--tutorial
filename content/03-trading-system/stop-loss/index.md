# 止损

本篇只写认错：**判断错了，在哪里离开。** 这一格必须早于止盈和加仓。没有止损距离，仓位没有定义。

本站只提供交易教育，不提供买卖信号、荐股、喊单或自动交易。教学示例只说明如何写规则，不是推荐策略，不能代表未来结果。

先修：[出场规则](/trading-system/exit-rules)。强平机制可回 [怎么学这门课](/course)。

类比：认错线是你自己画的「走到这里我承认这次看错了」。强平线是交易所在保证金不够时把你请出去。两根线不是同一根。把希望寄托在交易所出手，等于没写止损。

## 学习目标

读完本篇，你应该能：

- 说出止损回答「错了在哪认错」，并且必须写在止盈和加仓前面
- 区分计划止损和账户强平：止损 ≠ 强平
- 写出止损放哪、何时移动、以收盘还是盘中为准
- 解释止损过近和过远各会逼出什么问题
- 认出「把止损挪远以免被扫」是在改风险，不是在坚持系统

## 概念

**止损**是离场规则里的认错句。价格触及你事先写好的位置，这笔的前提作废，按规则离开。

它不是：

- **强平（爆仓）**：保证金不够维持仓位时，交易所强制减仓或平仓。成交价可能劣于你的计划止损。
- **止盈**：对了怎么走，下一篇再写。
- **再给一次机会**：把认错位往远处挪，让浮亏「还有空间」。

| 名称 | 谁决定 | 它保护什么 |
|---|---|---|
| 计划止损 | 你的规则 | 单笔判断错误时的退出点 |
| 预估强平价 | 保证金、杠杆、维持保证金、标记价 | 账户不被强制清走；它不是你的策略出口 |
| 最新价上的止损单 | 交易所撮合 | 可能成交；剧烈波动时仍可能滑点或未成交先强平 |

读图看最新价；估算强平看标记价。只用最新价挂一个很近的止损，却用很高的杠杆，可能出现：止损单还没成交，标记价已经触发强平。

止损回答：这笔错了，亏到哪里结束。

止损不回答：对了能赚多少、要不要加仓、哪个指标最准。

常见写法（都只是工具，不是推荐）：

- **固定百分比**：入场价上下某个事先写死的比例。
- **结构止损**：放在最近摆动低点 / 高点外侧，承认「这结构不算了」。
- **ATR 止损**：**ATR（Average True Range，平均真实波幅）** 用近期高低波幅估算普通波动大概有多宽。把认错位放在若干倍 ATR 之外，是在问「是不是超出普通噪声」，不是在给方向。

选定一种之后，仓位必须跟着距离变，而不是反过来改止损去迁就想开的仓。

## 怎么写规则

止损句至少写清：

1. **位置怎么算。** 结构点、固定比例、还是 ATR 倍数。公式要能复算。
2. **以什么价为准。** 盘中触及、收盘跌破，还是标记价。两种执行者不能各用各的。
3. **触发后怎么走。** 是否立即市价离场，是否允许盘中先减一半。
4. **何时移动、何时不移动。** 例如：未到第一目标，止损不挪；到达第一目标后，移到入场附近。没写的移动，都算改规则。
5. **和强平的关系。** 在所选杠杆下，预估强平价是否仍远于计划止损。强平更近：减小仓位或放弃这笔，而不是把止损再收近去「做出仓位」。
6. **开仓前就存在。** 先有距离，才能进入 [仓位管理](/trading-system/position-sizing)。先开仓再找止损，风险没有被定义。

教学示例（只说明如何写规则，不是推荐策略）：

> 偏多入场后，止损放在触发那根 K 线之前最近摆动低点的外侧。  
> 以标记价盘中触及为准，触发后市价平仓。  
> 未到达第一目标前，不把止损往远处挪。  
> 若预估强平价近于该止损，放弃这笔或减小名义仓位，直到强平远于止损。  
> 没有写下止损距离：视为入场条件不成立。

这不是本站推荐的止损。结构点、ATR、固定比例都可以用，关键是事先选定，并且能让另一个人数出触发次数。

看持仓时：

1. 先核对止损还在不在、有没有被你随手拖走。
2. 再看价格与止损的距离，不要先看浮动盈亏的颜色。
3. 触及就走认错句。不要用「[RSI](/indicators/rsi) 还没到超卖」否决止损。
4. 打到止损后，记一笔执行记录，而不是立刻改距离。

## 正反案例

下面两段必须对照着看。它们是教学情景，不是真实行情，不能代表未来结果。

### 正例：先写距离，再谈后面的格子

触发出现前，你已经按结构句算出认错价，并检查预估强平仍在更远处。开仓后立刻挂上。价格回来打到该价，你离开。随后行情又朝原方向走。你记下「止损按规则触发」，而不是「早知道不设」。

这是正例：止损的工作是结束错误，不是预测最低点。少拿后面一段，和规则仍可复核，可以同时成立。正例里包含「后来仍可能继续走」。继续走不证明不该设止损。

### 反例：止损当摆设，或拿强平当止损

入场后把止损设在「不太可能碰到」的远处，理由是不想被扫。单笔亏损上限因此失去意义。另一人把杠杆开得很高，计划止损写在强平之外——纸上有止损，账户先被强平。第三人每次快碰到就往外拖一截，美其名曰「给结构空间」。三笔都没有可回测的认错句。

再补一条：止损很近，为的是「亏一点没关系，可以开很大」。更近的止损更容易被普通波动扫出。这是在用更高的触发频率换名义规模，不是更严的风控。仓位篇会把公式写开。

再补一条：加仓时仍沿用旧止损，不重算总风险。账户暴露已经变了，纸上的「单笔上限」还停在第一批。加仓必须晚于止损句，并且重算。

## 常见错误

1. 开仓后再找止损。
2. 把强平价当成止损。
3. 还没写止损，就写止盈或加仓。
4. 被扫之后把下一笔止损收得更近，或拖得更远，却不承认规则改了。
5. 用动量指标否决已经触及的止损。
6. 止损过近却开很大，或过远却仍按满仓开。
7. 只在最新价上看止损，忽略标记价与强平。
8. 认为有止损就比较安全——本站不把止损说成消除亏损的开关。

## 局限性

- **滑点和瞬间插针**可以让实际亏损大于纸面距离。回测要加滑点。
- **过近**：普通噪声就会触发，交易成本占比上升。
- **过远**：同等单笔上限下，仓位必须变小；若不肯变小，单笔亏损会被放大。
- **结构点会被改写。** 新的摆动出现后，「最近低点」变了。要写清用开仓时的点，还是允许按规则更新。
- **ATR 会随波动变。** 高波动时距离变宽，仓位应变小，而不是抱怨「算出来开太少」。
- **永续合约有强平风险。** 杠杆把正常回撤推近强平。本站不鼓励高杠杆。历史案例不能代表未来结果。

## 总结

记住五句话：

1. 止损是事先写好的认错位置，必须早于止盈和加仓。
2. 止损 ≠ 强平。强平是保证金耗尽，不是你的策略出口。
3. 先有距离，才能算仓位。
4. 触及就走；不要盘中把认错位往远处挪来「再给一次」。
5. 有止损不等于结果可接受。示例只教写法，不能代表未来结果。
