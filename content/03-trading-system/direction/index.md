# 方向判断

本篇只回答一个问题：**在已经选定的环境里，规则给出偏多、偏空，还是不交易。**

本站只提供交易教育，不提供买卖信号、荐股、喊单或自动交易。教学示例只说明如何写方向规则，不是推荐策略，不能代表未来结果。

先修：[多周期](/trading-system/multi-timeframe)。环境句仍来自 [市场环境](/trading-system/market-regime)。方向只用决策周期的已收盘结论；低周期交叉不单独颁发方向牌。结构观察可复习 [摆动结构与假突破](/indicators/market-structure)、[EMA](/indicators/ema)。

类比：路牌写「前方只准往东」或「此路不通」。路牌不是油门。偏多不是「现在去开多」，不交易也不是认输，只是方向格还没有可执行的结论。

## 学习目标

读完本篇，你应该能：

- 把方向写成偏多 / 偏空 / 不交易三选一，而不是下单动作
- 先检查环境，环境不允许时直接写不交易
- 写出能让两个执行者得到同一结论的方向句
- 把「看起来要涨」从规则里删掉
- 认出方向确立之后，仍要等入场的前提和触发

## 概念

**方向判断**是规则化的偏向，不是下单。系统模板里这一格要能复核：换一个人看同一段已收盘的数据，应得到同一个标签。

| 标签 | 含义 | 常见误读 |
|---|---|---|
| 偏多 | 只允许讨论多头前提，不允许当笔开空 | 「立刻买入」 |
| 偏空 | 只允许讨论空头前提，不允许当笔开多 | 「立刻卖出」 |
| 不交易 | 方向未确立，或环境不允许 | 「错过了所以随便做一笔」 |

它回答：接下来只准往哪一侧找交易前提？还是两侧都不找？

它不回答：入场价、止损价、仓位、现在该不该点下单。那些是后面几格。

和阶段 2 的对照要分开。[趋势 + 动量](/combinations/trend-momentum) 里，我们只描述「价格在上行均线之上、力度在回落」，并提醒不要翻译成做多或做空。进入系统课后，你**可以**把已经写好的环境规则，翻译成偏多或偏空——但翻译的是你自己事先写的句子，不是把金叉当成指令。

方向未确立时，不进入交易前提。宁可多写几次不交易，也不要在看不清时给自己一个偏向，方便稍后「找个理由进场」。

## 怎么写规则

写方向规则时，锁死四件事：

1. **先引用环境。** 例如：仅当环境 = 趋势，才进入本格；否则方向 = 不交易。
2. **给出可检查的偏向条件。** 优先用结构句：**更高高点 / 更高低点（HH / HL）** 记偏多侧，**更低低点 / 更低高点（LL / LH）** 记偏空侧。可以再补均线位置，但不要用「强」「弱」「要涨」这类主观词。结构标法见 [摆动结构与假突破](/indicators/market-structure)。
3. **写清互斥。** 偏多和偏空不能同时为真。两边都能讲通，记不交易。
4. **写清失效。** 收盘回到均线另一侧、均线走平、环境标签被改成震荡：方向回到不交易，而不是改口「反手」。

教学示例（只说明如何写规则，不是推荐策略）：

> 若环境不是趋势：方向 = 不交易。  
> 若决策周期（本例 4H）收盘位于慢速 EMA 之上，且该 EMA 向上，且近期摆动走出更高高点与更高低点（HH / HL）：方向 = 偏多。  
> 若决策周期收盘位于慢速 EMA 之下，且该 EMA 向下，且近期摆动走出更低低点与更低高点（LL / LH）：方向 = 偏空。  
> 其余：方向 = 不交易。  
> 执行周期上的金叉死叉，不改本格。

这组句子里没有「开多」或「开空」。它只决定后面 [入场规则](/trading-system/entry-rules) 允许找哪一侧的前提。规则还要先能变成可能成交的单，见下一篇 [订单与成交](/trading-system/order-types)。

看图顺序：

1. 先读上一篇贴好的环境标签。不是趋势（或你允许的那种环境），停。
2. 再读位置和斜率，不要先读副图动量。
3. 对照三选一，写下标签。
4. 冲突或未收盘：维持不交易，或等收盘再标。
5. 不要把 [RSI](/indicators/rsi) 超买、[MACD](/indicators/macd) 金叉单独写成方向。它们是力度观察，最多用来否定「力度还在」，不能单独颁发偏多牌。

## 正反案例

下面两段必须对照着看。它们是教学情景，不是真实行情，不能代表未来结果。

### 正例：环境通过，才标偏多；对不上就停

环境已被你标成趋势。收盘在上行均线之上，摆动高点高于前高。你记下偏多，然后去写「回到均线附近才算前提」，而不是立刻下单。另一段：均线仍向上，但收盘已经多次跌破均线。按你事先写的失效句，方向改回不交易。你没有改口成偏空，除非空头条件也完整满足。

这是正例：方向是标签，入场是后一格。标签改变时，先停，再检查，而不是自动反手。

### 反例：把看起来要涨写成方向

副图 [RSI](/indicators/rsi) 从 30 附近抬头。有人写成「要涨了，偏多」。环境仍是震荡，均线走平。随后 RSI 再回到 30 附近。方向标签一天改了好几次，每一次都像有理由。

这是把力度观察当成方向颁发器。震荡里，力度尺会反复抬头。

再补一条：已经持仓时，把反向的一根影线写成「方向变了，反手」。方向规则应以收盘或你事先指定的确认方式为准。影线可以很响，仍可能收回。未写清确认方式，执行者无法复核。

## 常见错误

1. 把偏多写成开多指令。
2. 环境未定时仍给自己一个偏向，方便稍后进场。
3. 用「看起来要涨」「主力要拉」当方向句。
4. 只看动量交叉，不看环境和位置。
5. 偏多条件只满足一半，就当成已经偏多。
6. 方向一变就自动反手，而不经过出场规则。
7. 短周期方向否决长周期环境。
8. 认为方向对了，就可以省略止损和仓位。

## 局限性

- **方向正确，仍可能在入场上亏。** 偏多只允许找多头前提，不保证随后的触发位置合适。
- **滞后。** 等摆动高点高于前高，价格可能已经走完一截。
- **结构可以骗人。** 假突破会让「新高」短暂成立，随后失效。所以要写失效句。
- **两个执行者仍可能因「近期」「若干根」口径不同而标出差别。** 把窗口长度写死。
- **永续可做空，不表示偏空更聪明。** 做错方向，亏损同样被杠杆放大。多空持有成本也不对称：费率长期偏正时，多头更容易持续付费；急跌时下行滑点往往更脏。这只是成本提醒，不是开空理由。本站不鼓励高杠杆。
- **历史标签不能代表未来结果。**

## 总结

记住五句话：

1. 方向是偏多、偏空或不交易，不是下单。
2. 环境先于方向；环境不允许，方向就是不交易。
3. 句子要能让另一个人得到同一标签。
4. 力度指标不单独颁发方向。
5. 方向确立之后，仍要等前提和触发，仍要先写止损。
