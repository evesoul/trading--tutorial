# 完整交易系统案例

本篇是阶段 3 的收束作业纸。它只说明：**怎样按模板把本阶段二十篇的格子填成一份可检查的稿。**

这份稿是**虚构教学样本**。它不证明该系统有效，不是跟单对象，不是推荐策略，不能代表未来结果。本站只提供交易教育，不提供买卖信号、荐股、喊单或自动交易。学完本篇，也不等于已经具备稳定交易的能力。

建议先修：本阶段前十九篇，尤其是 [多周期](/trading-system/multi-timeframe)、[订单与成交](/trading-system/order-types)、[成本对照 R](/trading-system/cost-vs-r)、[账户热度与相关](/trading-system/account-heat)、[执行偏差](/trading-system/execution-bias)。跳读可以，但空格会变多。

类比：下面是一张已经填过的空白试卷，用来演示「题目怎么答」。它不是标准答案，更不是可以拿去上场的试卷。请用自己的句子重填一版。

## 学习目标

读完本篇，你应该能：

- 按「环境 → 多周期 → 方向 → 订单 → 前提 → 触发 → 止损 → 止盈 → 仓位 → 成本 → 热度 → 禁止条件 → 记录」说出一份作业纸的顺序
- 指出教学样本里每一格在回答什么问题，而不是把它背成开仓条件
- 解释为什么本案例不填回测成绩、不贴权益曲线
- 读完「匿名执行时间线」后，能说出看到什么、挂了什么单、滑了多少、收过一次资金费、日志怎么记
- 用同一模板另填一份自己的稿，并标明「不是推荐策略、不能代表未来」

## 概念

**完整交易系统案例**在本站的意思是：一份填完的教学作业纸。模板结构见策略文档的 12 节；本课用短句演示填写，不改编号。

它回答：本阶段各篇的格子怎样出现在同一张纸上。

它不回答：这套句子以后好不好用、该不该照做、成绩是多少。本篇**故意不提供绩效表**。不填胜率、不填收益率、不画曲线，以免被读成证明。

再强调四句，后面还会重复：

1. 这是虚构教学样本，不是实盘记录。
2. 不是推荐策略，不是跟单对象。
3. 不证明该系统有效。
4. 不能代表未来结果。

指标只进入环境、方向、前提、触发的观察层。[EMA](/indicators/ema)、[RSI](/indicators/rsi)、[成交量](/indicators/volume) 在样本里出现，只为了让句子可检查，不是因为它们「更准」。止损、仓位、刹车不由指标自动给出。

## 怎么写规则

先按链路填，不要倒过来先写「怎么赚钱」。下面整份稿都是虚构教学样本，不是推荐策略，不能代表未来结果。

### 1. 系统名称

教学作业纸-4H-趋势回调观察（虚构样本）

用「周期 + 核心观察」命名，便于检索。名称里不写收益承诺。这不是产品名，也不是喊单频道名。

### 2. 交易市场

U 本位永续；教学占位观察对象，不指定可跟单品种。数据源与交易所在你自己的作业纸上写清。不同品种的流动性、滑点、资金费率会改变同一套句子的执行。不要默认「所有币都能套用同一套参数」。本样本不是品种推荐。

### 3. 时间周期

决策周期与执行周期都写 4H。不拆到更短周期找额外触发。若你自己的作业纸拆成「4H 定场 + 更短周期触发」，按 [多周期](/trading-system/multi-timeframe) 写死一对，打架默认不交易。周期越短，噪声和交易成本占比通常越高，见 [交易频率](/trading-system/trade-frequency)。4H 只是教学占位，不是推荐周期。

### 4. 市场环境

- 趋势环境（本样本的工作环境）：4H 收盘停在慢速 EMA 一侧，且该均线有可看见的斜率；近期摆动高点高于前高（偏多侧）或低点低于前低（偏空侧）。
- 震荡 / 看不清：均线走平、频繁穿越、或两个执行者会得出不同环境 → 空仓。
- 高波动到无法为计划仓位挂可靠止损 → 空仓，见禁止条件。

环境识别失败时默认空仓。同一组 EMA 在趋势和震荡里含义不同，见 [市场环境](/trading-system/market-regime)。以上句子不是行情预测。

### 5. 方向判断

只在趋势环境里给方向：

- 4H 收盘在上行慢速 EMA 之上 → 偏多
- 4H 收盘在下行慢速 EMA 之下 → 偏空
- 其余 → 不交易

方向是「偏多 / 偏空 / 不交易」，不是「现在去下单」，见 [方向判断](/trading-system/direction)。两个执行者应得到同一结论。「看起来要涨」不算。

### 6. 入场条件

拆成前提 + 触发。必须同时满足，只满足一部分时不做。教学写法，不是推荐策略：

1. 前提：价格回到快速 EMA 附近；RSI 从同向高位回落，但未跌破中轴。
2. 触发：随后一根 4H 收盘重新离开该 EMA，且成交量高于最近 N 根已收盘均值。
3. N 事先写死，回测过程中不改。本样本不公布「最优 N」。

前提不等于触发。金叉、超买、回踩在本站都是观察，不是指令，见 [入场规则](/trading-system/entry-rules)、[趋势 + 动量](/combinations/trend-momentum)。

成交假设（教学写法，不是推荐）：触发后用限价开仓，当日有效；未成交视为未入场。若成交，立刻挂只减仓的止损市价，触发价源写明标记价。见 [订单与成交](/trading-system/order-types)。

### 7. 止损

认错位置：触发那根之前，最近一个反向摆动结构之外。触及计划止损即按规则离场，接受滑点。不以强平当止损。开仓后不把止损往远处挪。止损必须早于止盈和加仓，见 [止损](/trading-system/stop-loss)。

过近会提高被扫频率；过远会迫使仓位变小。本样本不给「标准百分比」。

### 8. 止盈

本样本只选一种主规则，避免「看情况」：计划风险的固定 R 全平（R = 入场到止损的距离）。环境翻转或禁止条件出现时，未到目标也离场。不写「拿到最多」。1R 只作记账单位，见 [止盈](/trading-system/take-profit)。具体 R 数由你自己的作业纸写死；本样本不颁布标准。

时间离场：超过预定根数仍无进展，按 [出场规则](/trading-system/exit-rules) 离开。

### 9. 仓位

由单笔亏损上限和止损距离反推，见 [仓位管理](/trading-system/position-sizing）。本样本只示范三类上限，不给建议数字：

- 单笔最大风险：账户权益的一个事先写死的小比例
- 最大名义仓位：防止极窄止损算出过大名义规模
- 最大连续亏损 / 日亏损：触达即停止开新仓

杠杆只决定保证金占用和强平远近。本站不鼓励高杠杆，也不给推荐倍数。共振不能当加大理由。

热度上限：当前所有未平仓计划风险之和；与 BTC 同向的山寨按满额计入。碰到上限先平、先减、或禁止开新仓。见 [账户热度与相关](/trading-system/account-heat)。来回成本对照 1R，见 [成本对照 R](/trading-system/cost-vs-r)。本样本不填具体成本数字当成绩。

### 10. 禁止交易条件

触发后的动作预先写好：空仓或只平不开。不要写「灵活处理」。

| 来源 | 本样本的句子 |
|---|---|
| 市场 | 无法挂可靠止损；点差或滑点估计接近单笔风险；成交量 / OI / 资金费数据缺失；连续强平、盘口一跳数个点 |
| 账户 | 达到日亏损、连亏或回撤限制；按原止损距离算出的仓位低于最小下单量却仍想硬做 |
| 执行 | 规则读完仍需现场解释；不能等到 4H 收盘 |
| 事件 / 周末 / 连续强平 | 重大公布前后、周末薄盘、盘口一跳数个点：只平不开 |
| 主观 / 执行偏差 | 为回本加仓；因多个指标对齐而临时提高杠杆或仓位；错过触发后市价追；浮亏拖止损。事先动作见 [执行偏差](/trading-system/execution-bias) |

详见 [风险管理](/trading-system/risk-management)。

### 11. 回测

**本作业纸故意不填成绩。** 不写胜率，不写收益率，不贴曲线。若你自己练习回测，按 [回测](/trading-system/backtesting) 的八字段卡片记录，并同时看 [数据统计](/trading-system/statistics) 里的回撤、盈亏比、次数和成本。手续费、资金费、滑点必须写进假设。

你自己量出来的任何数字：只描述那一段样本，不证明本教学稿有效，不能代表未来结果，更不是本站推荐。

### 12. 复盘

先问有没有遵守规则，再问规则要不要改。一次盈亏不够用来改系统。栏目与 [交易日志](/trading-system/trading-journal) 对齐：当时环境、方向、前提、触发、订单类型、计划价 / 成交价、资金费、热度、计划中的止损止盈、实际仓位、实际离场、是否触发禁止条件、是否违规、想改规则的冲动。改规则的顺序见 [系统优化](/trading-system/system-optimization)，并写过拟合风险。样本外与滚动前进见 [回测](/trading-system/backtesting)。第 11 节仍然故意不填成绩。

以上 12 节合在一起，仍只是虚构教学样本。不是推荐策略，不是跟单对象，不证明有效，不能代表未来结果。

## 匿名执行时间线

下面是一笔**虚构、匿名**的执行过程。它只练习「看到什么、挂了什么单、滑了多少、收过一次资金费、日志怎么记」。不是真实行情，不是跟单对象，**不填胜率、不填收益率、不画曲线**，不能代表未来结果。

| 时刻 | 看到什么 | 做了什么 | 记什么 |
|---|---|---|---|
| 决策周期收盘 | 4H 收盘仍在上行慢速 EMA 之上，近期摆动是更高高点 / 更高低点。环境 = 趋势，方向 = 偏多。热度当前 0。 | 不改周期。执行周期仍是 4H。 | 环境、方向、决策周期、热度 = 0 |
| 前提出现 | 价格回到快速 EMA 附近，RSI 从高位回落、未跌破中轴。 | 等待触发。不提前挂开仓单。 | 前提 = 满足；触发 = 未发生 |
| 触发收盘 | 随后一根 4H 收盘离开该 EMA，成交量高于最近 N 根已收盘均值。禁止条件未亮。 | 挂限价开仓，当日有效。认错价已算好。 | 触发 = 满足；订单类型 = 限价开仓 |
| 成交 | 限价部分优于计划价成交；余量撤销。按已成交数量重算名义。 | 立刻挂只减仓的止损市价，触发价源 = 标记价。 | 计划价 / 成交价分开写；滑点写实数；热度按已成交部分计入 |
| 持有期间 | 未到第一目标。经过一个资金费结算，本例按持有仓支付一笔资金费。 | 不因资金费改止损。时间句未到。 | 资金费：收过 1 次、金额记下；热度不变 |
| 离场 | 价格触及计划止损（标记价）。止损市价成交，成交价劣于触发价。 | 只减仓离场。不反手。当天不再用同一触发。 | 离场类型 = 计划止损；滑点再记一行；是否违规 = 否 |
| 复盘 | 执行合格，结果为亏。想改规则的冲动：把止损再收近一点。 | 冲动写入日志，当日不改菜谱。 | 是否违规 = 否；冲动存着，等样本足够再谈优化 |

滑点、资金费在本时间线里只作为「要记的字段」出现。本页不给出具体 USDT、不给出 R 成绩、不给出这段之后账户权益变成多少。

正着读这一节：时间线教过程。反着读：若有人在第 11 节补上胜率或曲线，就离开了本案例的用法。

## 正反案例

下面两段必须对照着看。它们是教学情景，不是真实行情，不能代表未来结果。

### 正例：把样本当格式，自己另写一版

你把上面 12 节抄成空表，改成自己的品种边界、自己的周期、自己的空仓句。触发仍拆成前提 + 触发。止损仍先于仓位。回测栏留空或只写「尚未按八字段数完」。你不把本页的 EMA + RSI 句子当成开仓指令，也不把本页转发成「网站推荐策略」。

这是正例：案例教过程。过程走完，不证明你的稿有效，也不能代表未来结果。

### 反例：把作业纸当成跟单对象，或补一张假成绩

有人直接按第 6 节下单，并把第 9 节的「小比例」理解成官方仓位。另一人觉得「没有成绩不像完整系统」，就编造一段上升曲线或一张高胜率表贴在作业纸第 11 节。第三人跳过本阶段前十九篇，只收藏本页当策略。

这不是案例的用法。本站禁止用虚构绩效表证明赚钱。再补一条：看见共振就提高杠杆来「执行案例」。本站不鼓励高杠杆。再补一条：把本页名称里的「趋势回调」读成对未来行情的判断。名称只是检索标签。

## 常见错误

1. 把教学样本抄成实盘条件。
2. 要求本页提供回测成绩或权益曲线。
3. 自己编成绩来「补全」第 11 节。
4. 只填入场，不填空仓、止损、刹车和日志。
5. 把案例理解成阶段 3 的标准答案。
6. 一次按样本做了盈亏，就宣布系统有效或无效。
7. 跳过风险和频率，只用第 4–6 节。
8. 把本页当成喊单或自动交易说明。本站都不是。

## 局限性

- **填完整不等于可交易。** 句子能复核，只说明可以开始检查。
- **虚构样本没有经过本站回测，也不将被回测成「有效」。** 不证明该系统有效。
- **同一套句子换品种、换周期、换费用，执行会变。**
- **永续合约有强平（爆仓）风险。** 杠杆会放大亏损。本站不鼓励高杠杆。
- **历史填写和教学案例不能代表未来结果。**
- **阶段 3 读完，仍不是稳定交易能力的证明。** 本站继续只做教育。
