# 清算瀑布怎么读图

清算瀑布（Liquidation Cascade，也称强平连锁）回答：**强平单在薄盘里互相催发时，图上哪些数暂时不可信。** 它不是方向指标，没有 70/30，也不告诉你该不该反向开仓。

先修：[成交量](/indicators/volume)、[持仓量](/indicators/open-interest)、[CVD](/indicators/cvd)。你已经会分开转手、存量和主动净额。本篇把它们放进同一次保证金事件里，看它们怎样一起失真。

本篇不教如何「抄瀑布底」，不教如何预测瀑布结束。

类比：消防栓爆管时，水表、气压表、流量计会一起乱跳。乱跳说明管子在喷，不说明明天该往哪边开店。

## 学习目标

读完本篇，你应该能：

- 用一句话说清：强平单通常是被动市价，打进薄盘会插针，并可能打穿下一波保证金
- 解释此时成交量、OI、CVD、多空比都可能同时失真
- 默认把瀑布进行中记成「数据暂时不可解释方向」
- 写出禁止条件：连续强平、盘口一跳数个点 → 空仓或只平不开
- 拒绝把长下影写成底部，或把 CVD 急跌写成主力出货

## 概念

**清算瀑布**是一连串强平单在短时间内互相催发的过程。它是**保证金事件在薄盘上的成交痕迹**，不是形态交易系统，也不是「主力选择了方向」。

教学链条：

1. 一批仓位触及维持保证金，交易所按规则强制减仓或平仓。
2. **强平单通常是被动市价（taker）**，打进当时的订单簿。
3. 簿薄时，市价会连续吃掉多档，K 线上留下**插针**（长影或跳价）。
4. 这一跳让下一批仓位的保证金也不够，再触发强平，形成连锁。

它回答：

- 这一段急跌或急涨，是否更像强平扫货，而不是普通转手？
- 此时成交量、OI、CVD、[多空比](/indicators/long-short-ratio) 还能不能拿来解释方向？

教学默认：

> 瀑布进行中，成交量、持仓量、CVD、多空比都可能同时失真，**暂时不可解释方向**。

它不回答瀑布会在哪一价结束、长下影是不是底部、该不该反向开仓。

| 中文 | 英文 | 本篇怎么用 |
|---|---|---|
| 清算瀑布 / 强平连锁 | Liquidation cascade | 事件，不是振荡器 |
| 强平 | Liquidation | 保证金不够时的强制减仓或平仓 |
| 插针 | Wick / spike | 市价扫过薄盘后的影线或跳价 |
| 薄盘 | Thin order book | 对手挂单很少，市价容易连吃数档 |
| 失真 | Distorted | 公开数据暂时不宜拿来讲方向 |

## 原理

没有 RSI 那种回看公式。学习者通常读交易所或数据商的**强平记录 / 强平热力图**，再对照价格与盘口，而不是自己算一条「瀑布指标」。

概念上只需记住成交路径：

1. 强平以市价进入订单簿。市价和薄盘止损的行为，见 [订单与成交](/trading-system/order-types)。
2. 对手挂单被吃掉，最新价跳变；标记价会跟，但不必同步。强平看标记价，K 线看最新价。
3. 下一档维持保证金被打穿，重复步骤 1。

可对照的公开痕迹（都可能滞后或口径不一）：

- 价格：数根内走出远大于近期普通波幅的影线或缺口
- 成交量：单根远高于两侧
- OI：短时间明显下降（仓位被关掉）
- 强平数量：连续出现、同一方向堆积

跨所强平数字不能直接加总。写案例时注明来源，不要把单一热力图当成全市场真相。没有「强平超过某张数即瀑布」的全站标准。

## 怎么看

![清算瀑布中量 / OI / CVD 失真示意图](/images/concept/vis-027-liquidation-cascade.svg)

上图是**示意图**，不是真实行情。同一时段价格插针，底下三条曲线同时剧烈抖动。教学上先记「数据不可用」，不写方向句。

1. **先看价格冲击**：盘口一跳数个点（或短时间走出远超近期普通波幅），同时出现长影或缺口。
2. **再看是否连续强平**：不是单笔强平，而是短时间一波接一波。个别强平是日常机制，不等于连锁。
3. **同时核对四条曲线**：Volume 巨量、OI 急变、CVD 单边直插、多空比跳变——任一已经可疑；几条一起剧烈抖动，按教学默认记「数据不可用」。
4. **不要在此时写方向句**：不写「主力出货」「抄底」「空头胜利」。先记「瀑布进行中」或「刚结束、数据仍脏」。
5. **等盘口重新连续、强平不再成串**，再恢复用 Volume / OI / CVD 做普通观察。恢复可读，不等于可以预测下一波。

| 形态 | 观察 | 限制 |
|---|---|---|
| 插针长影 | 市价扫过薄盘后部分收回 | 收回不等于底部或顶部完成 |
| 跳价缺口 | 盘口一跳数个点 | 中间价位可能从未被稳定报价 |
| 巨量柱 | 转手暴增 | 可能主要是连锁平仓，不是新开仓共识 |
| OI 急降 | 未平仓被关掉 | 也可能夹杂普通平仓，口径会滞后 |
| CVD 直插 | 主动卖或主动买单边堆积 | 强平 taker 会扭曲 Delta |
| 数条同时抖动 | 量 / OI / CVD / 多空比一起失真 | 记数据不可用，不写方向 |

观察时须写明：数据来自哪一家所、图表周期（1 分钟插针在 4 小时上可能只是一根影线）、用什么尺子判断「偏大」、连续强平看的是几分钟还是几根 K。

## 怎么使用

把瀑布当成**失效边界**，不是交易主题。

可以这样用：

1. 先声明你看的是哪一家所的强平、成交和 OI，以及哪一个图表周期。
2. 价格冲击加上连续强平，先贴标签：「瀑布进行中」或「刚结束、数据仍脏」。
3. 量、OI、CVD、多空比同时剧烈抖动时，**不写方向句**。不要用它们互相「确认」。
4. 写入系统的禁止条件（教学默认，不是盘中喊单）：
   - 连续强平
   - 盘口一跳数个点（相对该品种近期普通价差）
   - 上述条件下：**空仓或只平不开**
5. 盘口重新连续、强平不再成串之后，再恢复普通观察。恢复可读，不是新的开仓许可。

不要写成：「出现瀑布后反向开仓更划算。」薄盘市价的滑点可以远大于你在图上看到的收盘。本篇不教抄底，不教预测结束。

永续合约有强平（爆仓）风险。杠杆会放大亏损。现货没有这套强平连锁；合约图上的长影经常含保证金事件。本站不鼓励高杠杆。

## 正反案例

下面两段必须对照着看。它们是教学情景，不是真实行情，不能代表未来结果。

### 正例：量、OI、CVD 同时剧烈抖动，先记「数据不可用」

短时间内价格插下一根远长于两侧的影线。成交量单根暴增，OI 明显下降，CVD 几乎直线向下，多空比也跳了一档。你在日志里只写：「连续强平疑似进行中，四条公开数据同时失真，方向句空着。」你没有把长下影标成锤子线，也没有把 CVD 急跌写成主力出货。

这是正例：瀑布课的工作是停笔，不是找方向。停笔之后，价格仍可能收回。收回不证明该抄底，只说明扫货痕迹可以和随后的反弹同时发生。

### 反例：把瀑布长下影写成底部，或把 CVD 急跌写成主力出货

同一段里，有人看见长下影，写成「锤子线，底部到了」。另一人看见 CVD 直插，写成「主力出货，该空」。第三人试图「抄瀑布底」，用市价去接刚刚被扫过的价。

三笔都把保证金事件读成了方向。长下影首先是扫货痕迹；CVD 急变首先是强平 taker 在扭曲 Delta；抄底时的滑点可以大到让计划中的亏损失去意义。本篇不教这三件事。

## 常见错误

1. 把瀑布长下影写成锤子线底部。
2. 把 CVD 急跌写成主力出货，把急升写成主力吸筹。
3. 把巨量当成「有人在这个价大量建仓」。
4. 试图抄瀑布底，或预测「再扫一次就结束」。
5. 用 4 小时收盘形态解释 1 分钟里已经发生的连锁强平。
6. 认为标记价插针和最新价插针是同一件事。
7. 把单笔强平当成瀑布。
8. 把禁止条件写成「出现瀑布后反向开仓更划算」。

## 局限性

- **当底部 / 顶部形态用**：长影在瀑布里首先是扫货痕迹。
- **用来预测结束**：没有「瀑布结束公式」。
- **抄瀑布底 / 摸瀑布顶**：薄盘市价的滑点可以远大于收盘看到的价。
- **跨所热力图直接加总**。
- **瀑布刚过就立刻恢复用 CVD 讲主力**：失真可以持续一段时间。
- **量 + OI + CVD 同时剧烈变动**：教学上这是数据不可用的标志，不是方向确认。

清算瀑布擅长标出「这些数暂时不要用来讲方向」，不擅长预报下一跳。历史案例不能代表未来结果。

## 总结

记住五句话：

1. 强平单通常是被动市价，打进薄盘会插针，并可能连锁。
2. 瀑布进行中，量 / OI / CVD / 多空比都可能同时失真。
3. 默认：这些数暂时不可解释方向。
4. 连续强平或盘口一跳数个点：空仓或只平不开。
5. 不教抄底，不教预测结束。历史案例不能代表未来结果。
