# EMA 指数移动平均线

指数均线（Exponential Moving Average，EMA）也是一条由历史价格平滑出来的线。它和上一篇的 **MA（默认 SMA）** 同属均线家族，算法不同。本站不把 EMA 简称成「MA」，以免读成权重相同。

先修：[MA 移动平均线](/indicators/ma)。若还没手算过 SMA，建议先回去看 5 根收盘价那张表。默认读图顺序仍是先结构，再均线；穿过 EMA 不等于摆动结构已被破坏。

## 学习目标

读完本篇，你应该能：

- 用一句话对比：SMA 窗口内权重相同，EMA 越近的价格权重越高
- 看懂平滑系数 k = 2 / (N + 1)，并理解 N = 20 时最新收盘大约占 9.5%
- 说出同一 N、不同起始日，早期 EMA 可能对不上
- 在示意图上区分：价格在 EMA 上方、来回穿越、在 EMA 下方
- 解释「更灵敏」不是「更准确」，震荡市里 EMA 交叉往往更多

## 概念

EMA 测量的是**近端加权后的价格中枢**。它比同参数 SMA 更强调「最近发生的事」，但仍是过去信息的压缩。

它回答的问题和 SMA 接近：

- 近期中枢往哪移？
- 现价在中枢哪一侧？
- 快慢 EMA 是否交叉？

类比：SMA 像最近 N 次考试平均分，每一科一样重。EMA 更看重最近几次。上周的分数比上个月更影响这条线。即使如此，它仍是成绩单的压缩，不是下一场考试的答案。

EMA 被广泛用作后面 MACD 课的原材料，也常单独当作趋势参照。MACD 正文不在本篇展开。

## 原理

常用平滑系数：

> k = 2 / (N + 1)

递推：

> 今日 EMA = 今日收盘价 × k + 昨日 EMA × (1 − k)

N = 20 时，k = 2 / 21 ≈ 0.0952，最新收盘约占 9.5% 权重。

和 SMA 对比：

| | SMA | EMA |
|---|---|---|
| 窗口内旧值 | 每根权重 1/N | 越远越小 |
| 滑出窗口 | 权重立刻变成 0 | 旧值影响逐渐变小，不突然归零 |
| 同 N 时常见画面 | 更钝、更稳 | 更贴最近的收盘价 |
| 代价 | 旧尖峰滑出时可能跳变 | 单根异常收盘更容易把线拽走 |

启动方式常见两种，软件不同，早期数值会不一样：

1. 用前 N 根 SMA 当作第一个 EMA，再开始递推（较多图表软件）。
2. 从第一根价格直接当种子（早期更不稳定）。

因为递推依赖整段历史，**同一 N 的 EMA 在不同起始日期上会略有差别**。样本越长，差别通常越小。复盘时对不上数字，先检查起始日和软件算法，不要先认定公式错了。

### 三根示意（不必推公式）

假设 k 用 N = 3 来示意：k = 2 / (4) = 0.5。种子先用第一根收盘价 100。

| 根 | 收盘价 | 计算 | EMA |
|---|---|---|---|
| 1 | 100 | 种子 | 100 |
| 2 | 110 | 110 × 0.5 + 100 × 0.5 | 105 |
| 3 | 108 | 108 × 0.5 + 105 × 0.5 | 106.5 |

同一段价格，若 SMA(3) 在第 3 根是 (100 + 110 + 108) ÷ 3 = 106。EMA 更靠近最近两根。这是权重不同，不是谁对谁错。

数字是教学圆整，不是实盘，不能代表未来结果。实际软件默认 N 很少用 3，常见是 12、26、50 等。以你所用图表软件为准。

## 怎么看

观察维度和 SMA 相同，解释时多强调「反应更快」：

1. **斜率与走平**。
2. **价格在 EMA 上方或下方运行的持续性**。
3. **快慢 EMA 交叉**（如 12 与 26）。金叉、死叉同样滞后，同样不是指令。
4. **击穿之后看收盘**：是收盘站回，还是继续离开。教学看收盘，不看影线扫到。
5. **和同参数 SMA 画在一起**：EMA 更贴价格，SMA 更钝。两者分开过大时，说明最近一段涨跌很急。

短 EMA（如 8、12）在永续的低周期图上会非常敏感，几乎跟着价格蛇形，趋势过滤作用变弱。

## 怎么使用

可以这样用：

1. 先声明：图表周期、N、价格源（默认收盘价）、软件用哪种种子。
2. 把 EMA 当动态参照：讨论「收盘在哪一侧」，而不是「碰到线就会弹回去」。
3. 需要更快承认最近的加速或减速时，用 EMA 对照 SMA，看两者分开还是粘在一起。
4. 出现快慢 EMA 交叉时，先看线是否走平。震荡里交叉会更密。
5. 未收盘时不要宣布「EMA 已转向」。

不要把 12 / 26 交叉直接叫成 MACD 金叉。MACD 还要用到两条 EMA 的差、信号线和柱状图。那是后文，本篇只记住：MACD 的默认参数用的是 EMA。

## 正反案例

下面两段是教学对照，不是真实行情，不能代表未来结果。

### 正例：价格沿 EMA 一侧阶梯移动

收盘多次回到 EMA 附近再离开，回撤较浅，均线斜率保持同一方向。

你可以记录：近端中枢在移动，价格回撤后仍在原侧。这是趋势跟踪里常见的参照用法。一次深刺破就能打断这个叙事，所以它仍是观察，不是支撑保证。

### 反例：震荡市里 EMA 交叉比 SMA 更多

区间里价格来回。SMA 因为更钝，交叉次数相对少。EMA 更贴价格，快慢线更容易反复交叉。

若有人因为「EMA 更灵敏」就改用更短的 N，并在每一次交叉上开仓，损耗通常比 SMA 还勤。灵敏与稳定是权衡，不是升级。

插针收盘也会把 EMA 拽走，随后再拽回来。近端权重大，这是代价。

## 常见错误

1. 以为 EMA 能消除滞后。它只减少部分滞后，代价是更多噪声。
2. 把 12 / 26 交叉直接叫 MACD 金叉，却不看柱状图和信号线。
3. 混用 App 里未标明算法的「MA」。有的线其实是 EMA。
4. 用未收盘价宣称 EMA 已转向。
5. 认为价格每次都会在 EMA 上获得支撑。
6. 为了让交叉更好看而不断改 N，造成拟合历史。
7. 同一参数、不同起始日对不上，就认定公式错了。

## 局限性

- 震荡与锯齿行情：更快意味着更多来回穿越。
- 一次性插针：近端权重大，单根异常收盘影响更明显。
- 历史起点不同导致数值对不上。
- 周期过短时，EMA 几乎贴着收盘价，失去「中枢」意义。
- 「更灵敏」不是「更准确」。

EMA 仍然滞后于价格本身。它不能预报转折点。

## 总结

记住五句话：

1. EMA 对近价权重大，SMA 对窗口内每根一样重。
2. 同一 N、不同起始日，早期 EMA 可能对不上。
3. 看收盘相对 EMA 的位置和斜率，不看影线扫到。
4. 金叉死叉仍是滞后观察，不是开仓指令。
5. 震荡市里，更快的线通常交叉更多。
