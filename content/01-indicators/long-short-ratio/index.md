# 多空比

多空比（Long/Short Ratio，LSR）用除法表达倾斜：某一统计口径下，多头相对空头有多少。没有口径的多空比无法解释，也不能跨接口比较。

先修：[持仓量](/indicators/open-interest)。上一篇 [资金费率](/indicators/funding-rate) 看谁在付钱。本篇再引入一种更容易误读的结构数据：人数或仓位的比值。

> 多空比 = 多头侧统计量 / 空头侧统计量

「侧」是什么，必须先写清。下面四行不是同一个指标。

| 口径 | 统计对象 | 常见误解 |
|---|---|---|
| 账户数比（Accounts） | 有多少账户持多、持空 | 一个大户和一个散户各算 1 |
| 持仓量比（Positions / Size） | 多头仓位总量 / 空头仓位总量 | 与账户数比可以反向 |
| 大户账户比（Top trader accounts） | 排名靠前账户的多空人数 | 「大户」定义由交易所定 |
| 大户持仓比（Top trader positions） | 排名靠前账户的仓位量 | 仍不是全市场 |

同一时刻，账户数比可以大于 1（更多账户做多），持仓量比可以小于 1（空头单户更大）。两张图讲的不是同一件事。

多空比通常只覆盖**该交易所、该接口样本**，不是链上全部持仓，也不是全球交易者投票。没有口径，不要引用「市场多空」。

示意图见 vis-011。它是教学抽象，不是某交易所实盘。真实行情另挂 vis-115，不要用示意图冒充实盘。

## 学习目标

读完本篇，你应该能：

- 先读标题口径，再读数字
- 说出账户数比、持仓量比、大户账户比、大户持仓比各在数什么
- 解释为什么同一时刻两种口径可以相反
- 把比值远离 1 当成样本倾斜，而不是全市场真相
- 拒绝「散户偏多就该空」和「抄大户」

## 概念

多空比测量**样本内多空结构的倾斜**，不是价格动量，也不是未平仓总量。

它至多提供：

- 样本更偏多还是更偏空
- 倾斜是在加大还是收敛
- 大户口径与全员口径是否分裂

它不提供：

- 这些仓位的杠杆与强平价
- 开仓成本
- 下一步价格
- 全球真实持仓

OI 是双边存量：一张仓同时有多有空。多空比是某口径下的倾斜。不要把多空比理解成「多头开仓量减空头开仓量」。

把散户账户数比当作「聪明钱反向指标」，属于策略假设，不是本站的知识结论。该假设有时成立、有时不成立，且随样本变化。

类比：同一个小区，你可以数「多少户看多」，也可以数「多方总共占了多少平方米」。户数偏多、面积偏空，可以同时发生。没写清你在数户还是数面积，那个比值没有意义。

## 原理

交易所先按自己的规则抽样（全体、或前 N 账户、或某门槛以上），再分别加总多头与空头的账户数或仓位，相除。

教学写法：

> 账户多空比 = 多头账户数 / 空头账户数
>
> 持仓多空比 = 多头仓位规模 / 空头仓位规模

细节因所而异，课文必须抄接口说明，而不是背「全球统一公式」：

- 对冲账户怎么算（净仓还是分腿）
- 更新频率（5 分钟、15 分钟、1 小时）
- 是否含跟单、子账户
- 单位（张、币、USDT）

本站不指定某一交易所的数字为「标准多空比」。写入复盘的每一张图都要有：交易所、接口名、口径、时间。

没有类似 RSI 14 的默认回看。不要把 LSR 画成 0–100 再套 70/30。人为画 2.0 / 0.5 当极端，只是个人分区，须声明，且不构成指令。

1. **先读标题口径**，再读数字。看不清口径，就把图放下。
2. **1 附近**：样本相对均衡（仍可能两边杠杆不同）。
3. **远离 1**：倾斜。账户比远离 1 只说明人数不均。
4. **变化**：从 0.8 到 1.5 的过程，比孤立读 1.2 更有上下文。
5. **分裂**：全员账户比偏多、大户持仓比偏空，说明结构分层。分层是观察，不是「大户正确」。
6. **与价格、OI、资金费对照**：单独的多空比最容易被讲成故事。

| 形态 | 观察 | 限制 |
|---|---|---|
| 账户比持续 > 1 | 更多账户持多 | 仓位可能仍被少数空头主导 |
| 持仓比持续 < 1 | 空头仓位总量更大 | 人数可能仍偏多 |
| 价格上涨、账户比升 | 更多账户跟多 | 可能是趋势跟随，也可能是拥挤 |
| 价格下跌、账户比仍高 | 人数尚未转向 | 不能推出「即将反弹」或「还将跌」 |
| 大户与全员反向 | 结构分裂 | 不知哪边代表未来价格 |
| 比值急跳 | 检查数据更新、接口变更 | 先当数据事件 |

数值没有传统超买超卖线。一边倒可以持续整个趋势。

## 怎么使用

可以这样用：

1. 打开交易所信息页，先抄接口名和口径，再抄数字。
2. 同一时刻尽量并排看账户比和持仓比。两者相反时，先承认「讲的不是一件事」。
3. 需要上下文时，再打开 [持仓量](/indicators/open-interest) 和 [资金费率](/indicators/funding-rate)：倾斜变化时存量是增是减，付费方向是否一致。
4. 固定一个口径做复盘。中途换接口，等于换了指标。
5. 不要教自己「抄大户」。排名规则不透明，大户也会错。

多空比帮助你读懂披露页，避免把四个接口当成同一个指标。它不单独告诉你该开多还是开空。

永续合约有强平（爆仓）风险。杠杆会放大亏损。人数一边倒或仓位一边倒，都不降低强平的数学可能性。本站不鼓励高杠杆。

## 正反案例

下面两段必须对照着看。真实行情窗只用来认口径分裂，不能代表未来结果。

### 正例：同一时刻两种口径相反

在 vis-115 里，10-30 04:00 前后可以这样记：全员账户比大约 0.59，大户持仓比大约 1.46。更多账户站在空头一侧，但排名靠前账户的仓位总量偏多。它帮助你认出「人数和仓位不是同一张图」，不授权你按其中一张开仓，也不授权你「抄大户」。

窗内多数 4 小时桶都出现类似分裂，只是幅度没这么大。10-12 还可以看到反过来的一层：账户比略高于 1，大户持仓比略低于 1。两种分裂都只是样本结构，不是下一步价格。

### 反例：没有口径就引用「市场多空」

有人截一张比值 2.1 的图，写成「市场多头是空头的两倍，该空」。图标题其实是账户数比。持仓量比可能低于 1。没有口径的「市场多空」是故事，不是数据。

再补一条反向指标反例：散户账户比偏高，被写成「散户偏多就该空」。随后趋势继续，偏多的账户比维持了很久。这是未经验证的口号。

再补一条大户反例：顶级交易者持仓比偏空，被写成「跟着大户」。随后价格上涨。排名靠前不等于知情，也不等于正确。

## 常见错误

1. 没有口径就说「市场多空」。
2. 把多空比当成多头开仓量减空头开仓量。OI 才是双边存量。
3. 账户比和持仓比互相替代。
4. 散户偏多就该空。
5. 「顶级交易者」等于知情者。
6. 把比值 2 理解成「多头是空头的两倍力量」而不看是人数还是仓位。
7. 跨交易所平均出一个「世界多空比」而不统一口径。
8. 把一边倒当成反转定时器。

## 局限性

- **口径未声明或中途更换**。
- **把单所散户比当成全球情绪**。
- **样本偏差**：零售占比高的接口，人数比会系统性偏多或偏空。
- **对冲与套利账户**：真实方向暴露被净额或分腿规则隐藏。
- **低更新频率配高波动价格**。
- **读不出杠杆和强平价**。

多空比擅长演示「公开结构是样本」，不擅长代表全市场。历史案例不能代表未来结果。

## 总结

记住五句话：

1. 没有口径，就不能引用「市场多空」。
2. 账户数比、持仓量比、大户账户比、大户持仓比是四张图。
3. 同一时刻两种口径可以相反。
4. 多空比是样本倾斜，不是 OI，也不是下一步价格。
5. 不要抄大户，也不要把散户比写成反向指令。
