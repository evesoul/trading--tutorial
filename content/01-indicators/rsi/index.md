# RSI 相对强弱指标

相对强弱指标（Relative Strength Index，RSI）观察一段时间内价格上涨力度相对下跌力度，并把结果映射到大约 0 到 100。

它是动量指标，不是趋势线，也不是成交量指标。数值高表示窗口内上涨幅度相对占优；数值低表示下跌幅度相对占优。高或低都不等于价格马上反向。

先修：[K 线](/indicators/kline)、[MA](/indicators/ma)、[EMA](/indicators/ema)。先有读图和趋势参照，再解释 RSI，不容易把 70 / 30 当成红绿灯。

## 学习目标

读完本篇，你应该能：

- 说出 RSI 在测量窗口内平均涨幅和平均跌幅的关系
- 用手算 5 根简化 RSI，并知道软件默认常是 Wilder 平滑、N = 14
- 把 70 / 30 当成分区习惯，而不是反转指令
- 对照两种环境：震荡市里来回摆动，趋势市里高位或低位粘滞
- 把背离当成观察现象，而不是反转已被确认

## 概念

RSI 由 J. Welles Wilder 提出。这里的「相对」是相对**自己窗口内的涨跌**，不是相对另一个币种谁更强。跨品种比较要用其他方法，口径要单独定义。

它回答：

- 最近 N 根里，涨的那部分和跌的那部分谁更大？
- 这种相对强弱是在增强还是在减弱？
- 价格创新高或新低时，相对强弱有没有同步？

它不回答趋势的绝对方向。价格可以在 RSI 高位继续涨。它也不测量仓位、主动成交或资金费。

类比：像比较最近两周「涨了多少」和「跌了多少」，再压到一把 0–100 的尺子上。尺子靠近 100，说明这段里涨幅更占优；靠近 0，说明跌幅更占优。尺子停在高位，不等于下周必须回落。

## 原理

默认价格源为收盘价。本库教学默认 **Wilder RSI**，回看参数 N = 14。

对每根已收盘 K 线：

> 变化 = 今日收盘 − 昨日收盘  
> 涨幅 = 变化和 0 里较大的那个  
> 跌幅 = −变化和 0 里较大的那个（下跌记正数）

前 N 根先做普通平均，得到平均涨幅和平均跌幅。之后用 **Wilder 平滑**（不是再做一次普通 SMA）：

> 新的平均涨幅 =（旧的平均涨幅 × (N − 1) + 当前涨幅）÷ N

平均跌幅同理。然后：

> RS = 平均涨幅 / 平均跌幅  
> RSI = 100 − 100 / (1 + RS)

特例：平均跌幅为 0 时，RSI 视为 100；平均涨幅为 0 且平均跌幅大于 0 时，RSI 为 0。

部分软件用 SMA 或 EMA 做平滑，数值会和 Wilder 原法不同。复盘必须写明算法。以你所用图表软件为准。

未收盘的 RSI 会随最新价晃动。规则判定用已收盘。

### 先用手算 5 根简化版

下面用普通平均，只为建立直觉。软件默认不是 N = 5，也通常不是普通平均。

| 根 | 收盘价 | 变化 | 涨幅 | 跌幅 |
|---|---|---|---|---|
| 1 | 100 | — | — | — |
| 2 | 102 | +2 | 2 | 0 |
| 3 | 101 | −1 | 0 | 1 |
| 4 | 104 | +3 | 3 | 0 |
| 5 | 103 | −1 | 0 | 1 |

平均涨幅 = (2 + 0 + 3 + 0) ÷ 4 = 1.25  
平均跌幅 = (0 + 1 + 0 + 1) ÷ 4 = 0.5  
RS = 1.25 / 0.5 = 2.5  
简化 RSI ≈ 100 − 100 / (1 + 2.5) = **71.4**

这段里涨幅更大，尺子靠近传统超买观察区。它只说明这 4 次变化里涨的部分占优，不说明下一根要跌。

数字是教学圆整，不是实盘，不能代表未来结果。

常见参数：

| 项目 | 常见选择 | 说明 |
|---|---|---|
| N | 14 | Wilder 默认；本站教学默认 |
| N | 7 / 9 | 更敏感，进出极端区更频繁 |
| N | 21 | 更平滑 |
| 极端区 | 70 / 30 | 传统分区 |
| 极端区 | 80 / 20 | 强趋势里减少「过早喊反转」的误读，仍不是安全区 |

改 N 会改变 RSI 进入 70 / 30 的频率。不存在一组「更准确」的参数。

## 怎么看

1. **读数位置**：传统技术分析常把 70 附近看作**超买（Overbought）**区，30 附近看作**超卖（Oversold）**区。这是分区习惯，不是开关。
2. **中轴 50**：在 50 上方，窗口内平均涨幅占优；下方则跌幅占优。可当作粗略的动量方向，仍滞后。
3. **停留时间**：强趋势里，RSI 可以长时间留在高位或低位。这是本课对照的核心。
4. **背离（Divergence）**：价格创新高而 RSI 未创新高，称潜在顶背离；价格创新低而 RSI 未创新低，称潜在底背离。背离不是确定性的反转信号。趋势行情中，背离可以反复出现而价格继续走。
5. **看已收盘**：盘中 RSI 会晃。

超买不代表价格马上就会下跌。超卖不代表价格马上就会上涨。

## 怎么使用

可以这样用：

1. 先用均线或价格结构判断环境：更像趋势，还是更像震荡。
2. 再读 RSI：它是在高低区来回摆，还是粘在一侧。
3. 趋势环境里，把 70 以上或 30 以下先当成「这段涨跌很占优」，而不是当成反向开仓条件。
4. 震荡环境里，RSI 在高低区来回更常见。这能辅助识别区间，仍然不是区间交易信号。
5. 看见背离，先对照价格有没有真的转结构，不要单独下指令。
6. 写清图表周期、N 和算法。不要同时改 N 和极端区去拟合某一段。

RSI 只使用价格，不含量、不含仓。后面的量能和持仓课会补这两个问题，本篇不提前写成组合规则。

## 正反案例

下面两段必须对照着看。它们是教学情景，不是真实行情，不能代表未来结果。

### 正例：震荡市里 RSI 来回摆动

价格在区间里上下移动。RSI 升到 70 附近后回到中轴，再降到 30 附近后回到中轴。高低区来回，可读性通常好于单边趋势。

你可以记录：这段动量在区间两端反复占优。它帮助你认出「尺子在摆」，不授权你在 70 做空、在 30 做多。

### 反例：趋势市里 RSI 粘在 70 上方

价格一段时间内持续上移，均线也保持上倾。RSI 进入 70 以上后并不立刻掉下来，而是在高位停留，甚至反复回到 70 上方。

若把「进入超买」写成卖出指令，你会在趋势还在延伸时反复逆势。这是 RSI 最常见的失效用法。

对称的反例：下跌趋势里 RSI 粘在 30 下方。超卖可以持续。不能仅靠 RSI 判断买卖。

再补一条背离反例：价格继续创新高，RSI 高点一波比一波低。有人把它叫顶背离并开空。随后价格仍可再走一段。背离是不同步，不是反转已被确认。

## 常见错误

1. 超买 = 卖出，超卖 = 买入。
2. 背离 = 反转已确认。
3. 认为 RSI 能预测下一根涨跌。
4. 把「相对强弱」理解成两个币的强弱排名。
5. 用未收盘 RSI 做规则判定。
6. 同时改 N 和极端区去拟合某段行情。
7. 忽略 RSI 只使用价格，不含量和仓。
8. 在趋势里只盯 70 / 30 水平线，不看均线和价格结构。

## 局限性

- **强趋势**：超买或超卖可以持续。单独依赖 RSI 容易过早判断反转。
- **突然单根巨幅**：Wilder 平滑会把冲击带很久，随后若干根也会显得钝。
- **周期过短**：14 周期 RSI 在 1 分钟图上噪声大。
- **算法不一致**：Wilder 与 SMA-RSI 混用，同一时刻读数不同。
- **只看水平线**：忽略价格结构和趋势。

RSI 在震荡里通常比较直观；在强趋势里，更需要先看均线再解释读数。直观不等于可交易。

## 总结

记住五句话：

1. RSI 观察的是窗口内涨跌动能的相对强弱。
2. 70 / 30 是分区习惯，不是反转指令。
3. 趋势里 RSI 可以在高位或低位停留很久。
4. 震荡里 RSI 来回摆动更常见，仍不是开仓条件。
5. 背离是观察现象，不是反转确认。
