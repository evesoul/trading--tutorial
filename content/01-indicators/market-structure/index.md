# 摆动结构与假突破

会读 [K 线](/indicators/kline)、会连 [趋势线与支撑阻力](/indicators/trendlines) 之后，下一步是问：**这段是推进还是回撤，结构还在不在。**

**摆动结构（Market Structure / Swing Structure）**是把相邻的摆动高点、摆动低点排成序列。它是读图约定，不是算法指标，也不是开仓指令。结构还在，不表示价格还会沿同一方向走。

趋势线篇管**斜线和水平区域怎么画**。本篇管**摆动点怎么排成序列**，以及收盘离开和影线扫过怎么记。两篇用同一套摆动点，不要各标一套高低点。

先修：[K 线](/indicators/kline)、[趋势线与支撑阻力](/indicators/trendlines)。本篇只用已收盘的高低点。

## 学习目标

读完本篇，你应该能：

- 用左右 3–5 根窗口，在已收盘 K 线上标出摆动高点和摆动低点
- 按时间顺序写出更高高点 / 更高低点，或更低高点 / 更低低点
- 把沿原方向的一段叫推进，把逆向的一段叫回撤；回撤不是自动反转
- 区分收盘离开前高 / 前低区域，和影线扫过又收回
- 说出破结构之后，原区域角色可能互换，也可能立刻被扫回
- 按「先结构，再均线，再副图」的顺序读图

## 概念

先分清点和序列：

| 中文 | 英文 | 含义 |
|---|---|---|
| 摆动高点 | Swing High | 左右若干根已收盘 K 线里的局部最高 |
| 摆动低点 | Swing Low | 左右若干根已收盘 K 线里的局部最低 |
| 更高高点 | Higher High（HH） | 这个摆动高点高于前一个摆动高点 |
| 更高低点 | Higher Low（HL） | 这个摆动低点高于前一个摆动低点 |
| 更低高点 | Lower High（LH） | 这个摆动高点低于前一个摆动高点 |
| 更低低点 | Lower Low（LL） | 这个摆动低点低于前一个摆动低点 |
| 推进 | Impulse / Advance | 沿最近结构方向、实体通常较长的一段 |
| 回撤 | Pullback / Retracement | 逆向、通常较短或较浅的一段 |
| 假突破 | False Breakout | 影线穿出前高或前低，收盘回到区内 |
| 角色互换 | Role Reversal | 破结构后，原阻力开始被当成支撑来观察，或相反 |

教学上：

- **上升结构**：可见的 HH + HL（更高高点、更高低点）
- **下降结构**：可见的 LH + LL（更低高点、更低低点）

类比：像在山路上依次记下每个垭口和谷底的海拔。垭口一个比一个高、谷底一个比一个高，你可以说「这段在抬」。这是对已经走过的路的描述，不是下一座山还会更高的保证。

回撤像中途回头走一段下坡。下坡本身不自动改写成「整条路已经掉头」。

影线扫过前高，像脚尖踩过界桩又收回来：记「到过」，不记「已经离开这块地」。

本篇不使用订单块、Smart Money、庄家诱多这类说法。扫过前高前低，只记「到过 / 收回」，不鉴定谁在扫。

## 原理

没有回看参数公式。有的是与趋势线篇同一套读图步骤：

1. 选定图表周期，只标**已收盘** K 线。
2. 用左右 3–5 根窗口标出摆动高点、摆动低点。
3. 按时间顺序写下 HH / HL / LH / LL，不要先假设「这是上升」再挑点。
4. 把同方向、实体较长的一段称作推进；把逆向、通常较短的一段称作回撤。
5. 判断「破了没有」时，优先看收盘是否离开前高 / 前低所在**区域**；影线扫到只说明到过。
6. 破结构之后，把原区域标成「角色可能互换」的观察位，同时允许它立刻被扫回。

本站教学约定：

- **到过**：最高价或最低价扫到该区域，包括长影线
- **收盘离开**：已收盘收在前高或前低区域之外
- **假突破 / 扫过**：影线越过，收盘回到区内

不同人选出的摆动点会不一样。这是结构观察的主观性，不是算错了。同一张图可以标出不同序列。序列要服务于你要回答的问题（这段还在不在），不要为了好看而改点。

窗口越小，摆动点越多、噪声越大；窗口越大，结构越慢、越滞后。没有「标准结构参数」。

跨周期：5 分钟上的破结构，不能用来否决 4 小时上仍成立的已收盘结构。多周期怎么写规则，留给后面的系统课；本篇只立这条边界。

## 怎么看

建议按这个顺序读，而不是先找「完美的上升」：

1. **图表周期**：先声明在看哪一根周期的结构。4 小时和 15 分钟上的高低点，不是同一段路。
2. **摆动点**：先标点，再写 HH/HL 或 LH/LL。不要先写结论再找点。
3. **推进还是回撤**：沿最近结构方向走、波动相对大的是推进；逆向、通常更浅的是回撤。回撤可以很深，仍不必改写成反转。
4. **收盘离开 vs 影线扫过**：
   - 收盘离开前高 / 前低区域：记「收盘离开」，原序列可能已被打断。
   - 影线越过、收盘回到区内：记假突破或扫过。到过不等于收在。
5. **破结构之后**：原阻力可能开始被当成支撑来观察，或相反。也可能刚破就被扫回。两种后果都要允许，不要写成剧本。
6. **再叠加均线与副图**：结构看完，才问均线斜率、动量是否同步。副图冲突时回到结构，不是再加一把振荡器。

默认读图顺序：**先结构，再均线，再副图**。均线穿过不等于结构已被破坏。副图金叉、背离不能单独推翻已收盘的结构。

读图时问三句：最近几个摆动点是在抬还是在压？这一段更像推进还是回撤？收盘有没有离开前高或前低所在的区？

## 怎么使用

把摆动结构当成「发生过什么」的序列记录，而不是交易系统。

可以这样用：

1. 先选定并写下图表周期。
2. 只用已收盘 K 线复盘。盯盘可以看当前刺破，但要知道它还在变。
3. 先标摆动点、写出序列，再决定要不要叠加均线。均线下一篇再讲。
4. 在笔记里写「4 小时、HH 然后 HL、前高区域大约在哪、收盘有没有离开」，不要只截一张布满箭头的图。
5. 看见影线穿出，先等这根收盘，再决定记「到过」还是「收盘离开」。

图上的点只帮助你认顺序。它不会下指令，也不产生账户操作。

## 正反案例

下面两段都是教学对照。真实行情窗里的那一段 BTCUSDT 只用来认记法，不能代表未来结果。

### 正例：影线刺破前高后收回

在 vis-109 的 4 小时窗口里，可以先记下 10-13 的低点 L、10-17 的更高低点 HL，以及 10-18 大约 69000 的更高高点 HH。10-21 那根上影到过 69566，收盘回到 69000 一带以内。

你可以记录：**到过，未收盘离开。** 前高被扫过，上升序列先不必改写。下一步仍然是等结构，而不是把刺破写成突破开仓。后面 10-22 的低点先记成回撤，不要自动写成反转。

这是假突破的记法，不是「收回之后就会反向」的剧本。

### 反例：刺破瞬间开仓

同一根还没收盘时，最高价已经越过前高。有人把盘中刺破写成「突破了」，并按突破去开仓。

收盘回来之后，那个「突破」不再成立。把未收盘或只被影线扫过的位置写成已经确认的结论，是本课最常见的误用。

另一个反例：4 小时图上更高低点还在，5 分钟图上刚刚走出更低低点。有人用 5 分钟结构否决 4 小时结构，却不声明自己在看哪一段。两根周期可以同时成立，讨论的不是同一段路。本篇不展开多周期规则，只要求你先写清周期。

## 常见错误

1. 刺破瞬间写成突破开仓，不等收盘。
2. 把回撤自动写成反转。
3. 用 5 分钟结构否决 4 小时结构，却不声明周期。
4. 把影线扫过写成庄家确定诱多、诱空。
5. 破结构后把角色互换当成价格会回来确认的剧本。
6. 先画一条「好看的」趋势线，再改摆动点去贴线。
7. 副图金叉、背离单独推翻已收盘结构。
8. 用虚构 K 线证明某种结构能赚钱。

## 局限性

- 摆动点因人而异，同一张图可以标出不同序列。
- 几乎没有摆动点时，单边插针或根数太少，序列容易变成事后拟合。
- 周期过短时，点差和薄盘成交会制造假高低点。
- 未收盘当已破：盘中刺破，收盘可能收回。
- HH / HL 描述的是已经发生的点，不保证下一个点仍更高。
- 和趋势线、均线不是同一工具：线是位置，均线是算法平滑，结构是点的顺序。
- 清算瀑布、薄盘跳价时，高低点可能是强平扫货，不是广泛共识。巨量也可能来自连锁平仓，本篇不展开。

摆动结构是读图的第一层，不是一套结构交易系统。

## 总结

记住五句话：

1. 先标已收盘的摆动点，再写 HH/HL 或 LH/LL。
2. 回撤不是自动反转；推进和回撤先分开记。
3. 影线扫过只说明到过；收盘离开区域才谈破结构。
4. 破结构之后，角色可能互换，也可能立刻扫回。
5. 先结构，再均线，再副图；结构是观察，不是开仓指令。
