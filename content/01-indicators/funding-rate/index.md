# 资金费率

资金费率（Funding Rate）是永续合约按固定或动态间隔，在**多头与空头之间**转移资金所用的比率。目的是抑制永续价格长期偏离指数价格。它不是振荡指标，没有 70/30。

先修：[持仓量](/indicators/open-interest)。导学里已经见过资金费这个名字。本篇分开两个词，并练习怎么读图上的费率。

| 词 | 含义 |
|---|---|
| **资金费率** | 比率，用来观察拥挤与溢价 |
| **资金费（Funding Payment）** | 实际划走的金额 |

> 资金费 ≈ 仓位名义价值 × 资金费率

精确公式含标记价选取、仓位方向、费率封顶，以交易所为准。只有持有仓位越过结算时点的一方才收付。费率本身不是价格预测。

示意图见下方 vis-007。它先讲「谁付给谁」，不是一段连续行情。不插 vis-101–107。

## 学习目标

读完本篇，你应该能：

- 区分资金费率和资金费：一个是比率，一个是划走的钱
- 说出正费率由多头付空头，负费率由空头付多头
- 解释费率靠近 0 是常态，远离 0 只说明溢价或贴水偏大
- 用名义价值算出一笔教学级资金费，并看出高杠杆下它占权益的比例
- 拒绝把极端费率或「Funding + OI」写成反向喊单

## 概念

- **费率为正**：多头支付空头。常见于合约相对现货升水（永续更贵）。
- **费率为负**：空头支付多头。常见于合约相对现货贴水（永续更便宜）。

它直接测量：让永续贴住现货指数的周期性费用方向与大小。

它间接提供：

- 合约相对现货的溢价 / 贴水是否偏大
- 某一方向持仓是否愿意持续付费（拥挤的侧面）
- 持有成本：拿仓要付多少

它不测量价格下一步涨跌，也不等于 OI 或成交量。极端正费率可以和上涨同时存在很久：付钱的多头仍可能在价格上盈利。

类比：多空之间的过路费。过路费方向告诉你谁在付钱，不等于路要往回走。收费的一方也不等于方向正确。

常规情况下是多空互付，不是交易所当庄家收取。以各所规则说明为准。

## 原理

各交易所公式不同。教学抓结构，不背某一所的全部系数。

常见结构（以主流 U 本位永续的思路为例）：

1. **溢价指数（Premium Index）**  
   比较合约买一 / 卖一或中间价与指数价，衡量永续贵了还是便宜了。
2. **利率（Interest Rate）**  
   部分交易所加入稳定币与标的借贷利率差的一项，数值通常较小，并有夹逼（clamp）。
3. **资金费率**  
   由溢价与利率合成，再设上限、下限。结算间隔常见 8 小时；波动大时有的交易所会缩短间隔。

图上看到的，多是「已结算费率」或「预测中的下一次费率」。预测值在结算前会变。分析历史用已结算序列；盯盘用预测值时要标明「未结算」。

年化换算（仅便于直觉，各所间隔不同）：

> 粗略年化 ≈ 单次费率 × (24 / 间隔小时) × 365

粗略年化很大时，只说明「若费率维持不变，持有一年的费用很可观」。费率通常不会维持不变。不要把资金费率当成 APR 理财。对方付给你的钱来自对面持仓者，伴随价格风险。

数字例子（忽略手续费，教学近似）：

名义 10,000 USDT，单次费率 +0.01%。多头约付出 1 USDT。  
若同一名义用 50x，起始保证金约 200 USDT。这一次 1 USDT 只是保证金的 0.5%；连续多个周期同向偏高，费用会叠上去。费率 0.01% 看起来很小，在高杠杆、大名义上仍是真金白银。

本站不鼓励高杠杆，也不教「吃费率」。

## 怎么看

![资金费率示意图](/images/concept/vis-007-funding-rate.svg)

上图是**示意图**，不是真实行情。零轴上方是正费率（多头支付空头），下方是负费率（空头支付多头）。偏高或偏低只是拥挤的近似。极端费率不等于价格立刻反向，也不是开仓信号。

下面是冻结的真实行情教学窗。费率按结算点（常见 8h），`0.0001 = 0.01%`。极值不是反转指令。窗口已经截取，不是直播行情。历史观察不能代表未来结果，也不构成交易建议。

::real-chart{id="vis-107"}
::


1. **符号**：正 / 负，谁在付钱。
2. **幅度**：靠近 0 是常态；远离 0 表示溢价或贴水偏大，或间隔缩短后的折算不同。比较幅度时先统一「每 8 小时」还是「年化」。
3. **持续时间**：短暂尖峰 vs 连续多个周期同向偏高。后者更像拥挤或持续升水，仍不是反转时钟。
4. **与价格**：价格急涨且费率转正加大，常见于多头愿意付费拿仓。价格跌而费率仍大幅为正，可能是溢价尚未消退或计算滞后。
5. **与 OI**：费率极端 + OI 仍升，拥挤可能在加；费率极端 + OI 降，可能在去杠杆。对照只说明上下文，不是「双指标共振即可反向开仓」。
6. **结算时刻**：K 线在结算附近出现的量能或插针，要先排除机械性调仓，再谈形态。

| 形态 | 观察 | 限制 |
|---|---|---|
| 持续小幅为正 | 轻度升水，多头付少量费 | 常态，几乎不构成观点 |
| 持续大幅为正 | 多头拥挤或合约持续升水 | 价格仍可继续涨 |
| 持续大幅为负 | 空头拥挤或持续贴水 | 价格仍可继续跌 |
| 费率尖峰后回落 | 溢价被修复或间隔规则变化 | 不保证价格回头 |
| 价格新高、费率未新高 | 溢价与价格不同步 | 不是顶背离的等价物 |
| 结算时刻毛刺 | 量能或影线异常 | 先当机制噪声 |

## 怎么使用

可以这样用：

1. 先分清你看的是已结算费率，还是预测费率。
2. 再看符号和幅度。写清是单次比率还是年化，间隔是 8 小时还是 1 小时。
3. 算持仓成本：复盘要把资金费算进净盈亏。
4. 需要上下文时，再打开 OI：付费方向是否伴随加仓。两个数字同向，只表示多个观察接近，结果仍不确定。
5. 结算前后的插针，先当机制噪声。

资金费率解释永续为何能没有到期日仍贴近现货。它不单独告诉你该开多还是开空。

永续合约有强平（爆仓）风险。杠杆会放大亏损。费用与强平是两套风险，可能叠在同一时段。本站不鼓励高杠杆。

## 正反案例

下面两段必须对照着看。它们是教学情景，不是真实行情，不能代表未来结果。

### 正例：用费率解释「谁在付过路费」

费率连续几个结算周期小幅为正。你可以记录：合约轻度升水，多头在付少量费。它帮助你认出「拿多仓有持有成本」，不授权你按正费率开空。

同一段里，若 OI 同时缓升，你可以再记一笔：付费的同时，未平仓规模也在变大。这是 Funding + OI 的观察，不是反向指令。

### 反例：把极端费率当成反转时钟

费率升到近期偏高，有人写成「多头太拥挤，该空」。随后价格继续涨，付钱的多头在价格上仍盈利。极端费率可以维持，趋势也可以继续。

再补一条 Funding + OI 反例：费率极端且 OI 仍升，被写成「双指标共振，反向开仓」。共振只表示两个上下文同向，价格仍可继续沿原方向走。本站禁止把 Funding + OI 写成反向喊单。

再补一条单位反例：把 8 小时单次费率和年化画在同一张图上比较「谁更极端」。二者差几十倍，不能混比。

## 常见错误

1. 正费率就是该空，负费率就是该多。
2. 收到资金费证明方向正确。
3. 把资金费率当成 APR 理财。
4. 把资金费率和资金费当成同一个词。
5. 年化与单次费率混在一张图上比较。
6. 把预测费率当已发生。
7. 认为资金费由交易所当庄家收取。
8. 把 Funding + OI 写成反向开仓条件。

## 局限性

- **当反转指标用**：极端费率可以维持，且趋势继续。
- **跨所、跨间隔直接比数字**。
- **忽略名义价值**：费率很小，高杠杆大名义上仍是真钱。
- **只看 BTC 的经验套到低流动性合约**：山寨溢价与操纵更常见。
- **保险基金、自动减仓等极端机制启动时**，价格、溢价、费率关系会变形。
- **强平与资金费结算可能落在同一时段**，因果难分。

资金费率擅长补充「谁在付费、拿仓贵不贵」，不擅长预报转折。历史案例不能代表未来结果。

## 总结

记住五句话：

1. 资金费率是比率；资金费是划走的钱。
2. 正费率多头付空头，负费率空头付多头。
3. 过路费方向不等于路要往回走。
4. 比较幅度前，先统一间隔和单次 / 年化。
5. Funding + OI 只是对照拥挤与加仓，不是反向喊单。
