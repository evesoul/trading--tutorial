# 布林带

布林带（Bollinger Bands，BB，也常写 BOLL）由 John Bollinger 提出。它把「均线中枢」和「价格离散程度」画在同一张主图上。

先修：[MA 移动平均线](/indicators/ma)。本站中轨默认是**简单移动平均（SMA）**。单独说 MA 时，本库默认指 SMA。若软件用 EMA 作中轨，必须当作变体声明。

上一篇 [KDJ](/indicators/kdj) 仍在看动能位置。本篇换问题：最近波动有多大，价格相对自己的中枢有多远。

示意图见下方 vis-010。三格是对照，不是一段连续行情，不要读成「收口之后就会向上」。不插 vis-101–107。

## 学习目标

读完本篇，你应该能：

- 说出三条线：中轨是 SMA，上下轨是中轨加减 k 倍标准差
- 解释带宽变窄只说明最近波动小，不说明接下来往哪边走
- 把触及上轨或下轨当成「相对中枢较远」，而不是反向开仓条件
- 举出趋势里价格沿上轨或下轨走轨道的反例
- 区分收盘相对轨道，和影线扫到轨道

## 概念

布林带由三条线组成：

- **中轨**：通常是 N 期简单移动平均（SMA）
- **上轨**：中轨 + k 倍标准差
- **下轨**：中轨 − k 倍标准差

价格进入上轨附近或下轨附近，只说明相对最近 N 根，它处在统计上较远的位置。这不是「到上轨就该卖、到下轨就该买」。

它同时测量两件事：

1. **中枢位置**（均线）
2. **波动率**（标准差，即价格相对中枢的离散）

派生读数（可选，本篇只建立名字）：

- **带宽（Bandwidth）**：(上轨 − 下轨) / 中轨
- **%B**：价格在上下轨之间的相对位置

带宽变窄只说明最近波动小，不说明即将往哪边扩大。开口也不是开仓指令。

类比：中轨像最近 20 次考试的平均分。上下轨像「离平均分有多远」的活动围栏。围栏收窄，只说明最近分数很接近；围栏突然拉开，只说明最近分数散开了。围栏不会告诉你下一场考试考高还是考低。围栏每场都在重算，不是钉在墙上的固定支撑。

## 原理

默认常用 N = 20，k = 2，价格源为收盘价。

> 中轨_t = SMA(Close, N)
>
> σ_t = 过去 N 根收盘价的标准差
>
> 上轨_t = 中轨_t + k × σ_t
>
> 下轨_t = 中轨_t − k × σ_t

标准差的教学说法：先算各收盘与中轨的差，平方，再平均，再开方。软件可能用总体标准差（除以 N）或样本标准差（除以 N−1）。两条轨道宽度会略有差别。本站不要求你手算到第几位，复盘时注明软件即可。

约 2 倍标准差的直觉（若收益近似钟形，仅作数量级想象，行情不满足正态）：多数收盘会落在上下轨之间，少数会触及或刺破轨道。刺破并不罕见，尤其在趋势加速时。不要以为「2 倍标准差 = 很少碰到，所以碰到就要反向」。

| 参数 | 常见值 | 说明 |
|---|---|---|
| N | 20 | Bollinger 常用默认 |
| k | 2 | 默认带宽 |
| k | 1.5 / 2.5 / 3 | 更窄或更宽，触及频率改变 |
| 中轨算法 | SMA | 本站默认 |
| 价格源 | Close | 也有人用典型价，须声明 |

改 N 同时改变中枢速度和波动样本。没有「更准」的带宽，只有「触及更频繁或更稀少」。未收盘价会让轨道跟着影线跳舞。规则判定用已收盘。

## 怎么看

![布林带中轨与开口收口示意图](/images/concept/vis-010-bollinger-bands.svg)

上图是示意图，三格分别对照收口、开口向上走轨道、开口向下走轨道。开口方向事先未知。碰上轨不是卖点，碰下轨不是买点。

1. **带宽**：变窄是波动收缩，有时称收口、挤压（Squeeze）；变宽是波动扩张，有时称开口。收口之后常有较大波动，但方向事先未知，也不是每次收口都会大波动。开口收口都不是开仓指令。
2. **价格与轨道**：触及或刺破上轨 / 下轨，表示相对中枢的延伸。趋势里价格可以沿上轨或下轨**走轨道（walking the band）**。
3. **中轨**：当作 20 期均线来看斜率与穿越。价格回到中轨，可能是回归，也可能是中继，也可能是反向的开始。
4. **%B**：大于 1 表示收盘在上轨之上；小于 0 表示在下轨之下。同样不是买卖指令。
5. **与 K 线配合**：看收盘相对轨道，而不是影线扫到上轨就算「冲带」。

上轨不是超买线。下轨不是超卖线。轨道每根都在重算，会跟着价格走，不是固定的支撑阻力墙。

## 怎么使用

可以这样用：

1. 先复习中轨就是 SMA。布林带不是独立于均线的另一套系统。
2. 再看带宽：最近是收着，还是张着。
3. 趋势教学里，先找「价格是否贴着上轨或下轨连续收盘」，用来打破「碰轨就反」的直觉。
4. 震荡教学里，价格可以在移动通道里来回，但通道本身会变形。
5. 收口时，只记录「波动变小」，不要提前加杠杆等待突破。收口可以维持很久，方向也不预先写在带宽里。
6. 写清 N、k 和中轨算法。不要叠很多组参数去拟合某一段「刚好碰到点」。

布林带不测量方向对错，也不测量成交与持仓。开口时有没有量、仓位有没有增减，是后面的问题。

永续合约有强平（爆仓）风险。收口阶段若用高杠杆「等突破」，很小的假扩张就可能把保证金打薄。本站不鼓励高杠杆。

## 正反案例

下面两段必须对照着看。它们是教学情景，不是真实行情，不能代表未来结果。

### 正例：震荡画面里价格在移动通道里来回

中轨走平，价格上下触及轨道后又回到带内。你可以记录：相对 20 根中枢，价格在统计上的远端和近端之间切换。它帮助你认出「通道在，但通道会变形」，不授权你在下轨做多、在上轨做空。轨道会被新波动改写，边界会移动。

### 反例：趋势里走轨道，碰轨不回头

价格一段时间内持续上移，连续多根收盘贴近上轨。带宽同时张开。若把「碰到上轨」写成卖出指令，你会在趋势还在延伸时反复逆势。这叫走轨道，是布林带最需要留下的反例。

对称的反例：下跌趋势里价格沿下轨行走。下轨买入会反复做错方向。

再补一条收口反例：带宽明显变窄，有人写成「即将向上突破」。随后轨道可以向下张开，也可以先假扩张再收回，也可以长时间继续收着。收口不预告方向。

## 常见错误

1. 上轨超买、下轨超卖，到轨就反向。
2. 收口之后向上突破「更常见」。方向没有这种结论。
3. 以为 2 倍标准差意味着只有很少时间触轨，因而触轨很稀有。行情不服从简单正态，触轨并不稀有。
4. 把布林带当成独立于均线的另一套系统。中轨就是均线。
5. 用未收盘价让轨道跟着影线跳舞。
6. 叠加很多组 (N, k) 直到某段历史看起来刚好碰到点。
7. 把开口当成开多或开空的指令。开口只说明波动在扩大。
8. 影线扫到上轨就当成收盘已经冲带。

## 局限性

- **把轨道当固定支撑阻力**：轨道每根都在重算，会跟着价格走。
- **强趋势走轨道**：下轨买入或上轨卖出会反复做错方向。
- **突然插针**：标准差被单根放大，轨道瞬间撑开，随后再收，形态难看且滞后。
- **低波动长时间收口**：以为马上突破而过早加杠杆。收口可以维持很久。
- **跨品种比较带宽绝对值**：价格量级不同，应看相对带宽。

布林带擅长同时画出中枢和最近离散，不擅长预报突破方向。历史案例不能代表未来结果。

## 总结

记住五句话：

1. 中轨默认是 SMA，上下轨是中轨加减若干倍标准差。
2. 碰轨只说明相对中枢较远，不是反向指令。
3. 趋势里可以沿上轨或下轨走轨道。
4. 收口开口描述波动大小，不预告方向，也不是开仓指令。
5. 看收盘相对轨道，不要只看影线扫到。
